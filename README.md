# 思维模型决策工具

**任何疑惑，先用思维模型跑一遍。**

**把一件纠结的事发给你正在使用的 AI 智能体，让它逐步问清问题、比较选择，最后给你一份下一步行动计划。**

例如，决定要不要报名课程、怎样安排有限时间、一个项目该继续还是调整。你不用先学模型名称，也不用写完整需求书，从一句“我最近在纠结……”就能开始。

这里的 **Skill（技能包）** 是供 AI 助手读取的流程和资料。使用时仍在你的智能体里对话，GitHub 页面用于下载和查看说明，面向不同品牌的产品。原生支持 Skills 的产品可安装；没有 Skills 功能但能完整读取工作区资料的产品，可以在当前会话加载。具体能力先让智能体检查，不要求你自己判断技术细节。

## 开始使用

已经安装的用户，可以直接从第 2 步检查并开始。

### 1. 把这段话发给你正在用的智能体

复制整个文本框，粘贴到智能体的**对话输入框**并发送。

```text
请帮我使用“思维模型决策工具” thinking-model-decision：
https://github.com/sushengs-creator/thinking-model-decision/tree/main/skills/thinking-model-decision

先检查当前环境。支持原生 Skills 时，按本产品的方式安装完整技能目录；
没有 Skills 功能但能读取完整目录时，在本次会话加载 SKILL.md 及其所需资料。
若都做不到，请说明具体缺口，并给我当前产品可执行的下一步，不要声称已经安装。
不确定产品信息时先问我产品名和版本，不要猜测菜单或安装目录。
若已有版本，先备份并保留我的新增模型与修改。
完成后，实际读取入口和一张模型卡，告诉我采用哪种方式、读取是否成功、
下次如何调用，以及能否生成可下载的 HTML 文件。
```

**不能自动安装时**，先[下载独立技能包 ZIP](https://raw.githubusercontent.com/sushengs-creator/thinking-model-decision/main/dist/thinking-model-decision-v1.6.0.zip)。解压后得到 `thinking-model-decision` 文件夹，里面直接有 `SKILL.md` 和 `references` 等资料。按照当前产品的技能导入或工作区文件入口，提供**完整文件夹**。只接受 ZIP 的产品要按其格式要求导入；不同产品的入口和限制可能不同，具体操作见[手动安装与会话加载](docs/INSTALL.md#手动安装与会话加载)。

如果下载直链打不开，可用[完整仓库备用下载](https://codeload.github.com/sushengs-creator/thinking-model-decision/zip/refs/heads/main)。解压后在 `dist` 文件夹找到 `thinking-model-decision-v1.6.0.zip`，再按上面的方法使用。

如果产品只能收聊天文字，无法安装技能或读取完整资料，就暂时不能运行本工具的完整模型库。可以先看下面的示范，或在能读取资料的智能体中使用。向普通聊天框只发一个 GitHub 链接，不等于完成安装。

### 2. 确认已经能用

安装回执应说明**安装或加载方式、实际读取的资料、下次调用方法**。仅回复“已安装”，或只显示技能名，还不能确认资料可用。

如果回执不清楚，发送下面这段检查口令。

```text
请检查 thinking-model-decision 是否在当前会话可用。
实际读取它的 SKILL.md 和 references/cards/TM-077.md，
告诉我入口中的版本、这张卡的名称，以及它在什么情况下不适合直接试错。
说明资料从哪里读取、是原生安装还是仅本次加载；无法读取就如实说明。
```

正常检查会读到“可逆决策”卡，并依据卡片解释使用边界。这能检查当前会话的资料访问；是否能在新会话自动发现，仍取决于你的产品和安装范围。仅本次加载的用户，换会话后要重新提供目录。

### 3. 说出第一件困惑

第一次可以直接发送下面的教学问题，也可以把最后一句换成自己的实际困惑。

```text
请使用思维模型决策工具，先每轮问我一个关键问题，等我回答后再继续。
问题清楚后，比较选择，给我下一步行动计划。
我想学数据分析，已经看了好几门课，但一直决定不了要不要报名。
```

接下来，你只需要回答它的问题。不知道就说“不知道”，没有数据也可以先讲经历。它可能先问“你希望学会之后，解决哪一件具体的事”。已有背景足够时，它应直接分析，不必固定问满几轮。

**所有产品都可以先用上面的自然语言表达意图。** 能否触发已安装技能，由当前产品决定；有技能菜单时也可选中它。产品专用命令见[调用说明](docs/INSTALL.md#安装后如何调用)，不必记住某个平台的前缀。

### 4. 看行动计划，再带着结果回来

信息足够后，你应看到**当前建议、为什么这样判断、第一步做什么、什么时候调整**，以及事实和未知的区分。先核对建议是否符合你的目标和限制，有误就纠正；前提成立后再执行第一步。

- **能生成文件的环境**，默认提供 HTML 行动计划链接或附件。下载 `.html` 文件，用浏览器打开即可阅读和打印，不需要编程。
- **不能生成文件的环境**，默认提供完整 HTML 源码及保存方法，不应给出不存在的下载链接。觉得保存源码麻烦，可以直接说“这次请用聊天文字给我行动计划，不生成文件”。

收到计划以后，可以在同一对话发送下面的续接口令。

```text
请根据上面的行动计划继续。我的实际行动和结果是【写真实情况】。
请说明哪些判断需要调整，更新下一步安排，并保留仍然成立的约束。
```

如果换了新对话，先附上旧报告或结论摘要，再说明变化。工具会根据你提供的结果更新，不会自动知道你在线下做了什么。

## 操作示范

**以下是虚构教学案例，展示怎样使用，不是真实用户记录或效果证明。** 主题是“要不要报名数据分析课程”，实际使用时不要照抄案例中的个人条件。

### 你怎样回答，问题怎样变清楚

| 轮次 | AI 询问 | 示例用户回答 |
|---|---|---|
| 1 | 学会数据分析后，你最想先解决哪件事？ | 我每个月要做活动报告，希望判断哪些活动值得继续做。 |
| 2 | 你每周能稳定投入多少学习时间？ | 最多三小时，但我看的系统课每周要八小时。 |
| 3 | 除了报名这门课，还有什么可以先试的方式？ | 有免费短教程和有权用于练习的往年数据表，尚未试过，也没有必须现在报名的期限。 |

助手逐轮等待回答。得到这些信息后，问题被明确为“怎样在每周三小时以内，开始改善活动报告”。短教程是否适用、数据是否齐全、能否独立理解结果，都仍然未知。

### 你会得到怎样的建议

本例用 **TM-077 可逆决策** 检查投入、反馈和退出条件，用 **TM-062 信息价值** 确定试学要回答哪些会改变后续选择的问题。用户不需要指定这两个模型，助手应按实际问题读取和选择。

| 选择 | 本例中的判断 |
|---|---|
| 立即报名当前系统课 | 暂缓。按现有信息，八小时要求超过三小时约束；如果课程允许慢学且得到核实，可重新比较。 |
| 先用短教程做一个小任务 | 有条件优先。先检查材料及费用要求，再限定投入尝试。 |
| 维持现有月报做法 | 保留为基准。如果当前材料或时间不具备，可以先暂停学习安排。 |

行动计划会进一步写清楚。

1. 示例学习者先检查教程所需的软件、费用和数据字段，选一个月报问题；条件不具备就缩小任务或暂停。
2. 下次可用学习时段内做一张简单汇总，准备、操作和复盘**合计不超过三小时**。这是投入上限，不是完成承诺。
3. 记录用时、完成内容、卡点，以及能否独立解释统计口径和结果。只会跟着教程做，不等于已经理解。

这里可以[下载 HTML 示例报告](https://raw.githubusercontent.com/sushengs-creator/thinking-model-decision/main/docs/examples/learning-decision-demo.html)，保存后用浏览器打开。如果链接显示源码，用浏览器“另存为”保存为 `.html`；也可到[文件页](docs/examples/learning-decision-demo.html)点击 **Download raw file** 下载。完整逐轮示范见[案例详解](docs/EXAMPLE.md)。

### 做完之后怎样继续

假设这位用户本周已经尝试两小时，可以这样补充结果。

```text
请更新上面的行动计划。我本周试了两小时，能跟着做出汇总表，
但离开教程后无法独立解释计算口径。每周仍然只有三小时。
请说明哪些判断改变了、哪些仍成立，保留旧版，再给下一步安排。
```

更新应针对理解上的缺口调整练习方式。原来的时间约束仍成立，本周后续学习和复盘最多再用一小时；也不能因为做出一张表，就认定每周八小时的课程已经适合。

## 其他情况怎么说

| 你想做什么 | 可以直接发送 |
|---|---|
| 比较方案 | “请用思维模型决策工具，比较这几个选择，先帮我弄清目标和限制。” |
| 已准备好材料 | “请根据这些背景、选项和约束，直接给行动计划。” |
| 不想继续回答 | “先根据现有信息给阶段性计划，把未知和条件写清楚。” |
| 暂停 | “今天先暂停。” |
| 条件变化 | “情况变了……请更新受影响的判断与行动。” |
| 复盘 | “这是原报告、实际行动和结果，请区分判断、执行与环境变化。” |

更多方法见[详细使用指南](docs/USAGE.md)。新增模型属于维护操作，日常用户无需学习；需要时再看[模型维护流程](skills/thinking-model-decision/references/maintenance.md)。

## 卡住了怎么办

| 遇到的情况 | 下一步可以这样做 |
|---|---|
| AI 打不开 GitHub，或不能自动安装 | 下载上面的 ZIP，按[手动步骤](docs/INSTALL.md#手动安装与会话加载)提供完整目录。请它指出缺哪项能力或权限。 |
| 文件已经下载，但 AI 说找不到技能 | 检查提供的是包含 `SKILL.md` 的完整目录，按产品要求重新加载，再运行第 2 步。云端智能体不一定能读取你电脑里的文件。 |
| AI 一次抛出很多问题，或只列模型名 | 说“先只问我一个会改变判断的问题，等我回答；信息足够后给具体行动”。流程仍不符合时，先做第 2 步的读取检查。 |
| 它替你猜了目标或事实 | 说“这不是我确认的信息，请改为未知，依据我实际提供的内容继续”。 |
| 它一直追问，迟迟不给结果 | 说“根据已有信息先给阶段性计划，保留未知，告诉我现在能做什么”。 |
| 只看到 HTML 代码，或者附件打不开 | 说“这次先在聊天中给我完整行动计划”；想保留网页文件时，按[报告保存方法](docs/USAGE.md#报告怎样打开与保存)处理。 |
| 换一个对话后，它不记得上次情况 | 附上旧报告或摘要，补充新信息；会话加载方式还要重新提供技能目录。 |

## 资料、来源与维护

当前技能版本为 **1.6.0**，包含鬼子不言撰写的 133 篇思维模型原文、133 张操作卡、100 个万维钢工具条目及 87 条跨库关系。两套资料有重叠，不等于 233 个彼此独立、全部验证过的模型。本轮更新的是新手说明与分发方式，模型内容和核心流程不变。

本工具使用 [Agent Skills 开放格式](https://agentskills.io/specification)。格式可以复用，各智能体的安装和资源访问能力仍有差异；本项目没有逐一实测所有产品，也不需要额外的专用 API Key。模型服务的账号和额度由你所用的平台提供。
