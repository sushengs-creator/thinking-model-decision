# 思维模型决策工具

有困惑时，从一句话开始。工具通过一步一步的追问，帮你理清问题，再用思维模型比较选择，每次分析完成后，默认给出一份 **HTML 下一步行动计划**，包含决策依据、执行安排和调整条件。

知识库包含作者提供的 **133篇思维模型原文、133张操作卡，以及万维钢现代思维工具100讲的本地技能资料快照**，已整理87条跨库关系。当前Skill版本为 **1.6.0**。这些是可组合的参考资料，不是233个彼此独立、全部验证过的模型。

第一次使用，可以先看 [完整操作示范](#操作示范)，再把案例中的困惑换成自己的问题。

## 最简单的安装方法

把下面整段话复制到 **你正在使用的、支持 Skill 的 AI Agent**：

```text
请为当前 AI Agent 安装“思维模型决策工具”：
https://github.com/sushengs-creator/thinking-model-decision/tree/main/skills/thinking-model-decision
请按照当前 Agent 支持的 Skill 安装方式，安装完整的 thinking-model-decision 技能目录，并检查是否可调用。
如果已经安装，请先检查版本、备份并保留我的本地新增模型和修改，再进行更新。
如果当前环境无法自动安装，请说明原因，并给出适用于当前 Agent 的手动安装步骤。
```

安装完成并被当前 Agent 识别后，可以这样使用：

```text
请调用 thinking-model-decision（思维模型决策工具），帮我一步一步梳理这个困惑，最后给我 HTML 下一步行动计划：
我最近在纠结……
```

本工具采用 [Agent Skills 开放格式](https://agentskills.io/specification)，面向所有支持该格式的 AI Agent，安装方式由各 Agent 决定。核心流程不依赖 Codex 或 `skill-installer`；后者只是部分环境可用的安装工具。使用时需要 Agent 能读取完整技能包及相关资料；保存 HTML 需要文件生成能力。各产品的导入入口、技能目录、调用语法和能力可能不同，本项目尚未逐一实测。

它是运行在 AI Agent 中的 **Skill**，运行需要你使用的平台或模型服务。本仓库没有独立聊天服务，也不要求额外配置专用 API Key。

不会安装或希望手动安装，可查看[详细安装与更新指南](docs/INSTALL.md)。

## 操作示范

本例演示怎样决定是否报名数据分析课程。

**下面的情境、问答和报告均为编写的虚构教学示例，用来演示操作，不是真实用户记录、实跑记录或效果证明。** 实际使用时，助手会等待你的回答，再决定下一步；你不用照着示例回答，也不用先学会模型名称。

### 第一步，把困惑发给 AI

安装并启用技能后，在当前 Agent 的对话框里发送下面这段话。在 Codex 中，也可以把第一句换成 `$thinking-model-decision`。

```text
请调用 thinking-model-decision（思维模型决策工具）。
我想学数据分析，已经看了好几门课，但一直决定不了要不要报名。
请一步一步帮我梳理，每轮问一个关键问题，等我回答后再继续。
问题清楚后，给我一份 HTML 下一步行动计划。
```

### 第二步，每次回答一个问题

**AI 第一次提问**

> 你希望学会数据分析后，先解决哪一件具体的事？

**示例回答**

> 我每个月都要整理一份活动数据，希望能自己看出哪些活动值得继续做。

**AI 根据回答继续问**

> 现在有了具体目标，就是改善每月的活动分析。你能稳定投入多少学习时间？

**示例回答**

> 每周最多三小时。我看中的系统课每周要八小时，暂时挤不出更多时间。

**AI 再确认可行的选择**

> 这门课的时间要求超过了你的稳定投入。除了报名系统课，你还有什么可以先试的学习方式？

**示例回答**

> 有一份免费短教程，可以拿往年的一张数据表跟着做，我有权用它练习，但还没试过。没有必须现在报名的期限。

三轮只属于这个示例。信息已经足够时，助手会停止常规追问；实际问题缺少关键条件时，才继续问。你不知道的事情可以直接回答“不知道”。

### 第三步，看问题如何变清楚，模型如何改变判断

此时助手可以归纳为“怎样在每周三小时以内，开始改善活动数据分析”。还不知道短教程是否适用、数据是否齐全、学习后能否独立解释结果，这些会保留为待验证条件。

本例选择 **[TM-077 可逆决策](skills/thinking-model-decision/references/cards/TM-077.md)** 作主模型，把下一步限定为有时间上限的小任务，同时承认已经花掉的时间无法收回。补充 **[TM-062 信息价值](skills/thinking-model-decision/references/cards/TM-062.md)**，明确这次尝试要回答“时间够不够、卡在哪里、能否独立解释”，以及不同结果会怎样改变后续选择。缺少可信概率和收益数据时，不编造分数或回报率。

| 可选方案 | 与当前目标、约束的关系 | 本例中的判断 |
|---|---|---|
| 立即报名所看的系统课 | 按已提供信息，每周八小时超过三小时上限 | 暂缓；只有时间安排或课程要求发生可核实的变化，才重新比较 |
| 先用短教程完成一个小任务 | 可以限制投入，并观察实际学习困难；适用性尚未知 | 有条件优先，先检查材料和资源要求 |
| 暂时维持原有月报做法 | 无需新增学习投入，但改善目标仍未推进 | 保留为基准；当前没有合适材料时可以暂用 |

### 第四步，打开 HTML 行动计划，照着做第一件事

正常完成分析后，助手会给出当前任务中实际保存的 HTML 文件链接。打开即可阅读，也可用浏览器打印；不需要再说一次“帮我转成 HTML”。

这里提供一份可查看结构和内容的 **[HTML 示例报告](docs/examples/learning-decision-demo.html)**。GitHub 文件页显示源码，可点击 **Download raw file** 下载，再用浏览器打开。文件名是 `learning-decision-demo.html`，无需联网阅读。

报告中的行动安排如下。三小时来自示例中的个人约束，只是本次投入上限，不代表能在三小时内学会数据分析。

| 顺序 | 示例学习者要做什么 | 得到什么，以及何时停下 |
|---|---|---|
| 先检查能否开始 | 查看教程是否需要新付款、额外软件及当前没有的数据；选一个月报中确实需要回答的小问题 | 明确能否在现有条件下尝试；有前置缺口就先缩小任务或暂停 |
| 下次可用学习时段内尝试 | 用允许使用的数据副本，围绕这个问题做一张简单汇总；准备、操作和复盘合计不超过三小时 | 保留结果、实际用时和卡点；到时间上限即停，不用挤占其他安排强行完成 |
| 尝试结束后判断 | 检查能否说明统计口径、结果含义和限制；区分“照着做成”与“能够独立解释” | 根据具体缺口决定继续短教程、补基础、寻求有针对性的帮助或另选课程 |

能完成一次小任务，也不自动说明适合报名每周八小时的课程。报告会保留当前建议的前提，以及哪些新信息会改变它。

### 第五步，带着结果回来更新

继续这个虚构情境。假设尝试后出现下面的情况，可以在原对话发送这段话；真实使用时换成自己的实际记录。

```text
请继续使用 thinking-model-decision，更新刚才的 HTML 行动计划。
我本周试了两小时，能跟着教程做出一张汇总表，
但离开教程后，不能独立解释计算口径。
每周仍然只有三小时。请说明哪些判断改变了、哪些仍成立，
保留旧版，再给出下一步安排。
```

助手应把“能照着做出结果”记为新信息，把“独立理解仍不足”作为下一步要处理的缺口，调整练习或求助方式，并更新 HTML。原来的时间约束仍然成立，不应因为做出一张表就建议增加到八小时；本周后续学习与复盘合计最多再用一小时，不足的部分延至下一次可用时段。若已换新对话，先附上旧报告或结论摘要，再补充变化。

把第一步中的困惑换成你的问题，就可以开始。背景已经充分时，也可以直接说“根据这些材料出报告”；暂时不想继续回答时，说“先给阶段性报告，标明未知”。


## 一次决策怎样进行

**说出困惑 → 逐轮澄清 → 校准问题 → 选择模型 → 交付 HTML 下一步行动计划。**

- 你可以只讲一件事或一种困惑，不用先填表，也不用知道模型名称。
- 通常每轮只问一个关键问题，收到你的回答再推进。
- 对话会逐步弄清：发生了什么、真正要决定什么、希望得到什么、有哪些限制和选择。
- 信息足够就停止常规追问；一般选一个主模型和必要补充，解释它们怎样改变判断。
- 最终交付可离线打开、可打印的 HTML 文件，包含当前建议、事实与假设、方案比较、行动依据和安排，以及调整条件；对话里附简短结论和文件链接。

如果你已经准备好材料，可以直接要求出报告。如果暂时不想继续回答，也可以说“先给我一份阶段性报告”。报告之后改变目标或约束，只需补充变化，工具会更新 HTML 并说明变更，不用重答全部问题。无需每次再要求“转成 HTML”；单轮澄清不出文件，明确要求纯文本或其他格式时遵从你的选择。

## 调用方式与规则

通用说法是“请调用 thinking-model-decision（思维模型决策工具）”。如果你的 Agent 提供技能菜单或专用命令，使用该产品的调用方式；例如 Codex 可以用 `$thinking-model-decision`。`$` 前缀不是跨 Agent 的统一要求。工具根据你这次想做的事情选择路径，不必背固定口令。

| 你想做什么 | 可以直接这样说 |
|---|---|
| 从模糊困惑开始 | “用思维模型决策工具帮我梳理，先一步一步问我。” |
| 比较选择 | “我有A、B两个方案，先帮我澄清目标和约束，再出报告。” |
| 材料已经充分 | “这些是背景、目标和限制，请直接给决策报告。” |
| 暂时不想补充 | “根据现有信息先给阶段性报告，把不确定的地方标出来。” |
| 先暂停 | “今天先暂停。”（停止追问和分析；只有你同时要求时才出阶段性报告。） |
| 修改已有报告 | “情况变了：……请更新受影响的结论和行动。” |
| 复盘 | “这是上次的判断、行动和结果，帮我区分决策、执行和环境变化。” |
| 新增模型 | “这是思维模型134的文稿，请更新工具，完成卡片、关系核对和试跑。” |

默认每轮一个主要问题，等你回答再推进；已有信息不重复问，未知不替你编。问题、目标、关键限制和可比较选项清楚后，就进入分析和报告，不再要求你批准开始。报告使用实际读过的模型，默认一个主模型、至多三个补充或反证工具；没有适合的模型就说明原因，不凑数量。模型帮助比较，最终价值排序与选择仍由你决定。

仅提供文稿或要求审稿不会自动入库。明确要求维护时，只修改本次指定的目标；缺少写入或校验能力会标明未完成步骤。普通分析无需 Python，无法联网时会保留外部事实的待核实状态。保存 HTML 需要文件写入能力；不具备时会给可保存的完整源码，并如实说明尚未生成文件。

完整步骤、虚构对话示例、报告说明和常见问题见 **[详细使用指南](docs/USAGE.md)**。
