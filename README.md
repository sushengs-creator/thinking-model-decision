# 思维模型决策工具

**任何疑惑，先用思维模型跑一遍。**

把拿不准的事说给你的 AI 助手：它会一步一步追问，帮你弄清真正要决定什么，再比较选择，最后给你一份**有依据、能照着做的下一步行动计划**。

适合工作、学习、生活和业务中的判断与选择。你不需要先学会思维模型，也不需要会编程。这里的 **Skill（技能包）**，就是给智能体使用的一套工作方法和模型资料；你在自己的 AI 助手里与它对话，GitHub 页面用来下载和看说明。

## 第一次使用

### 1. 把技能交给你正在用的 AI 助手

**面向各种智能体用户，不需要使用 Codex，也不需要另装万维钢工具。** 不同产品的安装入口不同：有的能从链接安装，有的需要导入文件，有的只能在当前对话读取资料。先把下面整段话发给你的 AI 助手，让它检查自己支持哪一种：

```text
请帮我安装或加载“思维模型决策工具”：
https://github.com/sushengs-creator/thinking-model-decision/tree/main/skills/thinking-model-decision
先检查当前环境：能安装 Skill，就按本产品支持的方式安装完整目录；
不能安装但能读取文件，就指导我下载并提供完整目录，按本次会话加载。
不要把只打开链接、收到压缩包或读到 README 当作安装成功。
已有同名技能时，先备份并保留我的新增模型和修改。
完成后，请实际读取 SKILL.md、references/library-state.json 和一张模型卡，
告诉我加载方式、读到的版本及模型卡名称，并说明能否生成 HTML 文件。
如果缺少能力或需要我操作，请给出明确的下一步；不确定产品信息时先问我产品名和版本，不猜菜单或目录。
```

**看什么才算这一步完成？** 助手应说清“已安装”还是“仅本次加载”，报出实际读到的版本和一张模型卡，例如 `TM-077 可逆决策`。只回复“好的，我会了”不算确认。原生安装还应能在该产品的技能列表或实际安装位置找到；临时加载在新会话中可能需要重新提供资料。

如果助手不能访问链接，或你只看到上传按钮，直接看 **[下载、导入与附件加载步骤](docs/INSTALL.md#手动下载与加载)**。能聊天、能上传，不等于能解压和读取整个技能包；无法读取模型资料的环境可以做普通分析，但不能称为已使用本工具。

### 2. 复制这一句，换成你自己的困惑

完成上一步后，在**同一个 AI 助手**中发送：

```text
请调用 thinking-model-decision（思维模型决策工具）。
我最近在纠结：要不要开始一个新项目，但怕挤占本职工作的时间。
请每轮问我一个关键问题，等我回答后再继续；问题清楚后，给我 HTML 下一步行动计划。
```

只需替换第二行。不用先选模型，也不用一次讲完所有背景。如果你已经把材料讲清楚，可以直接说“根据这些材料给我报告”。如果产品有技能选择菜单，也可以从中选择 `thinking-model-decision`；自然语言请求本身不能替代技能加载。

### 3. 回答问题，让它帮你把决定想清楚

助手会根据你刚才的回答继续问，而不是一次发来一张长问卷。你可以说“不知道”“这一点还没确认”，也可以纠正它的理解。目标、限制和选项清楚后，就会进入分析，没有固定的提问轮数。

暂时不想继续回答，就说：**“先根据现有信息给阶段性报告，把未知写清楚。”** 想结束本轮，就说：“先暂停。”

### 4. 拿到报告，从第一步开始做

默认交付 **HTML 行动计划**，也就是一份用浏览器打开的网页文件。你会看到：当前建议、为什么这样选、其他方案的代价、谁在什么时候做什么，以及什么情况下应该调整。

助手有文件生成能力时，会给出实际文件或附件；下载后用浏览器打开即可阅读和打印。没有文件生成能力时，它应说明限制并提供完整 HTML 源码及保存方法；不方便保存时，你可以改要纯文本。**无需每轮都生成文件，也不用在分析结束后再要求一次“转成 HTML”。**

执行后，带着结果回到原对话说“请更新行动计划”；如果换了新对话，附上旧报告或结论摘要，再补充新情况。工具不会自动追踪你的进展。

## 操作示范

下面用“要不要报名数据分析课程”演示从困惑到行动的过程。**问答和报告均为编写的虚构教学示例，不是真实用户记录、实跑记录或效果证明。** 实际使用时，助手会等待你的真实回答。

### 先发出困惑

```text
请调用 thinking-model-decision（思维模型决策工具）。
我想学数据分析，已经看了好几门课，但一直决定不了要不要报名。
请一步一步帮我梳理，最后给我 HTML 下一步行动计划。
```

### 再逐轮回答

| 轮次 | AI 根据当前信息提问 | 示例使用者回答 |
|---|---|---|
| 第一轮 | 你希望学会数据分析后，先解决哪一件具体的事？ | 我每个月都要整理活动数据，希望能看出哪些活动值得继续做。 |
| 第二轮 | 你能稳定投入多少学习时间？ | 每周最多三小时。看中的系统课每周要八小时，暂时挤不出更多时间。 |
| 第三轮 | 除了报名系统课，还有什么可以先试的学习方式？ | 有一份免费短教程，可以拿往年的数据表跟着做。我有权用它练习，但还没试过，也没有必须现在报名的期限。 |

每行示意一轮问答；实际使用时，要等你的回答后才进入下一轮，不是把整张表示例发给 AI。三轮后，本例已经能明确：**如何在每周三小时内，开始改善活动分析。** 短教程是否合适、数据字段是否够用、学习后能否独立解释结果，仍然未知。

### 看模型怎样影响建议

本例用 **[TM-077 可逆决策](skills/thinking-model-decision/references/cards/TM-077.md)** 作主模型，将下一步限定为有时间上限的小任务，并承认已花掉的时间无法收回；用 **[TM-062 信息价值](skills/thinking-model-decision/references/cards/TM-062.md)** 补充，先想清楚试学要查明什么、不同结果如何改变下一步。

每周八小时超过三小时上限，是已有约束的比较。模型进一步改变的是行动安排：从反复搜课，转向一次能获得有用反馈、可以及时停下的尝试；没有可信数据，就不编造成功率或评分。

| 方案 | 本例中的判断 |
|---|---|
| 立即报名当前系统课 | 暂缓；除非核实课程可按三小时节奏推进，或可用时间改变，再重新比较。 |
| 短教程＋一个月报小任务 | 有条件优先；先检查资源，再尝试，准备、操作和复盘合计不超过三小时。 |
| 暂时维持现状 | 保留为基准；当前没有合适材料或时段时，可以先暂停。 |

### 拿到怎样的行动计划

**第一步：**下次可用学习时段，先检查教程的软件和付款要求、数据字段是否适合，再选一个月报中的小问题。条件具备才开始；到时间上限就停，记录结果、用时和卡点。

随后区分：能独立解释结果，可以继续检验这条学习路径；只能照着做，就处理具体理解缺口；缺材料或权限，先补条件。一次练习成功也不证明每周八小时的课程适合自己。

查看 **[本案例的完整 HTML 报告](docs/examples/learning-decision-demo.html)**。GitHub 文件页通常显示源码，使用该页的 **Download raw file（下载原始文件）** 保存为 `learning-decision-demo.html`，再用浏览器打开。正文可离线阅读；这是示范成品，你的实际报告会按你的情况生成。

### 带着结果回来更新

假设本周试过后出现下面的情况，在原对话发送：

```text
请继续使用 thinking-model-decision，更新刚才的 HTML 行动计划。
我本周试了两小时，能跟着教程做出汇总表，但不能独立解释计算口径。
每周仍然只有三小时。请说明哪些判断改变了、哪些仍成立，保留旧版，再给下一步安排。
```

助手应把“能照做”与“独立理解不足”分别记录，调整下一步练习，而不是从头重问。每周三小时的限制仍成立，本周后续最多再用一小时。示例结果也是虚构的；你使用时填入自己的实际记录。

## 日常使用时可以直接这样说

| 你现在需要什么 | 发给 AI 的话 |
|---|---|
| 从困惑开始 | “用思维模型决策工具帮我梳理，先一步一步问我。” |
| 比较方案 | “我有 A、B 两个方案，先澄清目标和限制，再比较。” |
| 材料已经充分 | “这些是背景、目标和限制，请直接给行动计划。” |
| 暂时无法补充 | “先给阶段性报告，把未知和条件写清楚。” |
| 修改建议 | “情况变了：……请更新受影响的判断和 HTML 报告。” |
| 复盘 | “这是上次报告、实际行动和结果，请区分判断、执行和环境变化。” |
| 暂停或只想倾诉 | “先暂停分析，我现在只想讲讲。” |

通常选一个主模型和少量必要补充，解释它们改变了什么；不要求一次跑完全部模型。最终目标排序与选择由你决定，模型不能替代事实核实或专业判断。详细规则见 [使用指南](docs/USAGE.md)。

## 遇到问题，先这样处理

| 看到的情况 | 下一步 |
|---|---|
| “无法安装”、找不到技能入口 | 按 [三种加载路径](docs/INSTALL.md#选择加载方式) 判断能否导入或临时读取；不要反复发送同一句安装口令。 |
| 已说安装成功，却答不出模型内容 | 用 [加载检查](docs/INSTALL.md#确认是否可用) 实际读取入口和模型卡；必要时按产品提示重新启用或加载。 |
| 只得到聊天文字，没有 HTML 文件 | 问它是否具备文件或附件生成能力；具备则要求实际保存，否则用源码或纯文本交付。 |
| 新对话不记得旧决定 | 附上旧报告或摘要；如果上次只是临时加载，还需重新提供技能资料。 |
