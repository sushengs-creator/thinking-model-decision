# 从问题找到可用模型

这张表用于不知道模型名称、或一个问题横跨多个阶段时。先定位当前最阻碍行动的一步，再读少量候选卡和 WW 条目；不是按表从头跑到尾，也不要求每行两个来源同时出现。完整模型覆盖在 user-catalog.md 与 wan-catalog.md。

| 当前问题与需要的交付 | 用户模型候选 | 万维钢候选 | 选型关键区别 |
|---|---|---|---|
| 不知道究竟要决定什么，目标相互冲突 → 可回答的问题、约束和取舍 | TM-064 机会成本、TM-076 有限理性、TM-103 MECE | WW-9.7 立题、WW-9.2 目标函数 | 先澄清用户重视什么；分类完整不等于题目正确，也不能替用户决定价值排序。 |
| 一条新闻、一位专家或一次失败左右判断 → 证据与反证 | TM-001 易得性、TM-002 确认性、TM-030 权威偏误、TM-048 主动开放思维 | WW-3.11 选择偏差、WW-2.9 认知解耦 | 偏差卡用来检查资料和判断过程，不凭行为给人贴标签；有情绪不等于判断必错。 |
| 有几种可能原因，急着干预 → 竞争解释与区分证据 | TM-050 竞争性假设、TM-056 反事实因果、TM-104 溯因推理 | WW-3.3 颗粒度与因果中介 | 解释最顺不等于已证明；先找能区分假设的证据，再决定干预。 |
| 工期、成功率或结果不确定 → 有条件的预测 | TM-053 基准率、TM-054 贝叶斯、TM-073 参考类预测、TM-051 校准 | WW-3.14 参考类预测、WW-3.15 超级预测 | 可比历史约束故事；样本频率不能直接变成当前事件的精准概率。 |
| 还要不要调查、咨询、等待 → 信息取得与停止条件 | TM-062 信息价值、TM-067 停止规则 | WW-3.5 信息价值 | 信息必须可能改变行动且来得及使用；没有可靠数字可定性比较，不凑收益表。 |
| 几个方案都不错，资源不够 → 方案差异与阈值 | TM-057 期望值、TM-064 机会成本、TM-065 边际成本、TM-105 敏感性 | WW-8.6 边际分析、WW-1.4 硬约束 | 比较未来增量与放弃的替代项；平均收益不能覆盖无法承担的损失。 |
| 想加码但怕回不了头 → 投入范围、底线和退出安排 | TM-058 安全边际、TM-063 期权、TM-077 可逆决策、TM-080 非遍历性 | WW-3.7 非遍历性、WW-3.9 期权 | 可撤销不等于无损；算出正期望也不等于用户承担得起。 |
| 指标变好但业务没改善 → 测量口径和替代行为 | TM-071 测量、TM-074 古德哈特、TM-100 委托代理 | WW-7.5 古德哈特、WW-7.7 委托代理 | 先查指标测的是什么，再查奖惩是否改变了行为；不先把动机当事实。 |
| 越努力越反弹、整体不提效 → 系统结构与干预点 | TM-082 存量流量、TM-083 反馈、TM-084 延迟、TM-085 瓶颈、TM-092 复杂适应系统 | WW-8.4 反馈回路、WW-3.10 状态杠杆 | 一次性因果链、存量积累、闭环、延迟和瓶颈不同；只选当前证据支持的机制。 |
| 合作各自合理却整体失灵 → 行动条件与激励安排 | TM-097 信息不对称、TM-098 道德风险、TM-100 委托代理、TM-111 共同知识、TM-112 协调博弈、TM-113 囚徒困境 | WW-6.3 激励相容、WW-6.9 共同知识 | 缺信息、缺共同确认、利益冲突或执行权不足是不同问题；不能一律要求加强沟通。 |
| 学过却做不出、投入时间没进步 → 可观察能力与练习 | TM-106 认知负荷、TM-115 ICAP、TM-118 刻意练习、TM-120 迁移、TM-121 元认知 | WW-4.1 认知负荷、WW-4.3 刻意练习、WW-4.10 拥抱与桥接 | 先区分任务超载、练习方式、反馈和迁移；不能把不熟练全部归为动力不足。 |
| 亲手跟做却只记步骤，换条件就失灵 → 操作—反馈—关系与变式检查 | TM-126 具身认知 | WW-4.7 可取的困难与具身认知、WW-4.2 ICAP；操作过载时查 WW-4.1 | 检查动作线索是否参与理解；缺新知识先补知识，动作不合适可用图示/讲解。正常工具保留，多次及延迟表现检验，不把一次成败当定论。 |
| 看演示时懂，独立做卡住 → 示范、保留、操作与条件的检查 | [TM-127 观察学习](cards/TM-127.md) | WW-4.1 认知负荷、WW-4.2 ICAP、WW-4.6 默会知识 | 先定位一个卡点；没表现不等于没学到，会做但无权限先处理条件，不强制重看全部教程。 |
| 当场改对，换题又沿用旧解释 → 解释比较与条件检验 | [TM-128 概念转变模型](cards/TM-128.md) | WW-4.4 心智模型、WW-3.4 贝叶斯先验 | 四条件不是固定阶梯；先核实证据与题目目的，不把不同意或执行受阻当作观念顽固。 |
| 人离开后文档接不住，专家答案对不上 → 知识定位、取得、核实和组合 | [TM-129 交互记忆系统](cards/TM-129.md) | WW-7.2 组织资本、WW-4.6 默会知识、WW-6.9 共同知识 | 联系人名单不是完整系统；用一次真实任务检查交接，缺知识、权限或预算分别处理。 |
| 复盘总改做法却不讨论标准 → 检验支配行动的规则 | [TM-130 双环学习](cards/TM-130.md) | WW-9.3 二阶意愿与元表征、WW-7.9 基线漂移 | 重复失败不证明规则错；先处理眼前风险，分开验收新规则被采用和采用后的效果，尊重修订权限。 |
| 合书讲不清或讲得顺但未经核对 → 独立解释、回查与变式 | [TM-131 费曼学习法](cards/TM-131.md) | WW-4.2 ICAP、WW-4.7 可取的困难与具身认知、WW-4.1 认知负荷 | 独自书写也可开始；外行点头不是准确性证据，表达卡壳不直接等于不懂，操作技能需实际练习。 |
| 提醒响了仍不行动，准备太费劲 → 一次机会中的提示、能力和动机 | [TM-132 福格行为模型](cards/TM-132.md) | WW-2.7 WOOP、WW-2.4 自我决定 | MAP不是概率公式；先找具体可调整条件，目标是否认可仍由用户决定，开始与成果分别验收。 |
| 目标认可却没开始、下一步过大 → 可执行行动与能力路径 | TM-122 自我决定、TM-123 WOOP、TM-125 相邻可能 | WW-2.4 自我决定、WW-2.7 WOOP、WW-5.5 效果推理 | 先确认目标是用户认可的；分别处理外部条件、内在障碍和当前能力。 |
| 多个办法可以反复试 → 探索分配及反馈窗口 | TM-124 多臂老虎机、TM-067 停止规则 | WW-2.14 探索与利用 | 反馈能否赶上下一次选择，选项是否可比，剩余机会是否足够；重大一次性决定不能直接套算法。 |
| 结果出来了，想知道该改什么 → 预测—过程—结果复盘 | TM-068 决策结果分离、TM-069 运气技能、TM-051 校准、TM-055 回归均值 | WW-3.12 回归均值、WW-3.15 超级预测 | 保留事前判断，区分信息质量、选型、执行和运气；单次成功不能验证整个模型。 |

这是编辑形成的召回路线，不是证明条目同义的映射。命中候选后用 `library.py show TM-编号` 查看状态、卡片路径及已经比较过的跨库关系；必要时返回原文。当前机制没有可用证据时，保留竞争解释，而不是补齐一个看起来完整的模型组合。

## 超出上述快捷表时

两套库都参与检索。没有合适 TM 候选时，可以直接以 WW 工具为主，不必先找一个 TM 配对。万维钢完整目录分成世界观、成长、决策、学习、商业、社会、组织、复杂性、价值反思和探索十个板块，共100条；以下补充入口尤其适合不在原快捷表中的问题。

| 问题信号 | WW 候选 | 先检查什么 |
|---|---|---|
| 在自制与采购之间争论，或创造价值却留不住收益 | WW-5.6 沃德利地图、WW-5.1 经济租、WW-5.2 阿尔法 | 哪些能力已通用化，哪些差异服务用户；创造价值与捕获价值不是一回事 |
| 讨论事实时不断变成人身防御，合作关系受损 | WW-6.1 地位、WW-6.2 礼、WW-6.14 第三物 | 区分事实、利益、身份和互动协议，不擅自断定动机 |
| 授权后仍凡事上报，流程写全却依赖某个人 | WW-7.1 剩余判断权、WW-7.6 指挥官意图、WW-7.8 智件 | 决策权、目标边界、信息反馈和可复用流程是否匹配 |
| 旧系统不能停，改革越改越乱 | WW-8.7 路径创造、WW-8.8 适应性循环、WW-6.12 慢变量 | 是否需要保留旧系统、逐步引流；系统状态与长期信用怎样改变 |
| 外在成绩不错却不认同生活方向，或追问留下些什么 | WW-2.15 共鸣、WW-9.3 二阶意愿、WW-100 探索和生发 | 用户自己的价值、责任与愿意投入的方向，不替其设定终极目标 |

需要进一步设计流程或组合角色时，读 [整体运行框架](wan-framework.md) 的对应任务段落。查找上述候选及其余全部条目使用 [100工具目录](wan-catalog.md) 或 `library.py search '用户的问题或工具名'`；用 `show WW-编号 --full` 读取原条目的调用条件、机制、程序和边界。快捷表只提供入口，不限定可选工具范围。
