周衡想学陶艺，想了大半年了。

家附近的工作室开了初学者体验课，周末下午，两个半小时，费用在他的预算之内。那个页面他早存进收藏夹，隔几天点开一次。他跟妻子说，自己就是想看泥在手里慢慢转，最后转成一个杯子的那种感觉。

第一期开放报名，表格填到一半，念头冒了出来："别人肯定比我做得好。要是只有我的杯子塌了，会不会很尴尬？"他关掉页面，去看教学视频。连看两个，心里轻松了一点。报名的事也搁下了。

第二期开放报名，同样的过程又来一遍。

到了第三期，他已经能给自己讲道理了："第一次做不好很正常，这课本来就是给初学者的，谁第一次拉坯不是塌的？"他还搬出一个同事当例子。那同事学吉他，头一个月弹的都是噪音，现在也能弹完整首曲子了。

道理他都懂。理由找得越顺，他越觉得自己不是在害怕，是在理性地看待这件事。

可他最后还是关掉了页面。

同一个页面，他为什么关掉了三次？

周衡心里有一句没说出口的话。等我不那么紧张了，我再开始。

他把感受设成了报名的前提。只要紧张还在，报名就继续往后排。

在接纳与承诺疗法（Acceptance and Commitment Therapy，简称 ACT）中，心理灵活性指的是：觉察当下的想法、感受和实际情况，并能为了自己重视的方向，坚持或调整行动的能力。这套框架来自美国内华达大学的史蒂文·海斯（Steven C. Hayes）等人。

这里的"觉察"，不是先看清楚、再想办法把它弄掉。那些想法和感受可以就留在那儿，人照样往下走。推开的动作不算觉察，它属于另一件事。

这里面最容易被忽略的一点，是"感觉不好的时候也能行动"。往好的方向行动，人人都会说；难的是感觉不好的时候也得动起来。

放到周衡这件事上，就是紧张还在，他仍然可以判断。这门课适不适合初学者？时间和费用能不能承担？自己是否愿意试一次？

条件允许，他就可以带着紧张报名。条件不允许，他也可以调整安排。这个判断的权力在他手上，不在那份紧张手里。

"等我准备好了"，这一天为什么一直没来？

准备当然有用。课程不适合初学者、周末没有时间、身体太累，都可能是暂缓的充分理由。

问题出在另一种情况：现实条件已经允许，但"准备好"始终等于"我得先感觉有把握"。

你可以决定周三晚上打开报名页面，却很难保证自己到那一刻一定不紧张。查资料、休息、找人聊聊，都可能改善感受，但不一定能把不确定感彻底消除。

于是就出现了一个很难受的局面：行动的开关，装在一个你按不到的地方。

类似的说辞，换个场景照样成立。

想跟父母好好谈一次，但"等我这段时间状态好一点再说"。

想开始运动，但"等这段忙完了有精神了再去"。

这些说辞背后是同一条规则。前半句是个感受，后半句是件事。感受没到位，事就不办。

麻烦就在这里。它不像一句明显的逃避，因为"准备"这两个字听起来特别正当。没人会觉得自己在逃避，他只会觉得自己在打基础。

周衡每次关掉页面，眼前都轻松了一点。这种轻松如果让他下次一紧张就再关一次，这个动作就会越做越顺。而"做不好会尴尬"这个担心，从来没有被真的检验过一次。倒是"关掉页面能舒服一点"这件事，一次次被证实了。

这也解释了为什么讲通道理以后，人仍可能不动。周衡已经接受了"初学者做不好很正常"，那个担心被推翻了一半，却还守着更深一层的规则：即使做不好很正常，我也得先不紧张，才能去做。

要判断自己是在准备还是在原地等待，可以追问一句：这次准备具体补上了什么，补到什么程度就能开始？看视频学会一项课堂需要的基本操作，是准备。反复看同样的视频，只为压住每次报名前的紧张，始终没有下一步，就需要换个办法了。

念头一出现，为什么就成了必须照办的指令？

事情卡住的时候，大多数人第一反应会往逃避上想。就是不敢面对，就是躲，就是拖延。这个理解不算错，可惜不是最要紧的那一层。心理治疗师路斯·哈里斯（Russ Harris）在《ACT就这么简单》里写过一句很直接的话。他说很多新手治疗师会以为经验性回避是 ACT 里的头号问题，其实不是。头号问题是认知融合。

这两个词听着像套话，说的却是两件不同的事。

经验性回避，说的是动作的目的。你去做一件事，或者不去做一件事，图的是躲开、减轻或者消除某个不想要的念头和感受。不敢上台，就不上台；怕被拒绝，就不开口问。判断一个动作算不算经验性回避，不看它表面上是什么样子，也不看别人看不看得见，要看的是它冲着什么去，是不是为了把某种感受推开。

认知融合，说的是念头的位置。念头被当成了事实，人照着它办事，却没察觉自己在照它办事。念头说"你不行"，你把它当成关于自己的结论；念头说"别人会笑话你"，你把它当成关于别人的预测。你不是在躲什么，你是在按自己认定的事实办事，而那个"事实"，本身只是一个念头。

周衡第三次关页面，包含了这两种状态。他为了把紧张推开而关掉页面，这是经验性回避。他把"我会做不好"直接接成"所以现在不能报名"，这是认知融合。而且他未必不知道自己怕。他清楚自己紧张，只是在他看来，这份紧张不用先处理，照常判断时机就行。

认知解离，说的是你和念头之间的距离。你能注意到自己正在产生一个念头，听见它，再决定怎样回应。哈里斯给了一个很利落的说法：解离意味着你能灵活地回应你的认知，这样它们就只能影响，但无法支配你的行为。

它没说念头不重要，也没说念头都是假的。念头照样能让你心里一沉、手心出汗。它拿掉的只有一样东西，就是念头下命令的资格。

打个比方。走廊的火警响了，喊的是"着火了"。

认知融合是，你根本没听出那只是警报器在响，你已经认定屋里真的着火了，抓起外套就往外冲。

认知解离是，你先听出那是警报器在响，再决定去厨房看一眼、直接下楼，还是判断这是误报。三种反应都可能是对的。区别不在你跑得多快，在你有没有先听出那只是警报。

解离听起来像要先打赢一场仗，其实不用跟念头较劲，也不必靠意志力硬撑。哈里斯在《幸福的陷阱》里给了个现成的法子，简单到有点意外。就在那个念头前面加一句"我注意到，自己正在想"。"别人会笑话我"，变成"我注意到，自己正在想：别人会笑话我。"

念头的内容还在，但这句话提醒周衡，他正在作一个预测，接下来可以看具体情况。课程介绍写得含糊，就去问工作室；已经确认它面向初学者，那就接着判断自己愿不愿意接受第一次做得不好看。它换的是念头的位置，从"事实"退成了"想法"，内容没动。

这个练习不保证马上减轻紧张，也不要求你认定念头是假的，更不适合拿来打发别人的难受，或者回避现实问题。需要核查的事实仍然要核查，只是念头出现以后，行动不必立刻跟着走。

这里要澄清一个常见的误解。很多人以为 ACT 是不改变想法的，练到最后就是认了、躺平了。哈里斯专门反驳过这个印象。ACT 确实会改变想法，只是不走挑战、争论、反驳那条路，而是靠解离、接纳，加上主动去培养新的思维方式。它改的是你和那句话的关系。

除了与念头拉开距离，还能从哪里入手？

心理灵活性模型包含六个相互关联的过程。把它们放回周衡的处境，就容易理解了。

| 过程 | 放到这件事里，可以怎么理解 |
| --- | --- |
| 接纳 | 注意到紧张，允许这份感受存在，不急着先消灭它。 |
| 认知解离 | 听见"我会出丑"的念头，仍然查看实际条件，再决定怎么做。 |
| 当下觉察 | 从脑中的尴尬画面回到眼前。此刻只是在填一张报名表。 |
| 自我即情境 | 退后一步，看见自己正在紧张，不让"我就是个胆小的人"概括全部的自己。 |
| 价值 | 弄清楚自己想怎样学习、创造和安排业余生活。 |
| 承诺行动 | 采取与这个方向相符的具体行动，并根据情况继续或调整。 |

这张表真正值得看的地方，是它把六个"好"的过程和六个"卡住"的样子配得整整齐齐。接纳对面是经验性回避，解离对面是融合，当下觉察对面是活在反复回放的过去和预演的将来，自我即情境对面是自我即内容，价值对面是价值不清，承诺行动对面是无效行动。僵化就是六个过程各自被卡住的一种形态，跟能力高低、性格好坏没关系。

"自我即情境"这个名字最拗口。它说的就是那个"退后一步"的位置：你能注意到自己此刻的想法和感受，也能发现它们正在变化，不必把其中一个念头当成关于自己的最终结论。它就是一个视角，不是藏在里面的神秘真我。认知解离里的"解离"也要分清，它跟临床上的"解离"不是一回事，后者指的是人格解体那类症状。

从故事里能看到的，他主要卡在前两行。有那个紧张的感受，不许它存在，想先把它弄掉，这是第一行。把"我还没准备好"当成事实照办，这是第二行。后面几项故事里没有给材料，不硬判断。这个区分有用，因为"我这个人不行"是个改不动的结论，"我卡在第二行"是个有具体位置的问题。

这六个过程可以归为三组：开放（接纳、认知解离）、觉察（当下觉察、自我即情境）、投入（价值、承诺行动）。它们没有固定的练习顺序。对周衡来说，先看见"我必须不紧张才能去"这条规则，就已经找到了一个可以尝试的入口。

暂时躲开，怎样判断是在休息还是在耽误自己？

回避本身不必受到责备。争执时先暂停，疲惫时休息，难过时听会儿歌，都可能帮人恢复。《幸福的陷阱》原书里有一句话说得更直接：低水平的经验性回避很正常，不构成问题。

值得检查的是，这种应对是否长期有用。它有没有逐渐占去太多时间和精力，让你放下了自己原本重视的事？

参考 ACT 对行为效果和代价的关注，可以整理出四个复盘问题。

1. 我这样做，当下得到了什么帮助？

2. 过一段时间再看，我原来担心的问题，有没有变好一点？

3. 它花掉了多少时间、精力，带来了什么其他代价？

4. 它让我更靠近自己重视的生活，还是让我一次次把这件事往后排？

第四问说的"重视的生活"，可以借一个画面来分辨。一位母亲带两个孩子去动物园，车程两小时。一个孩子一路坐卧不安，不停抱怨怎么还不到。另一个孩子一路看窗外的风景，一点都不烦。到动物园是个目标。只盯着目标的人，心里跟着目标患得患失。把目标当成路标的人，路上就已经在过他想过的日子了。

拿周衡走一遍：看视频让他暂时松了一口气，可到了下一期，他还是不敢报。大半年惦记着这件事，错过了三次报名。这足以让他考虑换一种应对，不必先证明所有准备都没用，也不必责怪自己连一个课都报不了。

还有一层机制值得细说。为什么越不许自己想，那个念头越容易回来？

心理学家丹尼尔·韦格纳（Daniel Wegner）1987 年做过一个实验，让人唯独不能想一只白熊，结果不许想的那几分钟里，白熊反而更容易冒出来。ACT 科普里也常打另一个比方：陷进流沙里，本能是挣扎，可越挣扎陷得越快。两个比方说的是同一件事，卯着劲要把某种感受推开，那个感受反而占了更多位置。

这个实验看的是"压住某个念头"，不能推广成"所有难受的感受越调节越糟"。累了就休息，难过就找人说说，这些都正常。哈里斯也明确讲过，经验性回避常常是个问题，但并不总是问题。

想做成一件事，为什么也要允许自己调整或退出？

价值说的是，你愿意持续怎样做事、怎样生活。"做出一个杯子"是目标，完成后可以打钩；价值是一直朝东走，走了多远都还能继续往东。

如果周衡重视的是"保持好奇，亲手学习和创造"，那么做杯子是实践这个方向的一种方式。杯子做好了，仍可以继续学；这家工作室不合适，也可以换地方。不过"我想看泥在手里变成杯子"只能当追问的起点，不能替他决定他重视什么。

ACT 所说的"承诺行动"，就是在价值引导下采取有效行动，包含坚持，也包含依据反馈改变做法。这个词容易被听成"下定决心，坚持到底"。哈里斯的说法不是这样。他说承诺行动意味着灵活的行动，做好准备去适应情况的变化，按照需要坚持，或者改变。这句话把硬撑从唯一正确答案的位置上拿了下来。

日常选择里，大致有五种做法。判断看的是条件和代价，不是勇气。

| 做法 | 判断时可以看什么 | 可以直接说的一句话 |
| --- | --- | --- |
| 继续 | 事情仍值得做，条件允许，代价可以承担。 | 我知道我会紧张，那就带着紧张去试一次。 |
| 调整 | 方向仍然重要，但课程、时间或参与方式需要改变。 | 方向不变，我先换个更短的方式试一试。 |
| 暂缓 | 当下需要休息、处理更急的事或补足条件；可以约定何时再看。 | 这一期时间不合适，我定个日子再看下一期。 |
| 求助 | 缺少必要的信息、技能或支持，需要向老师、朋友或专业人员求助。 | 这一块我自己摸不出来，得找人问清楚。 |
| 退出 | 这门课不合适、代价过高，或自己已经不想继续。 | 我试过了，这条路不合适，我把时间放到别处。 |

这五条是并列的，没有哪一条比别的更勇敢。也不能只凭名字判定对错。继续可能出于兴趣，也可能只为证明自己不胆小；暂缓可能是在恢复精力，也可能是又一次没有期限的等待。害怕也不自动否定退出的理由，一个人可能既害怕，又确实疲惫、负担过重，或者不喜欢这件事。

接纳内在感受，不等于接受伤害自己的处境。

哈里斯在书里说得很硬。接纳是"经验性接纳"的简写，意思是接纳我们的个人体验，想法、感受、记忆这些，不是被动地接受我们的生活情境。

这两件事差得很远。心里紧张，可以允许它在那儿。但老板长期压榨、合同明显不公、身体确实有病，这些是要去改的，不是要去接纳的。还有一条更细的分寸：不是每一个不想要的想法和感受都要接纳，只有当经验性回避挡在了有效的、朝着价值方向的行动前面时，才谈接纳。面对不公、危险或资源不足，需要处理外部问题。心理灵活性可以帮助人带着担忧去沟通、求助或离开，但不能替代这些行动，更不能成为别人要求你顺从的理由。

轮到自己时，可以怎样走完一次？

下面五步，是本文为日常小事整理的练习流程，不是 ACT 的标准治疗程序。

第一步，把困扰缩成一件具体的事，先查现实条件

把"我总是行动不了"，改成"周三晚上八点前，决定是否报名周末的陶艺体验课"。核对课程、时间、费用和身体状态。条件确实不允许，就先处理条件。

第二步，写下念头、感受，以及自己实际做了什么

念头："别人会比我做得好，我做坏了会很尴尬。"感受："紧张，想赶快关掉页面。"行动："关页面，看教学视频。"分开写，能看清这次应对的过程，而不只给自己一个"我又拖延了"的评价。

第三步，用四问看效果，再问自己为什么想做

把前面那四个问题过一遍。周衡的答案是，看视频的短期作用是减轻紧张，长期却没有帮助自己参加课程。他还需要确认：如果不要求第一次就做得好，自己是否仍然愿意动手学？假如答案是否，就重新考虑这件事。

第四步，选一个有帮助的练习，配一个具体行动

如果仍然想去，可以先试着说："我注意到，自己正在担心做不好。"然后把注意力放回眼前的报名表。行动写成"周三晚上八点前，提交这次体验课的报名表"；如果还缺关键信息，就改成"今天问清楚初学者能得到哪些指导"。不必等这句练习让人舒服了，再做下一步，否则"我必须先解离成功"又成了新的等待条件。

第五步，看实际反馈，再决定继续、调整或停止

回看三个方面。自己有没有做出有意义的尝试，实际代价能否承受，得到了哪些会影响下一次选择的信息。报名后仍紧张，不足以说明练习失败。上课后发现老师不指导，也不必为了证明勇敢继续报名。

如果练过以后仍然没行动，就回头看看。是否遗漏了现实困难，定的动作是否太大，是否需要别人支持？可以缩小动作、补足条件，或者重新考虑这件事，不必再用"我连这个也做不到"责备自己。

周衡可以把这次练习记成一张卡：具体事情和条件、念头与感受、习惯性应对、短期效果与长期代价、自己重视什么、下一步、事后回看。不用天天填，挑一件反复卡住的事填一次，就够看清很多东西了。

做出杯子，可以成为进展，却不能单凭这个结果判断一个人是否更灵活。假设周衡到了课堂，始终只顾着藏起紧张，遇到不会的地方也不敢提问。课虽然上了，学习仍受到"绝不能显得紧张"这条规则的限制。反过来也一样，换一个版本的周衡，他注意到这条规则，愿意向老师问一句，哪怕杯子依旧做塌了，这次行动也可能更符合他想认真学习的方向。

一项研究能说明什么，又不能说明什么？

2023年，澳大利亚纽卡斯尔大学的伊丽莎白·迪顿（Elizabeth Ditton）和同事发表了一项医学生研究，评估为期五周的 ACT 技能训练 App。

这项研究招了143名医学生，按1:1:1随机分入个性化训练、非个性化训练和等待名单三组。研究主要考察倦怠中的"耗竭"，即感到精力被耗尽。比较各组训练前后的变化，没有发现两个训练组相对等待名单在这一指标上有统计显著的差异。

个性化组的 P 值为0.75。

所谓统计显著，是说这次的数据能把观察到的差别和随机波动区分开。这次没能区分开。这意味着数据还不足以支持训练改善了这一指标的结论。它也不能反过来证明训练真的没有作用。

部分次要结果有改善，例如个性化组的心理灵活性、两个训练组的压力指标。这几个指标在研究开始前就计划测量了，但不是主要结局，论文把它们列为探索性分析，还需要更多研究确认。

研究总流失75人，占最初143人的52.4%。较高的流失率和有限的样本，都要求谨慎解释结果。作者把它视为潜在益处的早期证据，仍需更大样本和更长随访。

还有一句要说清楚。这项试验检验的是那个 App，不是本文的五步练习，两者不能直接对等。它也不能代表 ACT 所有应用的效果。持续或明显影响生活的困扰，需要寻求专业评估和支持。

下一次紧张还在，你准备怎样决定？

回到周衡的故事。第四期报名时，他还是紧张，也还是担心自己做不好。这一次，他重新看了课程安排，确认条件允许，也确认自己确实想去试试，然后提交了表格。

到了课堂，杯子塌了。他问老师哪里没掌握好，又试了一次。杯子依然歪，但他已经开始学习了。

这个假设故事想说明的变化很小。他允许紧张留在这次体验里，不再要求自己先把它处理干净。

心理灵活性模型提醒我们一件事。卡住人的，常常不只是那个难受的感受，还有"必须先把它处理掉，我才能行动"这个前提。这个前提不写在任何地方，却一直在替人签字。

下次发现自己又在等"状态好一点"时，可以先问：我缺的是必要的条件，还是希望所有不舒服都消失？条件有缺口，就去补条件；如果事情仍然值得做，风险和代价也能承担，再问一句：紧张还在，我现在愿意迈出哪一步？




模型档案卡

模型名称

心理灵活性模型（Psychological Flexibility）

一句话定义

注意当下的想法、感受和外部条件，为自己重视的方向，坚持或调整行动的能力。

来源

美国内华达大学的史蒂文·海斯等人发展的接纳与承诺疗法（ACT），本文用的是其中的六过程框架；通俗解释引自心理治疗师路斯·哈里斯的《ACT就这么简单》和《幸福的陷阱》。

核心功能

把"等我不难受了再行动"这个隐形前提翻出来，看看它是不是必须的。

调用提示

卡住时先问一句，我缺的是必要条件，还是希望不舒服的感觉先消失？

适用情形

条件允许却迟迟不动；反复准备却始终没有下一步；分不清是在休息还是在拖。

使用边界

不把每次休息、准备和退出都算作回避，也不凭一次成败判断灵活与否。接纳内在感受不能替代改善不公、危险和资源不足。
