# 思维模型127：观察学习——同事演示时你看懂了，回到工位为什么还是不会做？

同事给你演示了一遍数据透视表的操作。你站在旁边看着，每一步似乎都跟上了，觉得挺清楚。回到自己工位，打开同样的文件，却突然拿不准该先点哪里。

刚才明明看懂了，怎么自己一做就卡住？

也许是步骤没记牢，也许是不熟悉软件，还需要多练几次。不过，在重新看教程之前，可以先想想：刚才那次演示，你到底记住了什么？是具体的操作，还是只留下了“看着挺简单”的印象？

## 自己做不出来，刚才的示范就白看了吗？

1965年，斯坦福大学心理学家阿尔伯特·班杜拉（Albert Bandura）做了一个实验。

三组幼儿观看了成人攻击充气玩偶的影片。攻击动作相同，结局却不同。一组看到大人受到奖励，一组看到大人受到惩罚，第三组什么后果也没看到。

看完影片，孩子们被带到放有同样玩偶的房间。研究者发现，看到大人受罚的那组，主动模仿攻击动作的孩子，明显少于另外两组。

随后，研究者告诉所有孩子，只要把影片中大人的动作展示出来，就能得到奖励。这一次，原先的组间差异不再显著。

这个结果提示我们，先前较少做出动作的孩子，可能已经记住了那些动作。有没有学到，不能只看他们是否主动做出来。

回到工位上的困惑也需要这样拆开。孩子没有主动做，你可能想做却做不出来，两种情况的原因不同，但都提醒我们：仅凭眼前的表现，还不足以判断学到了多少。

观察学习，是通过观察别人的行为，学到做法、规则或判断。其中最容易被忽略的一点是：**从示范中学到了什么，与后来是否做得出来、是否愿意去做，需要分别检查。**

我们把这个定义拆开来看，有三层意思。

第一层，“学到”不等于“自己做过”。你看到同事怎么操作，脑子里可能已经记住了步骤，但手还没有动过。学到的是信息，做出来是行动，中间隔着好几道关。

第二层，“做不出来”不等于“没学到”。就像那些看到大人受罚的孩子，他们可能记住了动作，只是没有表现出来。你回到工位上卡住了，也可能只是缺了一个提示、一次练习，或者一个使用的理由。

第三层，“学到什么”和“学到多少”也需要分开。你可能记住了步骤，但没有记住步骤背后的理由；你可能看清了操作，但没有注意到同事每次都检查数据类型这个习惯。学到的东西不同，能迁移到新任务上的程度也不同。

## 回到工位卡住了，先查哪儿出了问题？

班杜拉用四个过程解释观察学习：注意、保持、行为再现和动机。名字听起来有些抽象，放进刚才的场景就容易理解了。

**注意**，要看你有没有留意到有用的信息。同事把哪个字段拖到了哪个区域？他切换数据源时，你看到了吗？有时我们一直盯着屏幕，却只注意到最后表格变了，漏掉了中间的操作。看见演示，并不等于看清了关键步骤。

**保持**，要看离开示范后，你还记得什么。比如，你能不能说出先点“插入”，再选“数据透视表”，接着把日期字段拖到行区域？当时跟得上，离开后却想不起具体步骤，就需要检查记忆。能说出流程和能解释操作理由，也要分开来看。

班杜拉与同事的研究发现，把操作步骤转成语言描述并及时复述，有助于记住。身体练习对记住步骤本身帮助不大，但对操作熟练度另有价值。

**行为再现**，要看你能不能照着记住的内容完成操作。说得出“插入透视表、拖放字段”，打开软件后却找不到按钮，仍然会卡住。你可以暂时放下口头解释，从头做一次，记下停在哪一步。接着再查：是步骤记得太粗，还是已经知道该怎么做，但操作还不熟练。

**动机**，要看你觉得使用这套方法会带来什么。它能省时间吗？切换起来是不是很麻烦？出了错，会不会被批评？即使已经会做，这些考虑也会影响你是否采用新方法。班杜拉讨论的动机包括预期的奖励、惩罚，以及做完后如何评价自己。它还可能影响你一开始愿不愿意认真看、看完后愿不愿意复述，并非只在最后才起作用。

这里已经从“想做却做不出来”，扩展到了“会做却没有使用”。还有一层要单独查：外部条件。没有数据权限，或手头根本没有相关任务，都可能让一个想用新方法的人暂时用不上。环境限制和使用意愿，需要分开处理。

四个过程彼此有联系，但检查时可以分开看。下面把它们整理成五个自查问题。

## 拿不准字段往哪拖，怎么补上这一步？

可以用下面五问检查。前四问对应班杜拉的四个过程，第五问检查外部条件，这一问在职场中尤其重要。

第一问，我看清了哪些关键步骤？有没有漏掉重要操作？

第二问，离开示范后，我还能说出哪些步骤和判断依据？

第三问，我能独立完成操作吗？具体卡在哪里？

第四问，我愿不愿意用？我觉得用了以后会怎样？

第五问，我有条件用吗？有没有相应的权限、任务和时间？

不用每次把五问全部走完。先独立试一次，看你在哪一步停住，就从对应的那一问开始查。

把开头的场景继续往下推。他回到工位，尝试独立创建透视表。创建完成后，要拖放字段了，他却拿不准该拖哪个、放在哪里。

他独立试了一次，卡在字段拖放这一步。这对应第二问“还记得哪些步骤”。他关掉文件，回忆刚才的操作。他记得要点“插入”、选“数据透视表”，说到字段时，却只记得“好像拖了日期”，想不起放在行区域还是列区域。

至少有一个具体问题找到了：字段位置没有记清。他请演示的同事再做一次，重点看这一处。同事说明任务是按月份汇总销售额，把日期字段拖到行区域，再按月份分组，把金额字段拖到值区域。他边看边复述，确认自己知道每一步在做什么。

回到工位后，他重新操作。这次字段放对了，金额汇总却不对，比预期少了不少。他接着查第三问，自己核对结果，并请同事帮忙看。两人发现金额字段里有文本形式的数字。把这些内容转换成数值、刷新透视表后，汇总结果才与源数据核对一致。

他把这次完成情况记下来：字段拖放经过再次示范后能够完成；数据类型检查仍需要同事提醒。这样的记录比一句“我会了”具体，也方便下次复查。

实际使用时，你可能补了一步仍然卡住，那就换一个问题继续查。五问的价值不在于一次定位原因，而在于帮你把笼统的“没学会”拆成可以逐个处理的卡点。先找到能处理的卡点，补上所需的提示或练习，再看结果，不必等到完全确定心理原因才开始行动。

## 换一张表，刚才学的方法还能用吗？

观察学习也可以让人从示范中学到规则和判断依据。

例如，你发现同事做金额汇总前总会检查数据类型，便问他为什么。他说，以前有一张表的金额字段混入了文本形式的数字，汇总结果漏算了部分金额，所以后来都会先检查。你核对那张表的源数据与汇总结果，确认了这个问题。

现在你知道了检查的是什么，也知道结果异常时该查哪里。“检查数据类型”就有了具体理由，而不只是一个需要照做的步骤。

继续前面的假设案例。三天后，这位同事接到新任务，要用另一张表按地区汇总销售额。他把地区字段放到行区域，金额字段放到值区域。这次在汇总前，他先检查金额字段，确认参与计算的内容都是数值，再把结果与源数据核对。

这说明他在这一次新任务中用上了先前学到的做法，也记得主动检查金额字段。

理解操作背后的理由，有助于判断什么时候该用这一步。换个任务能不能用上，仍然要试一试。

你从示范中推测出来的规则，拿不准时，问清楚，再结合结果核对。

## 再看一遍就做对了，能说明刚才为什么不会吗？

再看一次后做对了，说明补充示范有帮助，却未必能确定第一次为什么失败。第二次看，你可能更留意关键动作，也多了一次记忆和熟悉任务的机会。注意与保持都可能有所改善。

一次检查通常不足以确认原因。说不出步骤，也许当时漏看了，也许看到了却没记牢，或者一时想不起来。操作失败可能涉及步骤不完整、练习不足，或者新任务多了原先没有的要求。一个有能力、有条件的人没有使用新方法，也不能据此认定他不愿意学，需要了解他觉得新方法有什么收益、成本或风险。还要分清时间上的变化：学会后暂时没有使用，与隔了一段时间再做失败，是两个问题。过去成功过，只能说明当时完成了那项任务；现在还记得多少、能做多少，需要重新试。

但你不需要等确定原因才开始行动。先处理看得见的卡点，记录补了什么、结果怎样。有效就继续，无效再查。这样即使还说不准问题属于哪个过程，也能逐步改进。

观察学习模型提醒我们一件事：看完示范后做不出来，不等于白看了。你从示范中带走的，可能比你能当场做出来的多。但“可能带走了一些”和“确实带走了什么”不是一回事。下次看完示范又卡住，别急着说没学会，也别急着说学会了。先独立试一次，找到具体卡点，再用五问逐个检查。你从示范中到底带走了什么，要靠后续的表现和结果来回答，而不是靠当时“看懂了”的感觉。

**模型档案卡**

**模型名称**　观察学习（Observational Learning）

**一句话定义**　通过观察别人的行为，学到做法、规则或判断；学到了什么与后来如何表现，需要分别检查。

**来源**　班杜拉（Albert Bandura）1965年的波波玩偶实验，为区分学习的“获得”与“表现”提供了证据。1977年，他在《社会学习理论》中系统阐述了注意、保持、行为再现和动机四个过程。

**调用提示**　看完示范后做不出来，先独立试一次，记下卡点。结合注意、保持、行为再现和动机检查原因，再单独确认外部条件，决定接下来补什么。

**适用情形**　看过教程、参加过培训，或跟着同事做过一次，独立操作时却卡住；也适用于已经会做，却一直没有使用新方法的情况。

**使用边界**　四过程可以帮助检查原因，但不能保证一次就查清。没有表现出来，可能是没学到，也可能受到执行能力、动机或外部条件影响，需要取得更多证据。还要核对示范本身是否可靠：示范者可能做错，也可能省略了前置步骤。即使准确记住了示范，也仍需检查方法和结果是否正确。
