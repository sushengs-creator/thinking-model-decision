# 思维模型132：福格行为模型，计划每天学半小时，到最后却总拖到“明天再说”，问题到底出在哪？

你是不是有过类似的经历：提醒的闹铃响了，你看了一眼，关掉提醒，继续刷短视频。心心念念买了课但是一直没听完，鼓足勇气办了健身卡但是没有去几天，给自己设计了学习计划但是没坚持几天。中断几次后，你开始觉得自己不够自律，自怨自艾。于是重新给自己打气，再立一个计划，过几天，同样的场景又来一遍。

这样的场景在我们每个人身上频繁上演，我们不是不想要改变，但是为什么我们总是没有办法坚持下去呢，究竟是哪一步出了问题？

## 行为不发生，不等于你不想做

遇到这些情况，大多数人的第一反应是责怪自己：不够自律，不够坚持，不够努力。但仔细想想，你买课的时候是真想学，办健身卡的时候是真想练，设学习计划的时候也是真想做。动机一直在，为什么行为就是不发生？

2009年，斯坦福大学行为设计实验室创始人福格博士（B.J. Fogg）在论文《A Behavior Model for Persuasive Design》中提出福格行为模型。它用三个要素分析行为：动机、能力和触发因素。后来，福格把“触发因素”（Trigger）改称“提示”（Prompt），如今常用的简写是B=MAP。

[插图说明：原稿此处为福格行为模型图；临时签名图片地址未写入公共包，文字正文保留。]

**福格行为模型指的是，人类的一切行为都可以被拆解成动机、能力和提示这三个要素，也就是“我想做”“我能做”和“现在就去做”。福格用一个最简单的公式来表示为B=MAP。B指的是英文单词“行为”的首字母，而M、A、P则分别指的是动机、能力和提示这三个英文单词的首字母。福格认为，如果某个行为，我们始终做不到，那一定是这三个要素没有同时发生作用。**

其中最容易被忽略的一点是，**三个要素必须在同一时刻同时到位，缺任何一个，行为都不会发生。**

我们把这个定义拆开来看，有两层意思。

第一层，“做不到”不等于“不想做”。你买课的时候是真想学，办健身卡的时候是真想练。动机一直在，但行为就是不发生。福格的说法是，动机只是三个要素中的一个，另外两个，一个是你当时做起来有多容易，一个是提醒你“现在就做”的信号。这三个要素缺哪一个，行为都不会发生。

第二层，三个要素不是各自够就行，必须在同一时刻同时到位。早上精力充沛时，学半小时的动机没问题，但如果教材不在手边，能力这一项就不够。晚上教材放好了，做起来不难，但那时候你更想休息，动机又弱了。动机够的时候能力不够，能力够的时候动机不够，两个都够的时候提示没出现。三个要素不在同一个时刻凑齐，结果都一样：没做。

所以，提醒响了却没做，不能直接推出“我不够想”。你需要回到当时，看看这个动作要求你付出什么，提醒又是在什么情况下出现的。

## 福格行为模型三个要素，分别管什么

先说动机，动机就是“我想做”。你渴了想喝水，动机很足，不需要谁催。但你想学好统计，动机可能时强时弱。早上精力充沛时，学半小时的动机没问题。晚上忙完一天，同一个动机就弱了。很多人觉得做不到是因为不够想，但动机只是三个要素中的一个。你买课的时候是真想学，办健身卡的时候是真想练，动机一直在，行为就是不发生。

再说能力，能力就是“我能做”。福格把能力拆成五个因素：时间、金钱、体力、脑力，以及跟现有日程合不合得来。有人用七分钟健身操举例：时间够，免费，动作不复杂，也不用调整日程，但其中几个动作超出了你的体力。卡在体力这一项上，整个行为就发生不了。五项里只要有一项当时不够用，这件事就做不成。做产品的人对这个道理很敏感，后面会专门讲到。

最后说提示，提示就是“现在就去做”。提示不只是一声闹钟。放下饭碗、走到书桌旁，或者看到摊开的教材，都可能提醒你去做一个动作。有产品经理做过一个尝试：把透明水杯放左手边，一天能喝六到八杯；放右手边，喝四杯；放身后，几乎不喝。水没变，渴的感觉没变，变的是提示在不在你眼前。看不见就等于不存在。

三个要素要在同一时刻凑齐。你有动机也有能力，但提示没出现，行为不会发生。提示出现了，你也有动机，但当时做不到，行为也不会发生。缺哪一个，结果都一样：没做。

## 明明想改变，为什么还是会反复？

福格在《福格行为模型》一书中讲过朱妮的故事。她的母亲死于糖尿病并发症。母亲去世后，朱妮一边照顾家庭、应付工作，一边借甜食缓解悲伤。她后来意识到，疲惫和思念母亲会促使自己吃糖。记录感受、联系朋友，成了她尝试的其他应对方式。

这个故事里的困难，不能只用“不想改变”解释。想减少甜食，与当下想获得一点安慰，可以同时存在。知道改变有好处，也不等于每到行动时刻，那份意愿都会占上风。

学习也会遇到类似的冲突。你想学会看数据报告，但忙了一天，更想立刻休息。早上订计划时，半小时似乎不长。到了晚上，光是想到还要重新看懂上次的公式，就可能打退堂鼓。

这时除了给自己打气，还可以问一句：这件事能不能变得容易一点，让我在没那么有劲的时候，也愿意开始？

## 做不来时，先看看哪一步太费劲

你计划晚上看一页统计教材，可坐到书桌前，还得找书、找笔记，再翻出上次停下的位置。每一步都不算大事，连在一起，却可能让一个本来就疲惫的人决定“明天再说”。做不下来，并不能说明你不想学。

你已经知道能力包括五个方面。现在的问题是：卡在其中一项时，怎么办。

不一定要等自己更熟练了，才能改变这种情形。提前把书放在桌上、夹好书签、留下一句“下次从这里开始”，都在减少下一次的准备工作。

福格指出三条路径：提高技能、提供工具或资源、缩小这一次要做的动作。对于迟迟没有开始的日常任务，最后一条尤其容易着手：把“学半小时”先缩成“打开教材，读一行”。

## 提醒已经响了，怎样才能接上行动？

知道了提示是什么，下一个问题是：什么样的提示能让你真的动起来。

有效的提示需要被你注意到，让你知道具体要做什么，并且出现在你有条件行动的时候。晚上八点的闹钟即使准时响了，若你正在处理一件无法中断的事，它也未必能促成学习。

福格把提示分成三类，分别应对不同的动机与能力组合。

动作不难但不想做时，提示需要提供一个理由。设想有人提醒你：“这一页讲的就是你今天没看懂的图表。”这可能比“你该学习了”更能让你愿意打开书。

愿意做但执行有阻力时，提示可以同时把下一步变容易。福格展示过 Facebook 发给他的重新登录邮件：显眼的登录按钮，让他不用自己寻找入口。

愿意做也做得来时，只需要在合适的时候想起来。

因此，闹钟未能让你行动时，不必急着再加几个闹钟。先看看提醒出现以后，你能不能马上开始，还是仍有一串准备工作要做。

## 回看一次没开始，下一步该改什么？

实际使用时，可以按提示、能力、动机的顺序检查。提示是否被看到、执行有哪些障碍，通常比“我到底有多想做”更容易具体描述。先查这些条件，有助于避免一上来就责怪自己。

下面用一个假设的学习场景，走一遍检查过程。

一个人想看懂工作中的数据报告，原本计划每天学半小时，却一直没有开始。他回想了两次没开始的情形：一次是八点提醒响了，自己正在回复工作消息。另一次有空走到桌前，却找不到教材。

如果只想先把事情做起来，他可以同时调整学习时机、提前放好教材。若还想分辨哪项调整有帮助，就先选一个明显的障碍来试，不必把整件事变成复杂的实验。

他决定先解决启动问题，把动作缩小为“打开教材，读一行”。接下来记录的，都是这个小动作有没有完成。

假设尝试这个小动作时，八点的提醒仍经常撞上工作。他先改提示，把新的安排写成：“洗完澡、挂好毛巾后，打开教材读一行。”教材的准备方式暂时不动。他的预测是：这个时候更少被工作打断，应该更容易开始。

接下来的几次机会，简单记下有没有想起、当时在做什么、有没有读、停在哪里。记录可以只有一句，比如：“挂好毛巾时想起要读一行，走到桌前找不到书，没有读成。”用在自己身上时，把这句话换成当时的实际情况即可。

如果记录显示，新的提示能让他想起读书，找书却成了障碍，就保留这个提示，接着试“提前把教材放到桌上”。如果挂好毛巾后仍想不起来，或者那时其实也很忙，就继续调整提示及其时机。

日常动作可以用作提示，但需要建立起与新行为的联系。写好一句安排，只是开始，还要在实际生活中试着用。

一次读了，只能说明这次做到了。如果接连几次，在相近的情境里都更容易开始，就多了一些理由保留这个调整。但生活中的其他条件也在变化，不急着下唯一结论。

最后，还要认真看动机。他说“我确实想学”，不代表每次都愿意打开教材。如果提示能被注意，动作也足够容易，却仍反复不想做，就问问：这门课对自己有用吗？眼下是否有更重要的事？换一种学法会不会更合适？必要时可以调整目标。

观察的目的是找到下一步怎么改。单项调整方便分辨，多项一起调整也可以解决问题，只是不能据结果分清各项贡献。

## 我怎样把步行安排进日常？

2023年12月，在读完《福格行为模型》一书后，我给自己定了一个目标：每天步行一万步。这个规划一直执行到现在，不知不觉两年多过去了，现在我轻轻松松就能够完成每日一万步的目标，一万步已经变成了我生活中的一个习惯。

在刚刚开始的时候，我正在华为担任高级运营顾问，长期各地出差，由于经常在各地，为了让这个目标落到日常里，我安排了几个具体场景。每天中午午饭后，不上楼，立即在楼下开始走路；如果当天目标没有达成，每天晚上回酒店放下办公包后，立即穿上运动鞋，到酒店楼下开始步行。现在已经养成习惯，无论刮风下雨，中午吃完午饭，和几个同事就立即开始在楼下转圈走路，完成到1万步在上楼。

这些安排把“去走路”接在了具体场景后面，让我有机会想起它。这样中午的午餐就是一个重要的提醒，吃完午饭我们就知道需要开始今日的步行。

当开始的时候，每次步行完毕我还加了一个庆祝动作：走完之后，对自己说一句“very good”，或者在心里点个赞。这个庆祝的做法来自福格的微小习惯方法（Tiny Habits）。这套方法把新动作接在已有日常动作后面，让它足够小，并在完成后立即用适合自己的方式感受成功。这是在行为模型基础上设计习惯的方法。

## 产品经理也在用这个模型

福格行为模型不只用来管理自己的习惯，做产品的人也在用它设计用户的行为。福格在斯坦福大学的研究领域就是说服性技术，很多硅谷产品经理受过他的影响。他指导学生做出的Instagram就是靠极简设计降低了用户的使用门槛。

笔记软件flomo的产品经理少楠也说过，过去讨论用户行为时，动机归运营管，降低摩擦归设计管，曝光投放归市场管，三个要素散在不同部门。看到B=MAP公式后，他才把三件事串起来。

提示方面，前面说过水杯实验的结论：看不见就等于不存在。少楠把这个结论用在了flomo的设计上。笔记软件最大的问题是用户想不起来打开。所以他把入口铺得到处都是：微信服务号置顶、桌面小组件、浏览器插件、得到和知行分享入口。用户在哪儿可能产生想法，就在哪儿放一个入口。

能力方面，flomo的输入框只有一行，不像备忘录那样给你一张大白纸。空白画布会让人不敢动手，光想标题就耗半天。输入框缩小到一行，像发微信一样简单，用户就不用克服“不知道写什么”的心理门槛。不需要排版，不用写标题，写几个字也行。

动机方面，少楠做了一个特别的判断：不做打卡，不发积分，不推“你好久没记笔记了”的提醒。因为打卡奖励会把用户动机从“记笔记”扭曲成“贪便宜”，用户为了领奖励而记，根本不关心内容，最后只会弃用。他选择不扭曲用户的真实动机，顺着用户本来就想记笔记的意愿，帮他完成想做的事。

语言学习App多邻国在用户答完题后，会弹出动画提醒：明天来打卡可以拿更多奖励。这同时做了两件事：告知明天有奖励，加深打卡动机；告诉你明天同一时间来就行，降低行动门槛。

产品经理用福格行为模型，和个人用它的逻辑一样：检查提示在不在眼前，检查能力门槛高不高，检查动机是不是用户真实的意愿。区别在于，个人调的是自己的条件，产品经理调的是产品的设计。

## 照着做时，还容易在哪些地方判断错？

学了一个新模型，最容易犯的错误不是用错，而是用偏。你知道要检查动机、能力、提示，但检查的时候，还是容易踩进几个坑。

第一个坑，没做到就认定不够想。这是最自然的反应，也是福格行为模型首先要纠正的。你买课的时候是真想学，但到了晚上八点，忙了一天，那份意愿已经不是同一个强度。没做到，不能直接推出动机不够，可能是当时的时机不对，可能是手边缺工具，也可能是另一件事占住了你的注意力。先还原一次没做到的具体情形，看看当时三个要素各自是什么状态，再判断到底卡在哪里。

第二个坑，以为能力只指聪明或熟练。福格说的能力包括时间、金钱、体力、脑力和日程配合五个方面。你“会做”一件事，不代表你“当时做得成”。会做统计题，但晚上十一点脑子已经转不动了，脑力这一项就不够。从头走一遍准备到执行的每个步骤，找出具体卡在哪一项上，比笼统地说“我能力不行”有用得多。

第三个坑，提醒越多越好。提醒响了没做，第一反应是再加一个提醒。但问题往往不在提醒的数量，而在提醒之后你能不能马上开始。如果提醒出现时你正在忙别的事，或者下一步要找书、找笔记、开机、登录，一串准备工作横在中间，再多的提醒也没用。检查提醒之后下一步是否清楚、是否可执行，比叠加闹钟更重要。

第四个坑，完成小动作就算完成目标。把“学半小时”缩成“读一行”，是为了让你开始，不是为了让你停在那里。读了一行，说明启动问题解决了，但离学会统计还有距离。分别检查“有没有开始”和“有没有学会”，不要把启动当成完成。

第五个坑，改一次有效就认定找到了原因。你换了提示时间，连续两天都开始读了，于是认定问题就是提示时机。但生活中其他条件也在变化，也许那两天恰好不太忙，也许动机恰好比较强。多观察几次，把每次结果当作线索而不是结论，才能分辨哪项调整真正起了作用。

## 下次没做到时，先别骂自己

福格行为模型提醒我们一件事：行为不发生，不等于你不想做。下次没做到时，先别骂自己，回到当时的场景，看看提示、能力、动机哪个没凑齐。

下次提醒响了却没去做，先记下一次具体情形：提醒出现时，你正在做什么？下一步要付出什么？你当时愿意做这个动作吗？

选一个有依据、改得动的条件，试一试，再看接下来的几次机会发生了什么。

“我不够自律”很难告诉你明天该怎么做。“提醒总在回消息时响”“教材还没找到”“我其实不需要这门课”，才让下一步有了方向。

| 核心区分  | 想要结果不等于此刻愿意行动；能力包括当时的执行条件；有提醒不等于提醒有效                        |
| 调用提示  | 计划迟迟没执行、提醒响了没去做，或想减少某个具体行为时                                 |
| 应用方法  | 明确动作，回看一次机会，依次检查提示、能力、动机；调整后在多次相近机会中观察                      |
| 使用边界  | 不能计算行为概率，不能由单次成败确定原因；容易启动不等于达成目标；严重成瘾需寻求专业帮助                |
