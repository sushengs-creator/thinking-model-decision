想催他还相机，却怕一开口就吵架

设想这样一个借相机的场景。许宁把相机借给了陈默，说好周日晚还。到了周一晚上九点，相机还没回来。明早八点，她还要带着它去给朋友的活动拍照。

她打开对话框，打了一行字，删了。又打一行，又删了。

她想把相机要回来，也想问一句：答应好的事，为什么没做到？可她担心，话一出口，就会从还相机变成吵架。

类似的为难并不少见。室友拖着不交电费，同事没按约定交材料，朋友借走东西一直不还。你有理由提出要求，却不知道怎样开口，才能把这件事谈下去。

问题出在语气上吗？客气一点，加个表情包，就够了吗？

语气当然有影响，但我们还可以看看：那句话里，到底说了什么。

说好周日晚上的，怎么变成了「你每次都这样」

许宁想发出去的，可能是这样几句：

「你怎么还不还啊？」

「说好周日晚上的。」

「你每次都这样。」

这三句话的问题并不一样。

「你怎么还不还啊」，是在催还。如果当时语气很冲，对方可能先听见责怪。更值得检查的是：双方是不是已经知道具体约定，我有没有说清现在要确认的安排。两个人本来就在谈这件事，不必每句话都把背景重报一遍。

「说好周日晚上的」，是在提醒一项约定。如果双方确实这样约定过，这就是可以核对的事实。许宁有理由催还，也有理由指出陈默没有按约归还。

到了「你每次都这样」，话题就扩大了。原本要谈的是这一次没还相机，接下来却可能变成：陈默到底是不是一个不守信用的人？过去究竟有几次？

他可能马上反驳：「什么叫每次？上次我不是按时还了吗？」

两个人开始争过去的表现，眼前的归还安排反而没人谈。

对话就在这里拐了个弯：从这次做了什么，变成这个人怎么样。把事实说清楚，双方才容易对准同一件事；给人定性，则容易引出对方的自辩。

这不意味着只要吵起来，就一定是你说错了。对方的状态、你们过去的关系，还有眼前有没有利益冲突，都会影响回应。

假如有录像、录音或聊天记录，哪些内容能被核对？

「我们约的是周日晚归还，现在是周一晚上，我还没收到相机」，可以核对。

「你根本没把我当朋友」，是对对方态度的解释，需要另外确认。

「总是」「每次」「从来」也值得停下来检查，但它们不是禁词。「上周三次例会，你每次都在开始十分钟后到场」，有明确范围；「你每次都不把别人当回事」，则把行为和动机混在了一起。

事实可以说清，责任可以讨论，不必先给一个人下结论。

那句话里，其实装着四样东西

处理这类对话，可以借助美国临床心理学家马歇尔·卢森堡（Marshall B. Rosenberg）发展的非暴力沟通。

非暴力沟通，简称 NVC，是一种沟通框架。它用观察、感受、需要和请求四个要素，帮助我们把自己的处境说清，也认真理解对方，寻找双方都愿意接受的办法。它有两条线：一条是把自己的意思说清楚，一条是把对方的意思听明白。

它不保证把四个要素说全，对方就会答应。

其中最容易被忽略的一点是，它改的不是你话说得多客气，而是你要说的内容。不是「这个人怎么样」，而是「这件事是什么、我什么感受、我在意什么、我希望怎么办」。

我们把这个定义拆开来看。

观察，是具体发生了什么。它只放能拿出来核对的东西，时间、约定、发生过什么。

感受，是你此刻的心情，着急、失望，还是生气。不是你对对方的态度判断。

需要，是这份心情背后，你看重什么。是可靠，是自主，还是被尊重。这一层不必都说出口，但值得你想清楚。

请求，是你希望对方采取的具体行动。它要落在一个可以答应的动作上，而不是一个态度。

放到许宁的事情里，就是这样四句：

「我们约的是周日晚归还，现在是周一晚上，我还没收到相机。」

「我有点着急，也挺失望。」

她还可以问问自己：这份着急和失望背后，是对可靠、支持或信任的看重吗？

「你今晚十点前能把相机送到我家楼下吗？」

如果双方没有误会，其实一句「相机明早我要用，今晚能还吗」就够了，不必四步都走一遍。对话卡住时，再回头看还有什么没说清、没听懂。

卢森堡在书中提醒，NVC 不是固定公式，要适应情境和个人表达习惯。四个要素可以帮助我们整理思路，不必每次逐项念出来。

「我觉得你不尊重我」，说的是感受吗

「我觉得你不尊重我。」

这句话很常见，也确实可能来自委屈。但「你不尊重我」包含了对对方态度的判断，加上「我觉得」，也没有把判断变成感受。

可以再往下问一句：想到对方不尊重我时，我具体是什么感受？是生气，失望，还是难过？

「我很失望」，说的是自己的情绪。「你就是故意拖着不还」，说的是对方的动机。

「我觉得被忽视了」也常把这两层放在一起。你确实难受，但对方是不是忽视你、是不是有意这样做，还需要另外核实。把两层分开，才说得清：我是什么心情，我是怎么理解这件事。

许宁可以说：

「昨天没收到相机，也没收到你更改时间的消息，我挺失望的。我原本以为我们已经约好了。」

她把不满说了出来，也留下了让陈默解释的空间。对方更容易知道，究竟是哪件事让她受到了影响。

可以先用这个区分整理自己的话。别人说「我感觉被忽视了」，不必急着纠正他用词不标准，先听听他经历了什么。

非得让他亲自送回来吗

四个要素里，「需要」最容易和日常用语混淆。

我们平时会说：「我需要你明早八点前把相机还回来。」这句话表达了清楚的要求，但按 NVC 的用法，它已经包含了具体的人、时间、物品和行动。

NVC 所说的需要，是更普遍的价值和愿望，例如安全、支持、信任、能自己做主、被理解。满足需要的具体办法，叫作策略。

许宁可以分开想几件事。

她在意什么：如果今晚相机回不来，她担心明天开不了工。这份担心背后，可能是对可靠的看重，也可能是希望安排别临时变。

她也可能在意另一件事：她觉得自己没被认真对待。这份感觉背后，可能是希望被尊重，也可能是希望被理解。

她眼前要实现什么：明早出发前拿到可用的相机。

具体怎样实现：陈默今晚送回、她去取，或者请别人代送。

这几样都要由她自己确认，也可能同时存在。她不是非得挑出一个最要紧的。

分开之后，有些条件就不必捆死。如果她坚持「你必须亲自送回来」，而陈默今晚不在本地，对话可能卡在这里。假如相机留在他家、家人可以代送，就多了一个可讨论的办法。

但她也可能发现，自己在意的不只是明早能拍照。即使相机送回来了，「为什么改了时间却没告诉我」仍然值得谈，因为这关系到以后的信任。

因此，分清需要和策略，不等于劝自己别计较，更不等于替对方免除责任。它的用处是帮你看清两件事：哪些办法可以商量，哪件在意的事还没有被回应。

可以问自己：「我为什么这么在意这个做法？它在保护什么？」再问：「还有别的办法能照顾到这件事吗？」

暂时想不到别的办法，不代表你想错了。只有一台相机，把需要说清楚，也不会多出第二台。理解之后，双方仍要面对归还约定，商量安排和取舍。

你以为听懂了，其实你猜的是自己的意思

话说出去了，接下来就看对方怎么接。

很多人听过「我句式」，就是把「你怎么老是迟到」改成「你迟到的时候我很着急」。它和非暴力沟通有重叠，都是把指责换成自己的感受。

我句式做到了第一步，就是把话从「你怎样不对」转成「我怎样感受」。非暴力沟通在这之上还会往前走：说清具体发生了什么，说清你在意什么，提出一个对方能回应的具体请求，然后再听对方怎么理解。改一句话，只是开头。

假如陈默回了一句：

「你催得这么急，好像我故意赖着不还似的。」

许宁可能想反驳：「本来就是你没还！」事实没有错，但如果她想弄清对方卡在哪里，可以先核实自己的理解：

「你是觉得，我已经认定你故意不还了，是吗？」

这只是试着确认自己有没有听懂。对方确认后，还可以接着听他有什么顾虑、在意什么。

陈默可能说「对」，也可能说：「不是，我是还想多用一天，不知道怎么开口。」对方怎么回答，决定她下一步怎样理解。

倾听时，不必把对方的每句话都拆成观察、感受、需要、请求四项去对号。先听见情绪和顾虑，拿不准就问，猜错就改。对方也可以不想谈感受，只告诉你实际安排。

理解之后，许宁仍然可以坚持自己的要求：

「我明白你还想用。但明早的活动我已经答应了，我们也约好了周日归还。我们现在确认一下，怎么把相机送回来。」

听懂他，并不等于同意再借一天。理解对方和答应对方，是两件事。

同样，听见了对方的顾虑，也别拿它来施压。「我知道你怕失去朋友，所以你更应该答应我」，前半句是在谈理解，后半句却把对方的担心变成了交换条件。

可以检查自己的反应：如果对方纠正了我的猜测，或者没有按我的意思做，我还愿不愿意听他说完？

说得很温和，也可能是在下命令

「你能不能今晚送回来？」看起来是一句询问。可如果对方一说办不到，接着收到的就是羞辱、威胁，这个问句仍然可能是在要求服从。

非暴力沟通把这两样分开。请求，是你说出希望，同时留出对方说不的余地。要求，是对方一说不，你就用指责、羞辱或惩罚逼他答应。区别不在措辞，在你听到拒绝之后的反应：你愿不愿意听清他的困难、继续商量，还是只想着怎么让他就范。

不过，听取拒绝，不等于原有约定作废。陈默说「我今晚没法亲自送」，可以接着商量谁来送、什么时候送。陈默说「我还要用几天，不还了」，许宁也不必把它当成一个应当接受的安排。

「亲自送回」这个办法可以讨论，已经答应归还的事实仍然存在。她可以继续要求落实归还，也可以在事情处理后决定，今后是否还借给他。这些都不是惩罚，判断是不是在强迫，要看后果有没有被拿来逼对方屈服。

请求也不一定是一个「能不能」的问题。它可以只是问对方哪里不方便，先弄清他的处境，不一定马上要一个是或不是。

有一点要留意：如果你手里的权力比对方大，他听到的就不只是这句话。上级说「这件事让我有点失望」，下属听到的可能还有考核压力。用了感受词，不代表对方就有自由表达不同意见的空间。非暴力沟通中心的自查会问：我的语气和身体语言，跟我的话是不是一致？我的请求是不是伪装成了要求？我准备好听见拒绝了吗？

如果对话中出现威胁、暴力或持续强迫，先保护安全、离开危险并寻求支持，不必为了把四个要素说完整而留在现场。

换一种说法之后，相机就一定能回来吗

回到开头的场景。许宁可以这样发消息：

「陈默，说好周日晚还相机，现在我还没收到，有点着急。我明早八点要去给朋友拍活动，怕耽误事，想今晚把安排定下来。你能十点前送到我家楼下吗？如果不能亲自送，我们商量一下别的办法。」

这段话说的是事实、着急的感受和具体请求。日常说话不必把四个要素都摆出来，说清这三样，对方就能接住。

接下来，可能出现不同的回答。

假如陈默说：「抱歉，我忘了。我人在外地，相机在家，我问问我弟能不能今晚送。」

许宁还需要确认：弟弟是否方便、几点能到。说出一个可能的办法，还不等于事情已经安排好。

假如陈默说：「我还想再用两天。」

她可以回应：「我不同意再延两天。明早的活动是我早就答应别人的，不能再拖。你看今晚怎么安排归还？」

如果他迟迟不回复，她可以打电话确认，并提出答复时点：「请你九点半前告诉我，今晚能怎样交接。」到了时间仍联系不上，就同步找备用设备，另行跟进归还。为眼前的活动找替代方案，不表示这次失约就算了。

即使相机按时回来了，关系也未必立刻恢复。许宁仍然可以另找时间说：

「这次过了约定时间，也没有提前告诉我，我没法安排。以后如果不能按时还，请在约定时间前和我说，等我们确认新时间。下次是否再借，我也会重新考虑。」

把事情办好、表达不满、要求补救，都可以谈。许宁若希望陈默承认这次失约的影响、道个歉，也可以明确提出来。

换一种说法，你能调整的只是自己的表达和回应。对方是否回应、是否守约，仍然不完全由你决定。

那句话发出去之前，还来得及改

非暴力沟通提醒我们一件事：你有一件事要说，却发现自己一开口，就想把对方整个人批评一遍。这种时候，先别急着换语气，先看看那句话里装了什么。

先缓一缓，在心里理清四个问题：

1. 具体发生了什么，哪些能核对？

2. 我现在是着急、失望，还是生气？

3. 这件事为什么重要，我在意什么？

4. 我希望对方下一步做什么，能不能说得具体？

许宁可以把「你每次都这样」改成「我们约的是周日晚归还，现在我还没收到」。她也可以直接说失望、坚持归还，并要求对方说明接下来的安排。

这四个问题里，前三个问的是三样不同的东西，容易混在一起。

核对发生了什么。「约好周日还，现在还没收到」，这是能拿出来对的。

说自己的心情。着急、失望、生气，说的是你此刻的状态。

辨认你在意什么。「我在意信任，也希望安排可靠」，说的是需要。它不是「你根本不在乎我」，后一句是对对方态度的判断，不能拿来代替需要。

分得清这三样，你才知道自己该说什么。哪一步没想清，话说出去就容易变成在给对方下结论。

如果此刻气得听不进去，可以先暂停，等自己能够说清诉求时再谈。你不需要一边生气，一边考自己四个要素有没有背全。

说完，再听听对方的意思，拿不准就核实。谈出办法后，还要确认三件事：谁来做、什么时候做、怎么交接。对方持续拒绝或者不回消息，就先处理眼前的困难，那件事另找时间继续跟进。

一次对话能做到多少，取决于双方和现实条件。开口之前，你可以先把事实说准，把在意的事讲清，再提出一个具体的请求。这些是你这边能做的，对方的回应还要看他的处境和意愿。

模型档案卡

| 模型名称 | 非暴力沟通（Nonviolent Communication，NVC）。 |
| --- | --- |
| 一句话定义 | 用观察、感受、需要和请求整理表达与倾听，在重视双方需要的基础上，寻找愿意共同采取的行动。 |
| 来源与 代表著作 | 马歇尔·卢森堡（Marshall B. Rosenberg）发展；代表著作《Nonviolent Communication: A Language of Life》（《非暴力沟通》）。 |
| 解决什么 问题 | 诉求难以说清、对话容易滑向人身评价，以及只顾表达自己、没有核实对方意思的沟通困境。 |
| 调用提醒 | 发生了什么？我有什么感受？我在意什么？我希望下一步做什么？对方的意思，我核实了吗？ |
| 边界 | 它是整理思路的方向，不是必须一句句念出来的公式。需要与具体策略要分开。理解不等于赞同，听取拒绝不取消原有约定。它不保证对方听懂、答应合作，也不能替代安全保障、规则和责任处理。 |
