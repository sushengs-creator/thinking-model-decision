## 思维模型126：具身认知——**照着菜谱做对了一盘菜，换种食材就不会了——问题出在哪？**

架上手机照着菜谱做出了一盘菜，你觉得自己学会了，下次换一种食材，又拿不准该开多大火、炒多久，你只好重新再找教程。

上次明明亲手做过，为什么还是不会呢？

我们可以说是步骤没记牢、不熟悉新食材，或者独立练习太少，的确，这些问题都可能让你卡住。但是我们这里先检查一件最容易漏掉的事，动手时获得的感觉，有没有帮助你判断这一步为什么要这样做、什么时候需要调整？你还记得你的手感吗？

菜谱告诉你翻炒三十秒，你记住了这个数字，也动了三十下锅铲。至于翻动怎样影响受热，食材的状态变到什么程度才该出锅，你可能还没留意，甚至你也没有感受。

## 看别人做和自己上手，学到的会一样吗？

看别人操作，我们能看见动作和结果。自己上手，还会感到物体的重量、阻力，以及动作改变后手上的变化。这些感觉会进入到我们的思考，帮助我们理解眼前发生了什么。

做菜时你翻炒的那三十秒，手上感到食材逐渐变软、锅铲下的阻力的变化。这些感觉不只是你顺便记下的副产品，它们是你判断“该不该出锅”的重要依据。无论是做菜还是学习物理，有一个共同特征：身体的感觉和动作经验，可以参与到你对事情最后的理解之中。具身认知关注的正是这一点，**身体的感觉、动作以及与环境的互动，可以参与我们的理解和思考，是思考过程的一部分。**

我们把定义拆清楚。“身体的感觉和动作”包括你用手感受食材软硬、用眼睛观察颜色变化、用动作改变物体位置。具身认知理论认为，这些感知和动作经验不只是帮你完成手上的活，还会进入你的思考，成为你理解概念的素材。“参与”不是代替思考，而是为思考提供一部分材料。你判断青菜该不该出锅，靠的是手感、视觉和已有知识一起作用，不是纯粹的推理，也不是纯粹的手感。身体经验也是理解的一部分。“与环境的互动”指你不是孤立地在脑子里想，而是在具体情境中操作，改变事物的状态，也接收反馈，理解就发生在这个来回过程中。

身体经验可以参与理解，但动手能不能帮到理解，要看动作和概念的关系对不对上。理解一个概念，也不只有动手这一条路。

2015年，卡莉·康特拉（Carly Kontra）和同事发表了一组关于角动量学习的研究。康特拉当时在芝加哥大学研究身体经验与学习的关系。角动量是描述物体旋转状态的物理量，有大小，也有方向。研究者想知道，亲手感受旋转物体受力的变化，会不会帮助学生理解它。

装置是一根轴上装着两个可以独立旋转的轮子。一组学生握住轮轴，改变轴的朝向，感受手上的扭转作用；另一组在旁边观察，也能看到激光指示的偏转，两组都读过相关的说明。

之后，学生看着屏幕上的人物操作轮子，判断谁承受的力更大。实验发现，亲手操作组的后续判断表现更好。同一论文的一项脑成像实验还发现，亲手操作组在之后思考这些问题时，部分与感觉和运动有关的脑区活动更强，其中部分活动与测验成绩有关。

一种可能的解释是，学生后来判断受力大小时，调用了刚才手上感受到的经验。这里的身体体验与概念学习结合在一起。

做菜时也可以留意这种联系。翻炒过程中，食材逐渐变软，锅铲下的阻力也会变化。你能不能把这些感觉和食材的状态联系起来，用来决定下一步怎么做？

## 照着步骤做对了，怎么一换条件就不会了？

动手获得了经验，接下来我们再看看，这些经验能用到什么地方。

2014年，米丽娅姆·诺瓦克（Miriam Novack）和同事教8到10岁的孩子做数学等式题。诺瓦克当时在芝加哥大学研究手势与儿童学习。例如，2＋9＋4＝□＋4，空格里应当填11，让等号两边相等。

三组孩子听到的讲解一样，区别在手上。第一组拿起代表2和9的数字磁片，合在一起，移到空格处。第二组面前也有磁片，但不拿起来，只用手比画拿起、合拢、移动的动作。第三组更简单，用手指分别指向2和9，再指向空格。

三组动作都在表达同一件事：把两个数合成一组。但三组带走的东西不一样。第一组带走的是“把这块东西搬到那个位置”，第二组带走的是“做出搬的动作”，第三组带走的是“这两个数要合起来”。前两组的动作绑在具体的磁片和位置上，第三组只表达了数字之间的关系。

这个差别在换题型时就露出来了。比如改成2＋9＋4＝2＋□，空格里该填9和4的和。这时只记住“把左边前两个数搬过去”的孩子就卡住了，因为原来的动作对应不上新的题目结构。

结果正是如此。练过的题型上，三组学得差不多。但题目换了形式，用手指指向数字的那组表现更好，用实物磁片的那组反而不如他们。绑在具体物体上的动作，换一种题型就不容易迁移；只表达关系的动作，反而更容易搬到新题里用。

回到菜谱。你照着步骤做对了一盘菜，和那些孩子做对了一道题一样，只说明在当前条件下完成了一次。真正决定你换条件后还能不能做的，是你从操作中带走的是动作步骤，还是步骤背后的关系。记住“翻炒三十秒”，换一种食材就不灵；留意到翻动让食材受热更均匀，换个食材你还能用。

## 记住了“炒三十秒”，还要弄清什么？

假设一份菜谱写着“大火翻炒三十秒”。先别急着背时间，看看这一步想让食材达到什么状态。假如目标是把青菜炒熟，同时保留一些脆嫩口感，你就需要关注加热过程中软硬的变化。

菜谱里的火力和时间都有具体条件。灶具、锅的材质和一次下锅的菜量，都会影响实际受热。同样拧到最大火，锅里的情况未必相同。

可以把步骤拆开，写一张简单的对照表。


| 操作或提示 | 这一步起什么作用          | 还需要留意什么                    |
| ----- | ----------------- | -------------------------- |
| 调节火力  | 改变加热的强弱           | 结合锅和灶的情况判断，别把“大火”一律理解成开到最大 |
| 翻动食材  | 改变食材与锅面的接触，让受热更均匀 | 有没有一部分一直贴着锅底，另一部分翻不到       |
| 参考时间  | 控制持续加热的时长         | 时间要和食材的实际状态一起看，三十秒不能保证刚好熟  |
| 出锅装盘  | 让食材离开仍在供热的锅       | 食物本身仍有余热，出锅后变化未必立刻停止       |


这样拆开，就能分清翻动和计时各自在做什么。翻动影响受热的分布，时间关系到加热持续多久。把两者都记成“照着做三十秒”，容易漏掉需要判断的地方。

接着把注意力放回手上的操作。翻动时感到的软硬变化，和你看到的食材状态是否一致？准备出锅时，你依据的是倒计时，还是已经观察到目标状态？这些问题能帮助你把感觉、操作和判断联系起来。

如果某一格写不清，就去看教程有没有解释，或者请熟悉这道菜的人示范。刚开始学习，完全可以先借助别人的说明，再在操作中核对。对照表只用来找出自己还没弄明白的地方，填满它并不能保证理解。

## 换种食材，你还知道该怎么调整吗？

现在把青菜换成胡萝卜片。原来的时间还能照搬吗？切片的厚薄，会不会影响你对翻炒时间和出锅时机的判断？

如果你能结合食材特点和想要的口感，决定哪些步骤需要调整，操作时也知道观察什么，就比只记住“三十秒”多了一些可用的判断依据。

检查时可以保留计时器和自己的记录。先试着作出判断，再和可靠的做法对照。重点是逐渐减少对每一步提示的依赖，正常使用工具并不妨碍这件事。

遇到不会调整的地方，也别急着给自己下结论。你可能懂得火力和时间会影响结果，却还不知道这种新食材的特点。这时需要补的是食材知识。

如果换食材带来了太多陌生情况，就把变化缩小些。例如仍然用熟悉的胡萝卜，只改变切片厚薄，其他条件尽量接近。做之前想想哪一步可能需要调整，做完后再比较预想和结果。这样更容易看出，自己是漏看了食材状态，还是对某一步的作用理解有误。

一次做对、一次做错，都不足以判定理解到什么程度。多看几次表现，结合你作判断的依据；隔几天再做一次，也能帮助检查哪些东西真正记住了。

## 学新东西，每次都得亲手做一遍吗？

前面两个实验都显示动手有帮助，但这不意味着每学一样东西都得亲手做一遍。

判断要不要动手，可以先问两个问题。第一，你要学的关系能不能通过动作表达？翻动食材和受热均匀之间的关系，你能用手感受到。但有些关系很难用动作表达，硬安排一套动作反而让人忙于操作，顾不上思考。第二，你现在的理解缺什么？如果看图、听解释已经能理解一个关系，就不必额外补动作。如果你照着做了却说不清为什么，那检查一下手上的感觉有没有帮你理解步骤的作用，可能比再听一遍讲解更有用。

有研究发现，先学实物操作还是先学手势，效果受到学习者原有知识状态的影响。同一种安排，对不同的孩子未必合适。

无法完成某个指定动作的人，同样可以借助观察、图示或讲解学习。具身认知说的是身体经验可以参与理解，不是说你必须通过某个特定动作才能理解。所以，不是每次都得亲手做。但如果你照着做了却说不清为什么，检查一下手上的感觉有没有帮你理解步骤背后的关系，可能比再找一套动作更有用。

## 跟着教程做完后，问自己哪三个问题？

不必每学一样东西就画一张表。可以先挑一个你照着做过、又说不清为什么的步骤，问问自己。

**第一问，这一步要达到什么效果？**

炒青菜时，你希望它熟到什么程度？火力和时间分别会影响什么？不清楚的地方，先从教程的解释或熟手的示范里找依据。

**第二问，我做的动作起了什么作用？**

翻动改变了食材接触锅面的位置。做的时候，你能观察到哪些变化，又从中获得了什么判断依据？如果只能描述“手怎么动”，还可以继续追问它与结果的联系。

**第三问，换个条件，我还能自己判断吗？**

在允许使用工具的情况下，减少逐步提示，尝试一个小变化。做之前给出自己的判断，做完再对照结果。卡住了，就找具体缺口，下一次只针对那里练。

手感可以是理解的一部分。揉面时能根据软硬调整加水量，即使一时说不完整，也有实际价值。但手感本身也需要检验：这份判断能适应多大的变化，遇到陌生情况时，你是否知道该补充什么信息。

回到开头的问题。你照着菜谱做对了一盘菜，换种食材却不会了，原因可能不止一个。具身认知提醒你检查的，是其中最容易漏掉的一个：动手时获得的感觉，有没有帮你理解步骤背后的关系。记住了“翻炒三十秒”，你带走的是一个动作步骤；留意到翻动让食材受热更均匀，你带走的是关系。前者换个条件就失灵，后者换个条件还能用。

下次做完一道菜，先挑一个步骤想清楚。等条件变了，你至少知道从哪里开始调整。

**模型档案卡**

**模型名称**　具身认知（Embodied Cognition）

**一句话定义**　身体的感觉、动作以及与环境的互动，可以参与我们的理解和思考。

**来源**　具身认知包含多种理论。认知心理学家巴萨洛（Lawrence Barsalou）1999年提出“知觉符号系统”理论，2008年发表“接地认知”综述，是其中有代表性的研究。

**调用提示**　先弄清步骤想达到的效果，把动作和可观察的变化联系起来，再换条件检查自己的判断。

**适用情形**　跟着教程能做，换个条件就拿不准，想检查操作经验是否帮助自己理解了相关关系。

**使用边界**　动作的作用要结合讲解、图示和学习者已有知识来判断。找不到合适的动作就不必勉强。检验理解需要参考多次表现，一次成功或失败都不能直接下结论。
