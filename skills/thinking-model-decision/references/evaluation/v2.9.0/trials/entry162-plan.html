机会成本决定试算方向，不能直接决定数量

使用 TM-162「比较优势」：甲每做 1X 放弃 20÷10 = 2Y；乙放弃 45÷15 = 3Y。甲在 X 上机会成本较低。反过来，甲每做 1Y 放弃 0.5X，乙放弃 1/3X，乙在 Y 上有比较优势。甲两项都快，说明它有两项绝对优势，不说明乙“没有用”。

值得试算的方向是甲替乙做 X、乙替甲做 Y。乙只需要 1X，所以正向交换 X 数量只能是 1；甲只需要 3Y，所以交换 Y 的数量只能是 1、2、3 张。不能用半张、2.5 张或新加需求补出一个比例。

忽略协作成本时，双方严格省时需 2 < y/x < 3。计入成本后，甲净省 = 10y − 20x − 2；乙净省 = 45x − 15y − 3。x = 1 时要求 y > 2.2 且 y < 2.8；不存在这样的整数 y。

为什么不是漏掉了别的整数安排

把全部需求在两人之间分配，令甲生产 a 份 X、b 张 Y，则 a ∈ {0,1,2}，b ∈ {0,…,6}；乙生产其余 2−a 份 X、6−b 张 Y。这覆盖 3×7 = 21 个数量分配。自做对应 (1,3)，其他代做安排的工时为：

甲 A = 20a + 10b + 2；乙 B = 45(2−a) + 15(6−b) + 3。

甲做 X 数量要满足甲容量 A ≤ 52此时乙最少工时结论
a = 0b ≤ 5B ≥ 108乙不能在 85 分钟内完成。
a = 1有代做时 b ≤ 3代做数量分配至多 b=3 时 B=93；其中 (1,3) 不代做则乙 90全部超过乙容量；无必要的同类互换只会新增成本。
a = 2b ≤ 1b=0 时乙 93；b=1 时乙 78只有 (2,1) 同时满足容量，但甲 52 不严格小于自做 50。

因此，不只是“完全专业化失败”：在题设固定效率和成本下，全部合法整数数量分配中，没有满足原目标的安排。不增加 WW 同义工具；TM-162 已提供目标、机会成本、数量、逐人净收益、容量、日程和意愿的完整转换。

什么变化才会改变结论

  • 只降低交接成本未必够。1X 对 2Y 时甲未扣协作前正好持平，因此甲的协作成本即使降至 0，仍不严格省时；1X 对 3Y 时乙未扣成本也正好持平。单纯把 2 / 3 分钟减少到非负数，不能解决本题的严格整数互利问题。
  • 仅延长截止或扩大容量也不创造逐人收益。它能修正晚交付或超载，却不能让当前负的净节省变正。
  • 接受条件改变：甲真正愿意用 52 分钟换取乙省 12 分钟，且乙接受，这才使 1X 对 2Y 候选可用；仍须检查两人的实际时间和 10:25 截止。
  • 生产技术改变：作为阈值示例，若仅甲每份 X 耗时由 20 降为 t，其他条件不变，1X 对 2Y 时甲净省 = 18−t、乙净省 = 12；t < 18 时双方才都严格省时，t = 18 时甲仍持平。此时甲新工时 2t+12、乙 78，再核容量。这里是假设分支，不声称明天有这样的工具。
  • 需求、完整件规则、质量或开始时间改变：按新事实重列完整基准和可交换数量；需求改变不自动改变机会成本比值，单位效率改变才重算方向。质量不等、存在等待或任何一人拒绝，都停止沿用旧方案。
