# v1.4.1 跨 Agent 安装说明检查

日期：2026-10-01。版本 1.4.1，库修订号 11。本次只修改安装与调用说明；HTML 行动计划、模型选型和知识内容保持不变。

## 发现与修正

| 原表述 | 问题 | 修正 |
|---|---|---|
| “把整段话复制到 Codex”“请使用 skill-installer” | 把通用技能的受众和默认安装方式绑定单一产品 | 改为发给当前支持 Skill 的 AI Agent，使用该 Agent 的安装方式 |
| 手动安装仅给 Codex 目录 | 其他产品可能使用导入界面、不同目录或不同 ZIP 结构 | 说明完整技能目录、按产品要求导入/重打包及检查目录层级 |
| 默认示例都带 `$` | 容易被理解成跨 Agent 通用命令 | 通用示例使用技能名称；将 `$thinking-model-decision` 标为 Codex 示例 |
| 安装工具的覆盖行为写成统一规则 | 不同安装器可能停止，也可能覆盖 | 更新前检查并备份本地新增模型和修改，按实际安装器处理 |
| 安装、文件加载及成功运行边界不够清楚 | 仅显示技能名或读入口文件不足以证明完整安装 | 分别核对实际位置、版本、资料可读、技能识别与简单调用；临时文件加载不称持久安装 |

依据 [Agent Skills 格式规范](https://agentskills.io/specification) 核对入口元数据与目录结构；[官方概述](https://agentskills.io/home) 说明该开放格式面向兼容的 Agent 跨产品复用。没有将“采用通用格式”解释为所有产品和版本均已实测。

## 实际检查

- 独立只读审阅入口、引用路径和脚本，未发现核心运行流程要求 Codex、`skill-installer` 或 OpenAI 专用工具。`agents/openai.yaml` 仅为客户端元数据，保留供支持它的客户端使用。
- 把完整技能包复制到含空格的中立目录，移除该测试副本的 `agents/openai.yaml`，从另一个工作目录执行检查：官方 `quick_validate.py` 通过，`library.py validate` 通过（错误和警告均为零），`library.py show TM-054` 成功定位该副本中的原文与卡片。未修改原包的可选元数据。
- 知识库保持 126 篇用户原文、126 张卡片、100 个 WW 工具；477 个知识资产逐字节不变，索引、目录、模型关系、报告规则、HTML 模板及脚本均不变。
- README、安装指南、使用指南与技能入口的文案交叉检查；本地文档链接检查通过。安装请求采用 `text` 代码块，不冒充 YAML 配置。
- 本次没有改动决策分析流程，因此未重复 v1.4 的五条行为试跑或 HTML 布局检查；历史记录继续保留原测试版本。

## 验证边界

中立目录测试验证的是文件结构、资源定位和脚本可移植性，不是其他品牌 Agent 的真实安装或端到端运行。本轮没有登录或安装到其他产品，也没有验证其技能发现、上传限制、操作系统差异或全部工具权限。具体安装目录、启用方式与能力，以使用者当前 Agent 的官方说明和实际检查为准。
