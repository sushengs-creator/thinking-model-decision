# v2预览的实际输出

这里保存虚构案例的独立Agent实际回答，用于检查运行行为。用户私人案例未用于本轮测试。

- `batch-a.md`、`batch-b.md`：8工具，每工具一个适用及一个边界场景，共16条回答。
- `entry-regressions.md`：不点名模型的2条直接入口回答。
- `non-choice-regression.md`：修复入口后，学习难题直接进入解释与练习的1条回答。
- `entry-round-1.md`至`entry-round-3.md`：同一个虚构案例逐轮提供消息，包含澄清、HTML交付及新事实到来后的修订；旧版与新版HTML均保留。
- `design-review.md`：修订前的独立审阅快照。入口的选项前提和交付路径问题已在最终包修正。

为让预览包可移动，记录中的本机绝对路径已经替换为相对路径或`<preview-skill>`；HTML的来源链接同样改为包内相对路径。原始记录中的字节数和SHA-256是当时工作区原文件的验收值，不是路径转换后副本的指纹；最终包的`manifest.json`记录交付文件指纹。原消息和实际回答的内容没有据评审结论改写。

这些有限模拟不证明真实用户效果、跨客户端一致性或全库可靠性。文件结构与来源完整性、行为输出、现实结果分别评价。
