# 原始用户请求

用思维模型决策工具直接给下一步行动建议，纯文字即可。我负责一个10人设计团队。外部培训后，大家在新练习中都能正确完成；资料、权限、交接负责人也清楚。但两名新人提出不确定之处时，组长在群里说“这么简单都不懂”，之后新人只敢私下找熟人，不愿在复盘提问题。我亲眼看到那两次群聊，其他成员的经历还不知道。同类返工仍反复发生。有人提议再买培训，有人建议周会上强制人人讲一次错误，证明我们开放。我希望两周内改善问题发现和处理，不能降低交付质量；我每周只能投入45分钟管理时间。请说明行动依据、可继续的部分和何时改判，不必等我补充全部信息。

# 实际完整回答

建议先做两周的小范围改进：纠正组长羞辱提问的回应方式，提供可信的反馈渠道，再把一类反复返工的问题处理到底。暂缓购买通用培训，不采用“人人当众讲错误”的要求。交付标准和已有审核继续执行。

这是阶段性判断。要解决的是：在你每周45分钟的管理投入内，让不确定之处更早进入核查、得到处理，并检查后续任务是否改善。两周可以检验处理方式是否开始起作用，还不能据此宣布全队已经形成心理安全。

按你的陈述，已有两次你亲眼见到的贬低性回应，随后两名新人转向私下求助。这足以支持立即纠正这两次行为；但我没有独立核查群聊，其他成员的体验也未知，不能把局部证据扩大成“全队都害怕”，更不能认定全部返工都由此造成。

本次主模型是 TM-139《团队心理安全》：它把第一步从“让新人更勇敢”改为“改变开口后的实际待遇”，并要求把表达、处理和任务结果分别验收。补充用 TM-140《吸收能力》检查竞争解释：新练习能正确完成，是已掌握部分知识的积极证据；资料、权限和负责人清楚，也削弱了“再买一轮通用培训就能解决”的理由。但练习成功仍不能证明真实设计任务中的边界判断、负荷和方法适用性都没问题。

几个选择的取舍是：再买培训有可能补实际技能缺口，但当前尚未找到缺什么，会增加成本且保留已知的提问障碍；强制公开讲错误会要求成员再次暴露自己，发言次数也证明不了开放；维持现状虽省管理时间，却让已见到的回应方式继续存在。因此先修正回应、处理一个具体卡点，最贴近两周目标，也能为下一步提供证据。

第一周，你的45分钟建议这样用：

1. **10分钟，与组长单独明确行为要求。** 只谈你亲眼看到的两次回应和需要改变的动作：成员提问后，先确认卡在哪里、依据是什么、可能影响什么，再回答、核查或指派处理者。可以指出具体操作错误，不能以“这么简单都不懂”评价提问者。要求组长对原群里的不当回应作简短更正；是否真的做到，后续看实际回应。不要要求新人先来证明伤害。
2. **5分钟，在原群里明确工作规则。** 由你纠正已经公开发生的行为，不引用新人私下说过的话、不要求他们回应或接受道歉。可以说：“前面以‘这么简单都不懂’回应提问不合适。遇到不确定之处可以提，接收者需要帮助核查并反馈处理结果。交付仍按原标准审核。”取消强制公开讲错误，复盘保留自愿发言和事前提交问题。
3. **10分钟，分别与两名新人短谈。** 每人约5分钟，围绕最近一个具体卡点，了解他们愿意通过什么渠道提出、哪些内容可以转给处理者。明确谁能看到信息、何时会得到进展；小团队里的案例可能被识别，不承诺绝对匿名。先由你直接接收，再在本人接受的范围内转交工作问题，避免让组长成为唯一入口。
4. **5分钟，补充其他位置的体验。** 用简短的私下文字沟通，邀请一名老成员和一名不同协作位置的成员描述最近一次提问及实际回应。对方不愿或来不及回答就保留未知，不以没有反馈证明没问题。这只是补充线索，不代表覆盖全队。
5. **15分钟，选一类返工并启动处理。** 与现有交接负责人或审核人，从已有返工记录中选一个重复、影响交付的具体卡点；回看少量近期可比任务，确定当前返工表现。只开一条问题记录，写清事实、影响、处理者、动作、完成标准和下一次任务的复查时点。优先安排本周内能验证的修正，避免扩大为全面流程改造。

日常处理建议由已有交接负责人或审核人承接，并在上述时间内确认其容量和本人是否适合作为接收者。每个问题只补一条短记录，接入现有工作与审核，不另设每日报告。若没有可信且有容量的人承接，就缩到一个卡点、由你按约定时点跟进，不承诺覆盖全部问题。可能影响当前交付的异常继续走现有及时升级和审核流程，不能等到下周管理时段。

第二周仍控制在45分钟：

1. **10分钟，回访两名新人，并查看其他成员愿意提供的反馈。** 看有没有实际提出问题、接收者怎样回应、之后有无不利对待；没有提问时先了解原因，不当成成功或失败的直接证据。
2. **15分钟，与处理者检查闭环。** 问题是否核查过，改了什么，未解决的原因是什么，报告者是否知道进展。收到问题、说了感谢、改了文档，都还不等于解决。
3. **15分钟，检查修正后的可比真实任务。** 利用已有审核记录，看同类卡点是否再次出现、任务是否达到原质量标准、是否仍需他人临时补关键判断。若自然发生了换人交接，顺便检查下一位使用者能否完成；若两周内没有相应任务，就记录“尚未验证”，不额外制造交付风险。
4. **5分钟，给团队简短反馈。** 说明一个问题怎么处理、效果如何、还有什么待验证，只发布必要的工作信息，不公布谁曾私下求助。确定继续、调整或停止哪项试行安排。

可继续的部分包括：已经有效的培训内容与练习、现有资料和职责、原交付标准、审核与必要的同伴支持。私人求助本身不必被禁止；经当事人认可，把可复用的工作问题交给负责人处理即可。不能因为追求“独立掌握”就撤掉必要支持，也不能把持续由熟人补关键步骤说成已经独立掌握。

两周内分别看三类信号：

- **表达是否可行：** 提出问题后实际受到怎样的对待，约定渠道是否可用。公开发言人数和报告总数不作达标指标。
- **处理是否完成：** 问题有无核查、负责人有无采取具体动作、结果是否反馈给提出者。
- **工作是否改善：** 同类任务在原质量标准下是否少了重复卡点和返工；同时记录任务量、难度、审核覆盖与支持投入，避免把条件变化误算成效果。报告变多可能是发现渠道打开，变少也可能是继续沉默，不能单看数量下结论。

出现以下证据时改判或调整：

- **组长再次羞辱，或有人因提问遭排斥、被不当区别对待：** 立即处理具体行为，调整接收者与升级安排，必要时按已有管理制度处理；不要等满两周，更不要靠追加公开发言来解决。
- **成员能提出问题，但得到的答案慢或不可用：** 把重点转向响应责任和答案核验。仅增加表达机会已经不够。
- **真实任务暴露了可定位的知识或边界判断缺口：** 保留回应规则，同时安排针对该缺口的示范、练习或支持；这时才评估是否需要外部培训，并以真实任务表现验收。
- **大家会做，但赶工、流程或方法不适用导致反复返工：** 改负荷、流程或采用条件，必要时暂停该方法的应用，不能继续归因为不敢说。
- **质量下降或处理量超出可承接容量：** 缩小试行范围，维持原审核和交付标准，先处理风险最高的问题；不能以两周见效为由放行不合格交付。
- **两周后表达待遇改善、问题有闭环、可比任务也改善：** 保留这套简短安排，继续观察；若只有前两项改善，继续查返工原因；若没有足够可比任务，只能判断流程是否执行，暂不声称绩效改善或证实唯一原因。

依据为本包实际读取的 [TM-139《团队心理安全》操作卡](../../cards/TM-139.md)及 [TM-140《吸收能力》操作卡](../../cards/TM-140.md)。上述时间分配与安排是针对你的约束提出的建议，尚未对任何成员作出承诺或实际执行。
