# v1.4 HTML 下一步行动计划验证

日期：2026-10-01。Skill 版本 1.4.0，库修订号 10。本次改变报告交付方式，不增加模型、不改变知识条目成熟度。

## 变化与验证范围

默认交付从聊天中的决策报告变为实际保存的 HTML 下一步行动计划，覆盖完成分析、用户要求阶段性建议和后续报告更新。补入通用离线模板、行动依据、时间/触发条件、责任、依赖、完成与调整标准，以及文件读回、窄屏和打印检查。保留逐轮澄清及用户指定其他格式的选择。

## 实际行为试跑

由两个独立执行上下文使用当前技能处理虚构输入。输入见 [五个场景](html-action-plan-cases.md)，实际回复与读取范围见 [回复记录](v1.4-responses.md)。执行者未收到预期答案或评审标准。

| 场景 | 实际观察 | 判断 |
|---|---|---|
| A：材料充分、未指定格式 | 直接读取模型、比较选择，保存 HTML 并返回真实链接；第一周与第二周各 180 分钟，均计入试验和验收 | 通过 |
| B：只有笼统困惑 | 只问一个主要澄清问题，没有虚构背景或生成完整计划 | 通过 |
| C：明确只用文字 | 给出文字建议与行动，未强加 HTML；测试日志属于评估记录 | 通过 |
| D：关键条件未知且要求阶段性判断 | 不再追问，保存阶段性 HTML；报酬、工作量、日期及目标保留未知，提供核实动作与停止条件 | 通过 |
| E：A 的约束改变 | 保留初版，新建修订 HTML；每周从 180 分钟改为 60 分钟，放宽完整交付目标，说明旧安排失效及模型侧重点变化 | 通过 |

可直接查看 [A 初版](v1.4-artifacts/standard.html)、[D 阶段版](v1.4-artifacts/provisional.html)、[E 修订版](v1.4-artifacts/updated.html)。这些是虚构测试输出，不是对所有人通用的建议；公开副本仅调整来源和产物链接以适应目录迁移。

## 结构、文件与布局检查

- 官方 `quick_validate.py` 结构校验通过；入口版本、库状态版本及界面文案一致。
- `scripts/library.py validate` 通过：126 篇用户原文、126 张模型卡、100 个 WW 工具，错误与警告均为零。
- 与 1.3.0 基线逐字节比对：477 个知识资产未变；索引、目录、关系规则及维护脚本未变。旧验证继续保留原测试版本，不冒充本次覆盖。
- 新旧 Markdown 本地链接及新增 HTML 来源链接检查通过；三个报告均为 UTF-8 完整文件，没有模板占位符或脚本。通用模板中的占位符为预期资源，交付实例已全部替换。
- 通用模板和三个实际报告均用本地 Chromium 检查 1440、768、390 像素宽度，以及打印媒体布局与 A4 PDF 导出：页面无水平溢出、窄屏表格局部滚动、打印表格未超过容器、无重复 ID 或失效锚点、无脚本错误及自动网络请求。查看了桌面与窄屏截图；未进行实体打印。布局数据见 [检查记录](v1.4-layout-checks.json)。

本次没有发现需要改变模型机制或选型规则的问题。同步安装时保留本地独有的历史测试记录，公开包只使用虚构场景及通用资源。
