# TM-129、TM-130、TM-132 独立行为试跑原始记录

日期：2026-10-07

范围：仅读取指定草稿卡，进行六个彼此独立的用户场景模拟。以下为直接面向场景用户的实际输出；没有执行现实操作、联网、生成 HTML 或修改模型卡。每个场景分别尝试指定模型，不预设适用。未调用 WW 补充工具。

## B1

指定尝试：TM-129。

使用 ID：TM-129（主用，适用）。

输入：结算负责人离职，留下很多文档和联系人，我接手仍判断不出一笔退款卡在哪，别人给的答案像在说不同系统。怎样交接才有效？

实际输出：

先拿这一笔退款完成一次交接演练。你现在最明显的卡点，是各方答案可能没有对应同一笔业务、同一阶段或同一版本，暂时不能认定钱卡在银行。把交易号、退款申请时间、客户所见状态、需要判断的问题放在一张记录里；请实际处理商户审批、结算、汇款的人分别提供对应记录、时间、规则版本及尚未确认的部分，核对编号如何跨系统对应。联系人有名无回应、记录打不开，也要单独记下。

交接表只保留这条路径需要的信息：谁懂哪一段、入口与权限、依据、维护人、备份人和下一步责任。由你亲自查询、联系、处理一个例外并解释当前状态，请相关人员核对依据；找到卡点后交给有权处理的人。下一笔同类退款能独立查清，才算交接通过。若答案仍冲突，继续核对时间和定义；若事实已齐却无人愿意或有权推进，就转向权责安排，继续加文档帮助有限。

## B2

指定尝试：TM-129。

使用 ID：TM-129（仅用于边界诊断，停止扩展知识地图；后续为一般资源决策建议）。

输入：专家和记录都找对了，三个部门也确认当前版本一致；但谁也没有预算购买必需的检测设备。继续建知识地图能解决吗？

实际输出：

继续扩建知识地图解决不了眼前的设备缺口。你给出的信息已经排除了找人、取得记录和版本对齐这几处主要障碍；当前已知阻碍是没有采购预算。先让技术负责人确认设备必须满足的检测能力，以及没有设备时哪些结论不能作出，再把缺口交给能统筹预算或调整任务范围的负责人。三部门都没钱，不等于组织层面已作过取舍。

准备一页可决策材料：任务期限、最低检测要求、现有资源缺口，以及购买、合规借用、委托检测或延期的可行性、成本和责任，交由有权限者选择；不要未经验证就拿替代设备凑数。在决定前，明确等待期间能继续哪些准备工作、哪些检测结果不能承诺。约定一个决策期限，到期没有资源就升级或调整交付承诺。若评估时发现大家对检测要求仍有实质分歧，再回头核对知识；若要求一致、只是不同意谁承担费用，应处理资源分配和责任。

## B3

指定尝试：TM-130。

使用 ID：TM-130（主用，适用）。

输入：团队每月复盘并修改话术，考核仍只看当天关单数，客户重复来问没减少。我有一个小组试点授权，要怎样检验规则是否该改？

实际输出：

可以把“只奖励当天关单，可能促使团队过早结束处理”作为待检验假设。先抽取近期同类工单，还原几次关单决定：问题是否解决、为何关闭、后来是否重复联系；同时找反例，检查是否其实是产品缺陷、客户补充慢或系统状态受限。你已有小组试点授权，先核对是否包含评价方式调整，再确定试点范围和周期。

若证据支持评价失配，试行一个有限改变：按事先约定的解决依据区分“已解决”和“待补充”，评价同时看解决情况与处理量。采用检查是抽查客服是否实际使用新依据、主管是否据此评价，并记录关单理由；效果检查是同类工单在相同观察窗口内的重复联系率、积压和等待时间，比较试点前及同期可比小组，注明业务量差异。两项分开验收：没采用，先查工具、权限和激励；采用后重复联系仍多或积压明显恶化，修订原因假设及方案。初期好转只能支持继续观察，不能直接推广为长期有效的新制度。

## B4

指定尝试：TM-130。

使用 ID：TM-130（边界适用；先执行既有处置，暂不启动全面规则重构）。

输入：生产线这次因漏看明确步骤出现危险，现场仍未处理。有人建议先暂停处置，开会重新定义全部安全标准。双环学习是否更高级？

实际输出：

双环学习不天然更高级，也不能成为延误危险处置的理由。现在首先按适用的现场应急规程通知负责人，在自身授权范围内执行停止危险作业、隔离等规定措施；超出权限的事项立即升级，由具备资格和权限的人处理。不要为了开反思会让人员继续暴露，也不要临时自行发明或取消安全标准。

现场安全受控后，再还原这次遗漏：步骤是否可见、交班是否覆盖、操作者是否受过相应训练、当时是否存在赶产量等约束。已知是漏看明确步骤，并不足以证明全部标准错误；如果标准合理且能够执行，先修复执行条件，用实际操作确认步骤得到遵守。如果进一步记录显示赶工奖励持续压过必要检查，或规程在真实条件下无法执行，才把相关评价规则或程序前提列为待检验项，交有权人员审议。复查既要看要求有没有实际落实，也要看危险是否降低；再次遗漏应触发原因重查，不能只归咎个人，也不能自动推定必须推翻制度。

## B5

指定尝试：TM-132。

使用 ID：TM-132（主用，适用）。

输入：我买课是真想学，晚上八点闹钟总撞上工作消息，空闲又找不到笔记。想安排可持续开始，不想继续骂自己懒。

实际输出：

你已经提供了两个具体障碍：八点提示常落在不能立即学习的时刻，真正空闲时又有找资料的成本。先把“愿意学”与“那一刻能开始”分开，不必用懒来解释。今晚把课程入口、上次笔记和下一小节放在一个固定位置，写明下次只做什么。候选动作可以是“打开这一页，学一个概念并用自己的话写一句解释”，给自己留五分钟，之后是否继续自行决定。

把固定八点闹钟改为更贴合实际的信号，例如完成当晚一轮工作收尾、确认接下来五分钟可用后，打开已准备好的页面；若这一信号经常不出现，就换一个你真实拥有的空档。先试几次，简单记下有没有注意到提示、当时能否做、停在哪一步。为尽快开始，可以同时改时机和材料准备，但不能据此认定是哪一项单独起效。几次之后复看：仍被工作占用就重排时机；能开始却解释不出内容，就补示例、练习和反馈；条件具备仍不想学，再检查这门课是否服务你现在的目标。

## B6

指定尝试：TM-132。

使用 ID：TM-132（仅用于区分启动与成果，后续转向技能练习与反馈；不叠加其他模型 ID）。

输入：我每天打卡读一行，已连做两周，却仍看不懂工作报表。朋友说只要把提示多加几个，MAP凑齐就必然学会。请分别给实际建议，不预设卡一定适用。

实际输出：

你已连续两周开始阅读，说明“有没有启动”不是目前最需要加码的环节；读一行的动作本身，也未必足以训练理解报表。MAP帮助检查一次行动发生时的条件，不能把几个要素凑齐理解为必然学会。先保留现有提示，不急着增加提醒，把目标换成一项能检验的能力，例如解释某张报表里一个指标的定义、分母、变化及可支持的判断。

用一份获准使用的样例，先独立写出解释，标记不会之处，再对照说明或请懂业务的人指出具体错误；若连术语都不懂，就先补这个概念和一个示例。下一次换相似报表，不看原答案再解释一次，才能发现是否只是记住句子。学习记录同时留下是否开始和解释哪里正确，不再只数打卡天数。完成几次带反馈的练习后复看：如果开始稳定、错误仍重复，调整教学材料或寻求指导；如果练习太难而无法开始，再用MAP降低准备阻力或拆出有意义的一步。练习进度慢也不等于你不够想学。
