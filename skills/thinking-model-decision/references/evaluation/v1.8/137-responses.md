# TM-137 独立试运行回答

记录日期：2026-10-14。以下是两个独立虚构请求的完整输入与回答；均遵从用户的纯文字要求。

## 请求 C

### 完整输入

用技能直接给纯文字培训计划。新人用计算器除法算得对，但看记录甲访问80人成交12人、乙访问240人成交24人时，总说乙比例更高，因为24比12多。现有教程每题都换行业背景、颜色和行序。明天我只有15分钟，该继续加案例吗？工作允许用计算器。

### 回答

明天先停止批量增加案例，用15分钟安排一组专门区分“成交人数”和“成交比例”的对照。计算器继续用，初期固定行业背景、颜色和版式，最后再换行序检查是否真正会判断。

这次目标是：在时间范围和统计口径一致的两份记录中，新人能分别比较成交人数与成交比例，说清依据；资料缺少访问人数时，知道不能直接比较比例。

你提供的记录是甲12÷80＝15%，乙24÷240＝10%。所以乙成交人数更多，甲成交比例更高。新人会用计算器算除法，却用“24比12多”解释比例，提示他可能没有把成交人数与访问人数的关系用于判断。这个假设有依据，但尚不能排除“比例”一词没理解、读题要求混淆或依赖原表线索；不能把会算除法等同于已经理解比例。

我采用 TM-137「变易理论」。它改变的是案例的设计方式：先确定要让哪个区别显出来，再安排什么变化、什么不变，而不是靠案例数量或背景丰富度推动学习。

建议由你担任培训者，按下面的15分钟安排执行。以下新增数据是教学用例，答案先由你掌握，等新人作答和说明理由后再反馈。

1. **第0—2分钟：校准任务与已有判断。** 保留他已说过的“乙比例更高，因为24比12多”作为起点，明确今天要回答的是两个问题：“谁成交人数多？”“谁在自己的访问人群中成交比例高？”确认他知道“成交人数”和“访问人数”各指什么。原始两份记录是否属于同一时段、同一统计口径还需核实；若不一致，先用明确设定为可比的教学记录练习，不拿它们评价真实经营。

2. **第2—6分钟：固定成交人数，只改变访问人数。** 给两份记录：第一份访问80人、成交12人；第二份访问240人、成交12人。背景、版式、时间范围和口径保持相同。让新人先判断人数是否相同、比例是否相同，再用计算器核对并解释。参考答案：人数相同，比例分别为15%和5%；同样12个成交放在不同大小的访问总数里，占比不同。重点反馈分母代表什么，不只纠正答案。

3. **第6—9分钟：改变人数规模，保持比例不变。** 给访问80人、成交12人，与访问160人、成交24人的记录。让新人分别比较人数和比例。参考答案：后者成交人数更多，但两者都是15%，因为成交人数和访问人数同时扩大为原来的两倍。这一组检查他是否仍把“成交更多”直接等同于“比例更高”。不要求为了套名称再补齐四种练习。

4. **第9—13分钟：换一组数据检验判断。** 给访问40人、成交8人，与访问120人、成交18人的新记录，交换两行的位置，取消暗示答案的颜色；时间、口径、字段含义仍保持一致。让新人使用计算器，分别排序并解释。参考答案：18人多于8人，但8÷40＝20%，18÷120＝15%，所以成交人数与成交比例的排序相反。培训者记录他是否自己选择了正确的分子、分母，还是需要提示。若他卡住，先看过程，再决定补哪一步，不直接再换十个行业。

5. **第13—15分钟：检查是否知道资料边界。** 只给“某组成交9人，另一组成交14人”，问能不能据此比较成交比例。参考答案：只能比较成交人数，比较比例还缺两组的访问人数，并需要一致的统计条件。最后让新人用自己的话说明“人数更多为什么未必比例更高”，记下这次独立完成和需要帮助的部分。

这样的安排比继续增加复杂案例更适合当前15分钟：它能检验是否忽略分母，同时减少行业、颜色、行序一起变化带来的干扰。固定背景只是这一阶段的安排；一旦关系判断稳定，后续应逐步换行业和呈现方式，检查不同场景中是否仍能抓住相同关系。

明天的完成标准是新题中两种排序正确、依据说得清楚，并能指出缺分母时不能判断比例。使用计算器不扣分；如果得到别人提示，要如实记录为提示后完成。若计算正确却仍按成交人数判比例，就继续补分母及两者关系；若能解释却算错，检查输入、计算或百分数基础；若只在换行序后错，就检查位置依赖。不要把所有错题都归成同一种理解问题。

建议在下一次正常使用这类记录时，再给一题未见过、口径可靠的例子，保留计算器，观察是否仍会判断。明天一次答对只支持当时的表现，不能据此宣布已经长期掌握。

依据：技能包 TM-137「变易理论」操作卡中的“调用步骤”及“边界与易误用处”。计划尚未执行，未记录任何实际培训效果。

## 请求 D

### 完整输入

用工具给纯文字建议。学员原表会，改成小数和分数就常算错；老师说这是没辨识关键方面，要求按对比、分离、概括、融合固定走四步，只要今天答对就算永久掌握。另外比较了两个门店培训后的成交比例，想宣布培训导致业绩增长。请判断这些做法并给下一步。

### 回答

现在应先检查小数、分数的读法与计算基础，再按具体错误改练习；不要强制走固定四步，也不要用今天答对或两个门店培训后的比例，分别宣告“永久掌握”和“培训导致业绩增长”。这几项结论需要不同证据。

根据你的描述，学员在原表能做，换成小数和分数后常算错。这个差异提示数字表达与计算要求可能造成困难，但我们还没有看到他的运算过程，也不知道“会原表”是能解释关系还是记住了答案。老师的“没辨识关键方面”只能作为待查解释，不能作为已确认诊断。

这里以 TM-137「变易理论」为主模型，决定练习中应保持什么、改变什么，以及怎样检查实际理解；补充 TM-056「反事实因果模型」，单独检查培训效果的归因。两个模型处理的不是同一件事：学员会不会判断比例，与培训有没有造成门店业绩变化，需要分开验证。

对学习部分，下一步建议由老师这样做：

1. **先把目标说具体。** 暂以“能读懂记录、准确比较比例并说明依据”为目标。如果教学目标还包含独立进行分数、小数换算，把它另列成一项标准；实际工作允许计算器或对照表时，就保留这些工具，不把记忆和心算要求临时混入比例判断。

2. **拿一小组等值表达定位错误。** 同一个比例分别写成“20%”“0.2”“1/5”，先问各表示什么、是否相等，再看他的转换和计算过程。另给“1/5与1/4”或“0.2与0.25”让他比较并解释。老师的参考答案是1/5＝0.2＝20%，1/4＝0.25＝25%，所以后者比例更高。先收集学员回答，再反馈，不把这些参考答案预先展示成解题提示。

3. **把计算与关系理解分开检查。** 如果他不会解释小数位值、分母或等值换算，先做必要示范，再练这一项基础；如果已经理解关系，但计算或录入错误，补计算步骤和核对方法；如果在老师提供正确计算结果后仍按成交人数来判比例，才更有理由检查他是否把分子、分母联系起来。几类困难可以同时存在，不能只凭“换写法就错”排除其他原因。

4. **按错误选对照，不强制四步。** 若当前卡在等值表达，先保持比例不变，只换写法；若卡在分母作用，就保持成交人数不变，只改访问人数；若只会某一组数，再变规模并保持关系。对比、分离、概括、融合可以重叠、跳过或回头补，选择依据是当前缺口，不是把四个名称依次打勾。

5. **分层记录表现。** 纠正后用未见过的题目，改变数字或行序，让他自己判断并解释，保留目标允许的辅助。记录“原题答对”“新题独立解释正确”“借提示后完成”分别是什么情况。再在下一次课或正常使用机会做延迟检查。今天答对最多支持当前条件下的即时表现；若后来忘了，要调整复习与练习，不能一概说没有辨识，也不能承诺永久掌握。

与“增加更多混合题”的方案相比，这种做法多了一次短诊断，但能避免把数值表示基础的问题误当成比例关系问题。若基础检查均无异常，就把重点移到跨表达、跨情境的新题解释，而不继续无限补基础。

对门店结果，建议暂缓“培训导致增长”的对外结论。你给出的只是比较两个门店培训后的成交比例：没有具体数据和培训前基线，连是否发生增长都还不能判断；即使有前后提升，也不能把全部提升归给培训。

第一步由培训负责人或分析人员核对成交人数、访问人数、统计口径、观察时段、培训覆盖对象及实施时间。如果两个门店都受训，仅比较它们培训后的比例，无法直接提供“不受训时会怎样”的参照。门店原有差异、客源结构、促销、价格、人员变化和随机波动，都可能构成其他解释。成交比例也不等于全部经营业绩；如果要讨论销售额或利润，应另外查看对应指标。

当前可做的是如实描述两个门店在指定时段的成交比例差异；取得可比的前后数据后，可以描述变化，并注明尚不能归因于培训。若需要判断培训效果，先写清“对哪些人实施哪版培训、与什么安排相比、观察哪个指标和多久”。条件允许时，设计合适的随机分组，关注员工互相影响等执行问题；不能随机时，寻找有理由的同期参照和培训前趋势，说明它们能否代表没有培训的情形以及剩余局限。样本规模和自然波动也要纳入判断，不能把只有两个门店的简单比较包装成确定的因果估计。

所以今天最值得做的两件事是：保留一份学员错误过程，确定先补哪项基础或关系；把门店报表中的事实描述与培训因果结论分开，列出缺失的基线和对照依据。后续只有当新题、延迟表现和可信的效果评估分别提供证据时，才逐项升级结论。

依据：技能包 TM-137「变易理论」操作卡，以及 TM-056「反事实因果模型」操作卡。以上为阶段性建议，尚未核查学员答题过程或门店原始数据，也未执行新的教学或效果验证。
