# v1.2.1 高质量 Skill 标准审阅与验证

日期：2026-09-30；版本：1.2.1；库修订号：6。基线为1.2.0/revision 5。PDF逐项标准和具体修复见[公开审阅](https://github.com/sushengs-creator/thinking-model-decision/blob/main/docs/QUALITY-AUDIT.md)。旧版记录不改写为本版测试结果。

## 发现和修改

1. **实际缺陷：来源审计失败后残留旧通过文件。** 先成功生成报告，再使用不存在的源文件，旧程序traceback/exit 1，旧JSON仍`pass:true`。缺目录、坏UTF-8、`[null]`索引也可复现。现提供当次结构化错误、exit 2，尝试刷新指定目录的失败报告；内容差异仍exit 1，匹配exit 0。参数未解析完或输出不可写时，以当次stdout和退出码为准，不信旧文件。
2. **实际缺陷：独立安装附录死链。** `results-v1.1.1.md`原来的跨包相对链接改为公开HTTPS地址，历史结论不变。
3. **静态澄清：触发边界。** description前置用户说法，明确工作/生活/业务决策及本工具维护，排除纯润色、机器学习等相邻任务。旧描述本组选择并未暴露明确误触发，不称为已证实的触发故障修复。
4. **流程细化：交付前复核。** 将已有报告七项要求用于生成后的检查，重点核对硬约束、事实/假设和实际已读来源；不新增用户确认、固定轮数或报告评分。
5. **验证补齐：分开测试发现和执行。** 记录下面的元数据选择与三类实际回复，尤其明确要求隐去风险的催促场景。

## 仅看元数据的选择试验

两个独立执行者分别只收到旧/新名称和description、相同15个原始请求；没有读取正文、目录、模型卡或预期答案。返回选用、不选用或先澄清及理由。结果是模拟判断，**不是桌面客户端真实自动发现率**，也未在完整安装技能竞争列表中测试。

原始数据：[修订前15条](v1.2.1-trigger-before.json)、[修订后15条](v1.2.1-trigger-after.json)。

| 类别 | 请求 | 审阅结果 |
|---|---|---|
| 明确决策 | T01职业去留、T02方案报告、T03业务取舍、T11试点复盘、T13直接有条件建议 | 两版均选用 |
| 明确库维护 | T09新增126篇 | 两版均选用，不把文稿写作当自动入库 |
| 明确非决策 | T04概念、T05仅润色、T06只倾诉、T07机器学习、T12时刻查询、T14错题 | 两版均不启动决策流程 |
| 含糊“模型” | T08新增一个模型 | 两版均先澄清，未猜测是本库文稿 |
| 含糊“报告” | T10上次报告、报价降低20% | 旧版先澄清报告性质；新版选择本技能，理由将其理解为决策报告。仅凭此句不能确定报告性质；这是选择层仍需上下文消歧的边界，不计为无条件正确 |

因此不把15个标签简单宣称“100%命中率”。明确场景表现合理；含糊场景保留解释差异。运行入口要求依据当前可见报告更新，看不到则索取报告或摘要，不能虚构历史。

## 读取技能后的三类运行试验

两个执行者分别读取实际1.2.0、1.2.1入口及必要的对话、报告、关系、TM-062和TM-077卡片，各针对相同的三个虚构请求生成单轮实际回复。没有读评审标准、其他人的回复或先前审阅；未联网、未对外执行、未写入模型库，也未模拟真实用户后续回答。

修前执行者根据实际工具历史确认读取的确为1.2.0，报告文件尚无新增预检段；修后记录明确版本为1.2.1。公开记录仅把本机绝对路径改为包内路径，其他请求和回复保留。

原始回复：[修订前3例](v1.2.1-runtime-before.md)、[修订后3例](v1.2.1-runtime-after.md)。

| 类别 | 输入重点 | 新版实际观察 | 结论 |
