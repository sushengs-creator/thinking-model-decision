我组织社区手工课，这次18份包里有3份少胶带。发放前检查发现了并已补齐，没有影响活动。留存照片显示，15份用新清单，临时桌的3份旁边是旧清单，但我还没问装包的人实际照哪张做。负责人想下次只强调“仔细点”。我想查清并减少复发，请帮我安排接下来查什么、先改什么。

## 实际回答

先保留发放前逐包检查，再把“临时桌旁有旧清单”作为优先调查线索。现在可以统一现场清单版本，但还不能把“照旧清单装包”写成已经查明的原因。

这次明确的偏差是：18份材料包中3份少胶带，发放前发现并补齐，没有影响活动。最终检查发挥了作用。你的目标是减少前面的漏装，同时保住这个已经有效的检查环节。

**目前能说到哪一层：**

| 因果分支／问题 | 现有依据 | 尚未证明的环节与下一核查 |
| --- | --- | --- |
| 临时桌使用旧清单，导致没有装胶带 | 你的照片显示15份与新清单相联系，临时桌3份旁是旧清单 | “放在旁边”不等于实际照着做；也未知旧单是否缺胶带这一项。先对比两张清单，再请装包者还原操作。 |
| 用新清单或包含胶带的旧单，仍在实际操作中漏装 | 目前没有直接支持，属于竞争解释 | 核对胶带是否当时可取、装到哪一步、是否发生中断或换手、怎样判断装完。不能凭空认定人手不足或不认真。 |
| 胶带先装入、之后因移包或返工取出 | 目前没有直接支持，属于竞争解释 | 若装包者确信已放，查移交、搬动、返工和检查记录；不要为了保住旧清单解释而删掉相反叙述。 |
| 为什么能在发放前发现 | 已有发放前检查及补齐的结果 | 这个防线没有失效。核实怎样检查、由谁完成，便于下次保留；不能写成“检查缺失”。 |

**接下来按这个顺序查：**

1. 由你先保留原照片、两版清单及发现缺项的记录，给三个包对应的工作台和已知流程做一个简单标记。对比新旧清单是否包含胶带、数量要求是否相同。若旧单也列了胶带，“旧单漏项直接导致漏装”这条解释就要调整。
2. 请临时桌装包者从开始讲到结束：“你当时拿到什么要求？实际看了哪张？胶带放在哪儿？装完怎么确认？”先让对方讲过程，再核对照片，避免只问“是不是旧清单害你漏装”。同时了解使用新清单的桌面当时怎么做，比较材料供应、分工和交接是否还有差别。
3. 只有查明实际用了缺胶带项的旧清单，才继续追“它从哪里来、为什么仍在现场可用、更新怎样交接”。查看发放记录、现场纸单和相关人叙述。群里发过新版不等于现场已更换；任务单没写收旧单，也不能单凭这一点断言从没人收过。

反向看，候选链是：“旧单缺胶带项＋装包者实际照旧单操作 → 没有把胶带纳入装包检查 → 三份漏装”。现在前两个关键条件都需核实；链条念得通，不表示它已经发生。若实际使用新单，则转查操作和交接分支，不继续凑满五个为什么。

**可先做的改进，以及怎么验：**

| 动作 | 谁／何时（建议，尚待确认） | 落实标志与观察 |
| --- | --- | --- |
| 保留证据后，把旧版从可使用区撤下，统一带版本日期的现场清单 | 活动负责人指定一位清单管理者，下次开工前完成 | 每张实际工作台都有正确版本，包括临时新增桌；旧单留作归档不再供装包使用。 |
| 装包前确认材料要求与胶带供应位置 | 装包者与现场负责人，下次开始前 | 实际使用的清单、材料与任务一致；如缺料或需换手，当场记录并交接。 |
| 保留发放前逐包检查 | 负责人明确一位核对者，下次发放前 | 按正确清单检查所有包，并记录缺项，不因已更新版本而取消检查。 |
| 回看执行与结果 | 你在下次活动发放前后各核对一次 | 分开记录“版本措施落实了没有”和“漏装几份、漏什么、出现在哪一步”；再在后续活动继续观察，不因一次零漏装认定原因已找全。 |

这些是先降低混用机会的临时措施，不反过来证明旧单就是根因。也无需只喊“仔细点”：具体版本、材料、交接和检查责任，比抽象提醒更可检查。

建议本轮先用30—45分钟完成清单比对、两处操作回忆核对与记录；下次开工前的版本核对和材料确认可先安排约10分钟。逐包检查沿用原有必要投入，实际人时另行确认，不能算作免费新增资源。你作为组织者协调，负责人对职责调整确认，装包者是否已接受新安排尚待沟通。

当拿不到更多记录或各方叙述不一致，可以暂时停在“原因尚未查清”，由你记录未决点，负责人确认下一核查人和时间。若更新版本后仍漏装、旧单原本就含胶带，或实际操作与照片推断不符，重开对应分支。补齐、措施落实、漏装减少和原因查明是四个不同状态。
