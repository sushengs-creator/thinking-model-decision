我和室友说好每周日她打扫厨房，这周到了周二还没做，昨天我说“你每次都只顾自己”，她说我就是爱挑刺。今晚我们都在家，厨房现在还能正常用。我想把清洁安排说清楚，也想知道她是不是有别的困难，但不想又吵人品。请帮我准备今晚怎么谈、她不同意时怎么办。

## 实际回答

今晚先把“这一次没按约定清洁”谈清楚，给她解释和提出安排的空间；你可以为昨天的人身概括道歉，同时保留清洁约定。厨房还能正常用，不需要把今晚谈话变成必须立即执行的最后通牒。

**先把原句拆开。**

| 内容 | 这次怎么处理 |
| --- | --- |
| 可核对的事 | 你们约定每周日她打扫厨房；这周到周二尚未完成。以上来自你的叙述，可与双方记忆或记录核对。 |
| 对人格的解释 | “你每次都只顾自己”概括了次数和动机，目前没有材料支持，今晚不继续争这句话真假。 |
| 你的情绪 | 你没有说自己具体是生气、失望还是着急；若想表达，选符合当下感受的词，不必硬填。 |
| 已明确的目标 | 把清洁安排说清，也了解她是否遇到困难。是否还在意公平、可靠等，需要你本人确认。 |
| 可商量的办法 | 补做时点、必要时换班、提前告知方式；她原有清洁责任仍需落实。换班须你也愿意，不能默认由你接手。 |

**可以这样开口：**

> 昨天我说“你每次都只顾自己”，把这件事说成了对你这个人的评价，这句不妥，对不起。我想重新谈这周的厨房安排。我们说好每周日由你打扫，这周到周二还没做。今晚能花十来分钟，确认这次什么时候补、以后临时做不了怎么改吗？我也想先听听，这次是哪里卡住了。

她说完后先确认你听到的内容，例如：“我理解你是说，周日临时有事，之后一直没找到时间，是这个意思吗？”这句只在她确实说了类似情况后使用，不能替她编困难。若她纠正，按她的新说法重述。

**按实际回应推进：**

- **她答应补做。** 确认由谁做、具体哪天几点前完成、厨房清洁包括哪些项目。现有标准清楚就沿用；标准有分歧才现场对齐。可以说：“那我们确认由你在明晚饭后完成原来约定的项目，做完告诉我一声，可以吗？”这个时间只是提议，她答应后才成为新约定。
- **她有困难。** 先听清困难影响的是“这周日程”，还是“每周日这个固定安排”。如果只是这一次，谈补做时点；如果周日持续不合适，再共同调整以后排班。你不愿或没时间换班，就明确说明，继续找双方能承担的安排，不把理解等同于接下全部清洁。
- **她说你爱挑刺。** 可以回应：“昨天那句话我愿意改，也愿意听你觉得哪里被挑刺。厨房这次什么时候补做，我们还是需要确认。”若她指出标准不同，拿具体清洁项目核对；不要为了回到正题而禁止她说明受影响的地方。
- **她不同意你提出的时点。** 请她给一个自己能做到的时间，再检查是否双方可接受。拒绝“今晚做”不等于原有约定自动取消。
- **她今晚不想谈或争吵升级。** 先暂停，建议另约一个明确的短时段，例如明晚双方方便时；让她回应是否可行。厨房目前可用，你不必立刻兜底或反复追问。到约定回复节点仍无安排，明确记录尚未达成一致，并提出一起重订分工；反复失约时，再考虑双方认可的协调人或是否继续现有合住安排。这些是后续选择，不拿来逼她今晚服从。

建议你用5分钟整理事实，谈话先留15分钟，再用5分钟把谈成的安排记下来，总共约25分钟；这是沟通预算，不含实际打扫。若需要你临时帮忙，另算你的时间并征得你同意。记下的简短约定只包含双方确认的内容，别把你的提议写成她已答应。

下一个完成节点，是她承诺的补做时间：查看是否实际完成，再看下一次周日前能否按新约定安排。今天能聊下去、她口头答应、清洁完成和关系改善是不同结果。若仍反复不落实，需要调整合作安排，不能一直归结为你话说得不够好。

本次使用TM-149，把人格判断换成具体事实、核实回应与交接安排；不预言她会接受。
