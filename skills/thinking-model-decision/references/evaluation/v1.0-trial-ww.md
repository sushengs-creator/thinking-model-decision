# 独立试跑：效果推理一周启动方案

## 给用户的完整回答

这周先不决定做培训、工具还是服务。用五小时做一轮小探索：从你已经能做的企业数据分析出发，找到一个具体问题，争取一位愿意共同推进的人，再决定下周把时间投在哪里。

本周能控制的目标是完成最多三次具体邀约、记录实际反馈，并做出下一步选择。希望得到的外部结果是一个小而真实的合作承诺，但不能把对方一定答应当作计划前提。

**先把手里的东西分清楚。**

| 类别 | 目前知道什么 | 本周怎么用 |
|---|---|---|
| 能力 | 你擅长企业数据分析 | 从自己能够独立完成的一项分析动作切入，例如澄清一个指标口径、排查一个数据问题；这些只是候选，具体强项还要由你盘点 |
| 时间 | 每周五小时 | 本周活动累计最多五小时，包含联络、准备、访谈、制作和复盘 |
| 关系 | 认识十家机构的人 | 作为可以尝试接触的入口；目前零承诺，不能记作十个客户或十个合作伙伴 |
| 其他资源 | 未知 | 可用数据、工具、案例使用权限、联系人职责与决策权都未确认；第一天只列实际可用的，不把雇主资料默认当作自己的资产 |
| 方向 | 培训、工具、服务尚未定 | 保留三种形式，让问题和伙伴投入影响选择 |

本周暂定的损失上限是：五小时、零新增现金支出、最多接触三位熟人。只提出探索邀请，不承诺效果、完整产品或持续免费交付。这是一个保守的启动边界，不代表我知道你的全部预算或声誉承受能力。

**五小时这样分。**

| 时间 | 行动 | 留下的结果 |
|---|---|---|
| 第一天，30分钟 | 写出你做过且能独立复用的两三类分析任务；列出现有合法可用的工具、经验和素材。给十位联系人各补一句：他是否接近某个真实业务问题？不知道就标未知 | 一张手段清单；选出最多三位较容易谈具体工作、关系允许直接交流的人 |
| 第二天，30分钟 | 分别准备并发出短邀请，约20分钟了解一个近期数据难题；不群发产品推销，不先让对方在三种产品里选 | 三个以内的具体邀约与回应记录 |
| 第三至四天，90分钟 | 最多三场20分钟交流，另用30分钟记录。围绕同一个真实事件问：最近一次是什么？现在怎么处理？哪一步最费力？谁使用结果？为什么至今没解决？ | 原话、现有办法、问题发生频次、实际后果与未知项，避免把你的推测写成客户需求 |
| 第五天，60分钟 | 从反馈里挑一个你能处理、对方愿意推进的问题。用公开、模拟或获准使用的脱敏材料，做一页问题拆解或极简示例，不做完整课程和产品 | 一个足以让对方指出“有用在哪里、哪里不对”的具体对象 |
| 第六天，45分钟 | 最多一次20分钟回看，其余时间整理共同下一步。把“有兴趣”推进为一个有对象、有动作、有日期的承诺 | 一份简短约定，或明确记录对方拒绝、搁置以及原因 |
| 第七天，45分钟 | 汇总证据，区分问题是否存在、你是否能解决、对方是否愿意投入；决定下周继续哪一个方向、调整接触对象，或暂停 | 一页复盘和一个下周选择 |

合计300分钟。等待回复不占主动投入时间，但到了周末就按已有信息复盘，不把计划无限顺延。未约成的访谈时间也不自动转成开发时间。

可以使用这样的邀请草稿：

> 我想从企业数据分析里找一个值得继续做的小方向。能否约20分钟，聊聊你们最近一次分析数据时卡住的具体问题？先了解实际工作；如果发现我能帮上的一小步，再一起定是否继续。

交流时不要只问“这个想法你觉得怎么样”。真正会改变行动的是：对方愿不愿意提供一段具体工作时间、一个获准使用的案例，或让实际使用者一起参与。

例如，看到示例后可以提出一个明确的小约定：

> 如果这个问题值得继续，我下周可以用一小时做一次小验证。你是否愿意在某日前提供一个获准使用的脱敏样例，并安排实际使用结果的同事参与20分钟回看？你也可以修改这个范围，让它更贴近你们正在做的事。

这里的重点是**共同定范围**。对方的资源和限制可以改变方向，而不仅是帮你验证一个已经想好的产品。口头称赞算兴趣；约定投入时间、提供材料或组织使用者参与，才开始形成可用的承诺。付费是更强的一类证据，但本周不以成交作为唯一标准。

**遇到不同反馈，计划就这样变。**

- 如果对方知道要分析什么，却不会操作，而且愿意组织实际学习者、提供真实任务，可以把下一轮做成一个很小的培训验证。
- 如果对方反复进行同一类明确操作，并愿意提供使用流程与测试时间，可以研究一个工具样例。先核对流程是否足够相似，不能从一家机构的定制需求直接跳到开发通用产品。
- 如果对方需要的是一次具体判断或交付物，现有手段就能完成，而且有人愿意配合界定结果，可以优先试一项范围明确的服务。
- 如果出现意外资源，例如有人愿意介绍真正的问题负责人，就记录并重新估计它是否比原计划更值得投入。只有介绍实际发生或对方作出具体承诺后，才把它计入下一步资源。
- 如果只有“挺好”“以后聊”，不要启动制作。用原定第五、六天的时间澄清一次问题或换一个更接近现场的人；最多仍接触三人、总计仍不超过五小时。
- 如果没有回复，先记录“本周未获得接触”，不能推断“市场没需求”。如果问题确实存在，但现有能力和时间无法处理，也不为维持探索而接下交付。

先做一个通用演示也是备选方案：它能帮助对方理解你的能力，但可能占掉五小时却没有暴露真实需求。只有在“对方看不懂你能做什么”已经成为障碍时，才值得做一个短示例。现阶段更值得优先确认的未知是：谁有具体问题，谁愿为推进它投入一点资源。

**周末怎样决定。**

有真实问题、可承受的小交付范围和一个具体承诺，就选其中一项进入下一周；条件不齐，就只补最可能改变选择的那一项。若获得了明确拒绝，也保留原因：已有成熟解决方案、问题不重要、找错人、时间不合适，意味着不同的下一步。五小时用完仍没有可推进的对象，可以暂停或改变接触人群，不用为“已经开始”继续投入。

这次主要使用 **WW-5.5 效果推理**：现有手段决定起点，损失上限约束动作，真实承诺让伙伴共同塑造方向，意外反馈可以改变路径，你负责可控的行动。补充 **TM-062 信息价值**，只用它删掉不会改变下一步的调查，并给探索设截止点；这里没有可信概率和收益数据，因此不编造市场成功率或信息价值金额。

一周内出现一个积极反馈，还不足以证明可以规模化。等相似需求在独立对象中重复出现、交付流程和成本逐渐稳定、使用效果或付费意愿能反复验证，再把逐次探索转为有目标、预算、进度和指标的计划。现在要做的是找到值得兑现的下一步。

以上仅是计划及可用话术，尚未联系任何人、支出或作出合作承诺。方法依据为技能包中WW-5.5的现有技能快照，未按万维钢原课程校勘。
