# TM-086 · 杠杆思维

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
预算、人手、工具换过多次，结果仍回到原样，需要寻找别的干预位置时用。不是金融加杠杆，也不等于根因或瓶颈；一次零件坏了未必需要改全系统。需要重复结果、既往动作与等待时间、信息权限、奖励和副作用；现象模糊时问：“你们说问题没变，具体是哪项结果在什么时间里没有改变？”

## 转换动作
1. 先查数据、执行范围和见效时间，避免把未真正实施或尚在途当作参数无效。写清短期止血与长期改善目标，紧急需要可以先止血，不等待完整系统分析。
2. 依据问题扫描少量位置：数值与物理结构、反馈与延迟、信息权限与规则、实际目标。四组是原文为使用而作的归并，不是固定优先级；浅层也可能重要，深层也可能代价巨大或方向错。
3. 每个候选写“改什么，经哪些行为或状态影响目标，多久可见，同时可能伤害什么”。逐箭头标依据或假设，核实有权改变的范围与系统如何适应，不能只给一个抽象的“改文化”。
4. 按可行性、损失和信息价值排序，选择能检验一个主要机制的动作。条件适合才做可逆验证；同时改多项时明示难归因。临时刺激撤除后看变化是否持续、代价是否转移；无效则查机制，而非宣布全套理论失败。

## 最小成果与停止
交付有顺序的干预假说及方向、路径、延迟、副作用、验证和退出安排。能说明一项改变怎样影响目标并可检查即可完成；没有机制知识先补调查，不凭层级图发明方案。参与者适应、反馈或目标变化时重评。

## 工具箱接口
候选是闭环连接时交反馈回路；代理被强优化时交古德哈特；眼前产出被单环节限制时交瓶颈。把选定的机制假说交执行或实验工具时，同时传递边界，分别记录提议、接受、实际改变及持续效果。
