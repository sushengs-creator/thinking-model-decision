# TM-133 · 反馈干预理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
反馈多次仍不改、只顾能力评价或需同步提示才完成时使用。除反馈内容外，也检查注意和后续行动；任务学习、投入和自我评价可同时发生，质疑评价可能指出真实错误。

## 最小输入与追问
合理任务基准、实际材料、反馈原话场合与奖惩、接收者理解及动作、技能时间支持、是否要求下次独立。关键追问：“你准备按哪条建议改哪一处，实际试时停在哪里？”不靠沉默或情绪推断心理。

## 转换与分支
1. 对材料共同核对差距、标准和现实可行性；评价有误先改，要求不相称交有权者调整。缩短时间仍须保留必要依据，不拿删质量换表面达标。
2. 请接收者尝试修改一小段，分开反馈原话、自述与可观察行为。不理解就澄清或示范再让其处理另一处；担忧能力评价或公平先回应核实，不强压情绪。
3. 方法明确仍失败，查技能、练习时间、信息负担、资源与目标冲突。选择有依据的一项调整，写责任人和复查；多条件一起改则如实记录，紧急任务不为测试贸然撤帮助。
4. 分别检查建议是否采用、目标表现与代价是否改善；目标含学习时再用相近难度新材料和适当间隔检验独立完成。未用先查理解条件，用了无效先查建议与基准，当场好而独立差才补练或淡出支持。

## 最小成果与验收
交付差距、竞争解释、下一项反馈或支持、采用/效果/掌握观察及切换条件。只需本次交付时允许继续用工具，不额外强加闭卷目标；满意与不满均不能代替表现证据。

## 停止与工具箱接口
建议已准却资源不足时停止加码评语，处理条件与责任。反常好坏后的变化可交回归均值作反证，具体弱点交刻意练习，评价压力交心理安全；一次好转不确证注意机制或长期效果。
