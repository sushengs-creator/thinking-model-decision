# TM-031 · 把眼熟好感与真实使用证据分开

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
某品牌、人物或观点见得多就觉得顺眼、可靠，却拿不出相关表现时用。熟悉也可能来自长期有效使用，不能一律扣分；普通低代价偏好无需全面研究。输入候选、接触渠道、首次印象与具体用途；关键追问：“你觉得它好的依据，哪些来自亲自使用，哪些只是经常看见？”

## 转换动作
1. 写出实际选择标准，把眼熟、安心与性能、服务、费用分栏。好感可以保留，但不直接升级为质量或可信度证明，记忆确信也不全由单纯曝光解释。
2. 追溯熟悉的来源：同一广告重复、他人转述、独立使用经历。重复转发不增加独立证据，而长期稳定使用记录确实有参考价值，须注明场景是否仍相同。
3. 可行时隐去品牌和排名，用同一真实任务比较熟悉与陌生候选。无法隐去的服务、兼容或维护差异要补回，不能为了盲评删掉实际价值；差评也用相同证据标准审查。
4. 对缺乏记录的关键性能安排成本可控的小试，记录预期与表现。熟悉候选未达标就调整，陌生候选未经验证也不自动优先；重复曝光可能带来厌烦，不能套必然越来越喜欢的规则。

## 最小成果与停点
交付熟悉来源、独立证据、同任务试用结果与待验证判断。能明确“喜欢”及“有用”分别依据什么，即完成本轮；不要求用户放弃熟悉选择。新使用反馈或实际服务条件改变时重新比较，拟试用与已试用分开记录。

## 工具箱接口
试用缺口交小试与学习工具，剩余候选交取舍工具。若主要疑问是某件事突然变多，转趋势与注意力区分；若只是点赞多而非亲眼熟悉，转社会信号分析。
