# TM-087 · 阈值模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
大家说愿意却都等别人、已有种子用户仍不扩散时用。先行人数必须会影响选择；产品本身不需要、价格不合适不能都解释为门槛。需要具体采用行为、相关人群、可见先行者、进入退出和成本；适用性不明时问：“如果不知道别人有没有做，你自己的选择会有什么不同？”

## 转换动作
1. 以真实采用而非口头赞同记录先行与跟进，检查人们参考谁、能看见什么。用历史行为和中性阶梯询问形成大致响应，不给每个人虚构精确阈值；可见案例必须真实，不能制造大家都在用的假证明。
2. 画愿先试、愿早跟、稍后才跟的人群与连接路径。已有若干人后，要看是否有下一批在当前条件愿加入；平均门槛无法代替分布，某一段无人接续就会停。相关网络是局部的，总人数不一定能传到目标人群。
3. 定位断点是缺早跟者、成果不可见、不可信，还是使用成本与价值不足。只补一个关键条件，推演新增会否促成下一批；需要且可行时做真实有限试用，比较实际跟进，不把访谈意愿当实际采用。
4. 同时看退出与留存。加入后迅速离开会破坏简单单向链；条件和社会风险变化也会改变门槛。没有响应时转查价值、迁移成本和对象匹配，不能永远追加种子人数。

## 最小成果与停止
交付种子、相关可见网络、下一批、断点假说、验证或补证动作与停止条件。足以指出链在哪类人或条件断开即可完成；拿掉他人信息仍不改变选择时停用。扩散被支持只说明行为能传，不证明值得推动。

## 工具箱接口
别人加入改变实际使用价值时交网络效应；想看首次采用的总体时间曲线交巴斯；需要判断撤催促后能否维持交临界质量。将真实采用和退出记录传递，区分邀请建议、同意尝试、完成使用及持续使用。
