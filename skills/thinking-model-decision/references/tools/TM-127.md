# TM-127 · 观察学习

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
看懂示范却独立卡住，或培训后没采用新方法时使用。学习获得与实际表现分开：做不出不证明白看了，看过也不证明学会；注意、保持、行为再现和动机相互影响，并非互斥故障码。

## 最小输入与追问
具体任务及标准、看过的示范、独立尝试卡点、已有帮助与工具权限。关键追问：“离开示范后，你能独立做到哪一步，第一处卡在哪里？”保留正常工具和无障碍支持，不用撤掉必要条件测试能力。

## 转换与分支
1. 留一次适当环境中的尝试，用口述、图示、写出或演示记录看清了什么、保留哪些步骤理由、实际停点；说不出来不自动等于没有知识。
2. 将卡点变为候选解释：关键线索漏看、顺序或理由未保持、已知动作不熟。已能做却未用时另问预期收益、切换成本、出错顾虑，权限时间机会独立核查，不先判态度。
3. 按证据补最小缺口：局部示范、回忆核对、针对动作练习或纠正示范本身。原因未唯一确定也可先补可见缺口，同时保留竞争解释，不强制重看整段。
4. 重试并记录补了什么、帮助多少、结果如何，再用小变化或延后任务检查。第二次成功只说明安排有帮助，不能唯一确证第一次失败原因；新任务新增知识需另补。

## 最小成果与验收
交付“卡点—证据—仍可能解释—下一步补法”、反馈来源与后续检查。验收看任务质量、保持与迁移及提示依赖，复述流畅或示范者成功不能代替学习者表现。

## 停止与工具箱接口
会做但无条件时停止培训归因，转资源权限安排；示范错误先修源材料。过载可交认知负荷，隐含判断交默会知识，旧解释反复主导交概念转变。补示范可能同时影响多个过程，不给心理原因编分数。
