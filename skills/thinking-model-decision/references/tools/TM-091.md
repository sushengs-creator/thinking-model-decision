# TM-091 · 重尾分布

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
当一个大客户、一次损失就能改写整体结果，或平均数与多数人的体验相差很大时调用。集中、二八现象或一条极端记录，都不足以证明重尾或幂律。最小输入是原始记录、分组口径、头部贡献和可承受损失；缺信息先问：“这个极端记录怎样产生、怎样核实，是否与其他记录属于同一口径？”

## 转换动作
1. 先检查录入错误、不同群体混合和观察范围。错数据应订正，真实极端保留；不能为了让图好看删掉，也不能靠一个异常宣布存在重尾。
2. 并列中位数、分位数、头部占比和均值。暂时去掉头部只用于敏感性比较，同时保留原口径；区分收入贡献、利润、回款和服务成本。数据不足时只报告集中暴露，不给分布下定论。
3. 对最大对象退出、多个头部共同受冲击、超出历史最大值分别推演。检验储备和固定承诺能否承受；历史平均不是自然安全线，部分重尾分布的相应矩甚至不存在。
4. 同时考虑保护有价值的头部和培育替代来源。依赖上限由承担损失的能力决定，不套固定百分比，不因头部贡献大就一律清退小对象。

## 最小成果与停止
交付“集中度与尾部压力表”：口径、异常核实状态、头部收益与成本、冲击下的缺口、应对条件。能辨认主要暴露即可完成，行动不必等到证明幂律；数据错误或混合足以解释时停用分布判断。头部结构、储备或固定成本变化后重判，一笔大单不能证明长期承诺可承担。

## 工具箱接口
利润与资源选择交给边际分析；相关冲击和承受路径交给风险、生存或韧性工具；奖励正在放大头部集中时交给反馈与激励工具。保留事实、情景假设和建议，调整被接受、实施及实际分散效果分别记录。
