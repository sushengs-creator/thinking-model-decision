# TM-039 · 把他们都一样拆成样本与行动相关差异

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
见过几个成员便说“他们都一样”，准备对整类人统一判断或行动时用。正面概括也可能抹平差异；群体确有共同制度或任务条件时可以统一处理。输入群体定义、接触对象、来源场景与要做的决定；关键追问：“你实际见到的是哪些人、在什么情境下的哪些行为？”

## 转换动作
1. 将“他们都……”改成有范围的样本陈述，列接触人数、具体行为与未覆盖对象。不是只把语气改软，而是限制结论适用范围，避免让个别经历代替所有成员。
2. 检查样本是否来自同一冲突、渠道或传播筛选。增加更多同类极端样本仍可能看不到差异；记录哪些群体成员没有机会进入观察。
3. 围绕行动提出可验证的内部差异，例如预算、使用目的、熟练度或资源限制。类别只是候选，需要个体资料支持，不为完成练习硬造三类，也不凭群体身份替个人推断能力或品性。
4. 按真正影响行动的差异设计回应，并保留例外与重新归类入口。若共同约束确实相同，就保留统一措施；新样本推翻分组时调整，避免新标签再次锁死人。

## 最小成果与停点
交付有限范围的群体描述、待验证差异与对应响应。决定所需差异已可检查、个体没有被整体均值替代，即完成本轮；不以类别数量或找出特例验收。样本无法覆盖总体时保持局部结论，不宣称已经认识所有成员。

## 工具箱接口
缺失样本交调查与选择偏差工具，不同需求交选项设计；若主要是偏袒自己人而非看不见差异，转同标准评价。无需把面孔感知研究当成本次分群的直接依据。
