# TM-075 · 中心极限定理

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
拿到平均数或两组差异，要判断估计会随样本晃动多少时用。它讨论反复抽样的均值分布，原始数据不必钟形；样本超过某个固定数也不是通行证。需要抽样设计、目标总体、样本量、离散程度、依赖和极端值；目的不清时问：“你想知道总体平均水平、典型个体，还是少数极端情况？”

## 转换动作
1. 先审查覆盖、拒答、群聚重复、时间变化和口径。平均值不能回答典型人或尾部风险时换成果类型；样本有系统偏差，先限制适用人群或修采样，不拿公式为其背书。
2. 查偏态、稀有事件和极端值是否主导均值，并区分近似形状合适与误差足够小。经典独立同分布且有限非零方差下，标准误随样本量平方根缩小；相关记录需匹配设计调整，不能直接把总记录数代入。
3. 输入充分时报告点估计、标准误或区间、方法和前提；未知总体波动须用适当估计方法。资料不足先交缺口，不自行补标准差。置信区间的比例说的是重复使用方法的覆盖率，不能说固定参数对已得区间有那个概率。
4. 比较差异与决策阈值，只有精度改善会影响行动时才考虑补样。即使差异超出抽样波动，仍查人群、口径与因果解释；不能由统计差异直接宣布某活动有效。

## 最小成果与停止
交付估计对象、估计及不确定范围、设计限制、对当前行动的意义。已有精度足以支持决定即可结束；极重尾、无限方差或不合抽样条件时停用常规近似，转匹配的方法或描述性结果。计算、解释与行动建议分开保留，不把扩样建议写成可靠性已提升。

## 工具箱接口
样本是否增加有效信息交大数定律；指标是否测对交测量模型；差异是否由行动造成交反事实因果。若需决定补多少资料，把影响选择的精度缺口交信息价值，不机械追求更小误差。
