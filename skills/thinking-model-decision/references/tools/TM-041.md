# TM-041 · 把阵营忠诚与事实方法分开讨论

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
讨论从事情是否成立变成“你是哪边的”，承认不利事实被当成不忠时用。群体认同可支持合作，真实利益冲突与价值差异也不全是偏差；核实过的来源信誉仍应考虑。输入争议主张、身份标签、证据、共同目标与表达风险；关键追问：“把谁说的先放旁边，这句话具体在主张什么？”

## 转换动作
1. 准确复述内容，拆成可核事实、推论、价值取舍和情绪表达。共同愿望只能列目标，不能因为双方都希望它成立就写成事实；不同价值无需被迫合一。
2. 交换说话人阵营，检查看同一材料时证据要求是否变化。保留真实造假、履约和利益关系等相关记录，只摘与主张无关的身份标签，不用假装完全不知道来源来取消审查。
3. 找双方能够共同核查的事实并约定同一尺度。表达可能受罚时先私下保存判断与依据，不要求个人公开证明中立；对证据的承认不等于接受对方所有立场。
4. 双方愿意时，围绕真实且需要配合的任务做有限试验，明确贡献、权限和反馈。不制造危机迫使合作，普通共同任务也不自动成为双方缺一不可的目标；若争议仍是资源分配，转入协商。

## 最小成果与停点
交付身份与内容分离表、可共查事实以及可选的自愿合作任务。事实审查不再以站队为前提，剩余价值或利益分歧明确，即完成本轮；不以和解、同意对方或归属感变化验收。合作反馈仍须查证，严重表达代价未解决时暂停公开化。

## 工具箱接口
可核事实交证据工具，利益冲突交取舍与协商，有限任务交执行。若只是一次内外区别评价，采用同标准比较即可；持续封闭反证入口时才进一步检查方法能否被修正。
