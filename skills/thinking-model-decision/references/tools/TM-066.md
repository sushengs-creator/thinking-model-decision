# TM-066 · 沉没成本

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
因为“已经投入这么多”而继续，或听到沉没成本就想立刻退出时用。它是重新比较原则，不能自动劝退；能退的钱、可卖资产和退出才发生的代价都不是应删除项。需要旧支出、现有资产信息、继续与退出的后果及替代；混淆时问：“如果今天换一种选择，哪些钱、时间或后果还会跟着改变？”

## 转换动作
1. 逐项按“是否随当前选择改变”分账。真正无法回收且各路径都一样的过去支出退出本次比较，但保留到复盘记录；退款、残值、复用能力、新实验发现和真实承诺进入未来比较。
2. 从今天估计继续到下一个有效验证或交付点的完整投入，包括小批追加背后的绑定责任；另列退出、转移和切换的新增成本。不能把退出费误当已经沉没，也不能把“快做完”只当心理借口，接近交付可能确有价值。
3. 对继续、暂停、退出、切换比较未来净值及风险。借用掌握同样信息和责任的新负责人视角，检视哪些理由只是维护旧决定；意见不同不是偏差证明，需核对对方是否了解资源、承诺与退出后果。
4. 若继续，写有依据的预算、期限和下一停止点；若退出，列资源回收和交接。把过去责任复盘与今天的资源选择分开处理，既不为承认错误继续投入，也不借模型抹掉真实善后。

## 最小成果与停止
交付剔除与保留清单、各路径未来增量、建议及下一节点。旧投入不再决定排序、资产和退出代价未漏即完成；缺未来证据时允许暂缓判断，不能只凭情绪命令退出。新需求证据、退款条件或交付成本出现时改判，接受建议、实施退出和实际回收分别记录。

## 工具箱接口
未来用途竞争交机会成本，下一批承诺交边际分析，需要防止反复追加交停止规则。旧损失引发的情绪可以先被承认，再进行账目比较，不把理性清账当成否认感受。
