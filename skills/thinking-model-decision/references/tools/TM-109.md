# TM-109 · 言语行为模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
大家听懂内容，却不清谁接下、谁仅答应回复、谁有权批准时使用。字面内容、话语所做的行动和后续效果分开；请求发生不等于获接受，承诺发生不等于履行。

## 最小输入与追问
原话与上下文、说话对象、惯例、岗位责任、权限、条件及回应。关键追问：“对方当时具体答应的是回复，还是完成哪项工作？”没有原话时保留待确认，不靠语气判断动机。

## 转换与分支
1. 还原已有安排，将一句话里的说明、要求、承诺、情感表达和宣告拆开；“通过并由我协调”要分别核查批准与承担的工作。
2. 核对要求发给谁、承诺由谁承担、宣告者是否具有身份权限并完成必要程序。缺权限的口头通过不能直接启动依赖工作；没有新口头承诺也可能已有有效岗位责任。
3. 标记已接受、附条件接受、拒绝、待回复或未明确。清楚惯例下“收到”可以够用；答应某日答复，只排回复节点。已有承诺却资源不足时保留责任，同时讨论补条件和重新协商。
4. 共同记录范围、前置依赖、回复或交付时点，按状态安排下一步。看板记录保存澄清结果，不能倒推出此前承诺；具体执行与结果另记录。

## 最小成果与验收
交付“谁对谁、接下什么、条件、当前状态、下次节点”的约定表。关键未决事项明确由谁确认，提议、双方接受、执行、效果不混写；不以对方服从或所谓真诚为验收。

## 停止与工具箱接口
足以安排下一步即停。任务含义不同交共同基础；约定清楚但配合动机不同交激励或博弈；多方需共同启动交共同知识。不得通过重新命名话语免除既有职责，也不替代实际权限开通。
