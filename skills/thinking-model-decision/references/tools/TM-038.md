# TM-038 · 用同一标准比较自己人与外人的行为

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
同样行为因“自己人”或“外人”被赋予不同解释、机会或宽容时用。可靠履约历史、职责差异和亲近偏好可能有合理意义，偏差不是所有差别待遇。输入双方可比事实、评价规则、关系标签与历史表现；缺口问：“如果保留事情经过，只对调两边的身份，你会怎样判断？”

## 转换动作
1. 先写适用于此事的行为标准与允许考虑的情境，再分别放双方事实。核对是否给自己人查背景，却直接把外人的行为归为人品；未听到另一方版本要标缺口。
2. 做身份交换检验，观察解释、责任或机会是否改变。变化是可能受归属影响的信号，继续查真正相关差异，而非直接判某方更差。
3. 将“我信任他”与“这件事有哪些证据”分开。能隐身份时先看作品和记录；不能隐时明确哪些历史经验与当前任务相关，避免把群体荣誉当事实证明。
4. 在授权范围内补另一方或无利益绑定者视角，再按同一规则更新。局外人也可能缺信息，不因与自己不同便优先相信，更不能纠偏后反过来偏袒外人。

## 最小成果与停点
产物是双方同标准证据、身份交换结果与仍成立的决定理由。事实差异和归属差异已分开，责任或资源安排有可解释依据，即完成；不要求喜欢双方一样，也不以认错验收。新增履约证据时允许差异化信任，未核实公众争议不作事实裁定。

## 工具箱接口
双方情境差异可交归因或机制工具，资源分配交取舍工具，缺版本交沟通工具。只有群体内部差异被抹平时才接外群体同质性，不把两个身份问题混为同一审查。
