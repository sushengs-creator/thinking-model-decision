# TM-034 · 改写体面问法并核对真实行为与限制

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
问卷、访谈或汇报满是正确态度，却不能解释实际选择时用。体面回答可能是礼貌，也可能真诚；行为不同还可能受预算、机会和记忆限制，不能据此抓谎。输入提问原句、在场者、回答后果和可自愿取得的记录；关键追问：“对方如果给出不同答案，会担心发生什么？”

## 转换动作
1. 标出问题里暗示标准答案的词、评价者权力与奖励惩罚。根据当地规范判断可能少报还是多报，同一行为在不同环境中方向可能相反，不默认人总夸大好处。
2. 改成中性问法，说明没有规定答案、可以拒答，并如实交代保密范围。能做到时降低公开压力；不能保障匿名就不许诺匿名，不编“很多人都这样”来诱导披露。
3. 从抽象品德转到最近一次具体选择：做了什么、有哪些替代、卡在哪里、放弃了什么。不要把追问变成审讯，也不在问题中预填原因让回答者附和。
4. 用自愿提供的行为记录或透明小试交叉核对。口头偏好、实际行动、完成结果分别记录；差异出现时保留表达压力、资源不足、目标变化等竞争解释，而非立即认定欺骗。

## 最小成果与停点
交付中性问题、回答环境说明及偏好—行为—限制核对表。回答不再被直接当成行动承诺，主要差异有待核解释，即完成本轮；不以对方承认自己说了假话验收。若只是礼貌寒暄且不影响决定，停止深挖；不秘密监控或强迫提交私人记录。

## 工具箱接口
真实需求线索可交调查或选项工具，资源卡点交约束工具。若没人愿意说而非说得好听，转沉默与表达渠道分析；已经确认的投入才交执行安排。
