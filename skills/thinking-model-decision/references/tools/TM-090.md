# TM-090 · 临界质量

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
增长依赖提醒、补贴或人工撮合，想判断能否减外力时用。临界质量不是注册人数，也不等于盈利；彼此互不影响的产品不必用这个模型。需要要维持的功能、局部活跃网络、角色构成、同周期进出及外力条件；目标不清时问：“外力减少以后，你最希望哪项具体功能仍然持续发生？”

## 转换动作
1. 先核实参与者增加会怎样提高后续参与的价值，再明确是要保住订单、协作、使用，还是持续提供公共品。少数稳定贡献者可能够维持公共品，却不代表居民参与已经自发扩散。
2. 分开催促、投放、补贴与参与者间的真实带动，查相关连接、稀缺角色和退出。来源可能混合，不能把带奖励推荐全算自然增长；只堆人数可能补不到最关键的审批人、贡献者或供给方。
3. 若需要验证，在可回退的局部逐步减少一种外力，覆盖完整使用周期，记录有效新增、退出、体验和成本。撤补贴同时改变价格或供给收益，因此结果是运营敏感性证据，不是纯粹揭示固定临界点。
4. 比较内部带动能否抵消流失、关键功能是否持续；明确继续减、维持或恢复条件。维持不了时查价值与角色缺口，不无限补人；每轮都保留当时价格、竞争和外力水平。

## 最小成果与停止
交付有条件的自维持判断、局部减外力方案、指标周期与恢复触发点。能对当前条件给出区间性证据即可结束，资料不足允许尚不确定。不能从短期稳定宣布完全自维持；关键成员退出、竞争、价格或体验变化时重评。减外力提议、实际变化及功能持续分别记。

## 工具箱接口
相关用户是否相互增值交网络效应；进出人数对不上交存量—流量；行为接力断在哪交阈值；单一贡献者负担能否持续交参与者与资源约束工具。临界质量支持的是特定功能的维持判断，不替代付费或盈利检验。
