# TM-044 · 把检查别人的标准也用于自己的实际判断

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
擅长识别别人偏误，却用“我有理由、没有故意”证明自己不受影响时用。模型不证明双方同样错误，专业判断也不因自信被取消。输入一次具体争议、双方选取或舍弃材料、原规则与外部反馈；关键追问：“如果你指出的同类问题也出现在自己这里，最可能表现在哪个具体动作上？”

## 转换动作
1. 将“他有偏误”还原为可观察行为，例如删了哪些样本、何时换指标。先写指认所需证据，意见不同或语气笃定本身不够，也不给人格下结论。
2. 用完全相同尺度检查自己的对应行为。把自己熟悉的意图与外部可见记录分开：“并非故意偏袒”解释动机，不能证明样本选择合理；同时允许对方补相关情境。
3. 指定一个真实自身风险点，恢复原始记录、匿名复评或请不同立场者查该点。外部意见仍按质量评价，不把自我纠偏变成听谁反对就服从，也不只写一句抽象的“我可能错”。
4. 记录修正、维持或暂缓的理由，以及能改变结论的新证据。对照修订前后有什么具体变化；知道名词、反省真诚或刚通过检查，都不是以后免疫的凭证。

## 最小成果与停点
交付同标自查表、一个具体风险位置和一次可追溯校准动作。原判断已经接受与他人相同的检查、结论有更新条件，即完成；不以承认自己错或双方一致验收。重复检查未产生会改变行动的新信息时停止，保留重新开启条件。

## 工具箱接口
发现具体证据偏差后交相应取证或评价工具，修正结果交复盘；不存在证据时保留待核，不把盲点标签再用作指责对方的武器。
