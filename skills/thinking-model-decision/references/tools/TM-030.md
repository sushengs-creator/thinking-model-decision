# TM-030 · 把身份背书还原为专业范围与证据

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
因头衔、职位或机构标识而少问依据，或专家跨领域发言仍被全盘接受时用。合理委托专业人士不等于偏误，外行异议也不与合格证据自动等权。输入具体主张、专业背景、支持材料、适用条件及行动后果；关键追问：“这个建议具体建立在哪些事实和前提上？”

## 转换动作
1. 暂去姓名和身份，只保留可检验的主张，标出对象、时间、推理及缺口。发现去掉头衔后说不清理由，是追问信号，不直接证明主张错误。
2. 核查专业训练和实际经验是否覆盖当前问题，证据能否追溯，利益关系可能怎样影响建议。身份可提供初步可信线索，但不能代替对适用条件的检查。
3. 对重要且能等待的选择，获取独立、合格的第二意见，比较双方分歧来自哪些假设与资料；不是随便再找一人反对，也不是按支持者人数投票。紧急情境不机械拖延。
4. 记录采纳、待核或不适用的理由及保留问题。若涉及职位命令，区分“相信结论”为何与“职责上执行”依据，必要时用既定升级或反馈渠道，不能靠身份替风险担保。

## 最小成果与停点
交付主张—专业范围—证据—适用条件—分歧与下一步。用户知道信任来自何处、主要缺口如何处理，即完成；无需自己成为该领域专家或推翻权威。新证据或范围改变时更新，不从故事推断具体人的动机。

## 工具箱接口
可核命题交事实查证或比较工具；权力压力交参与者协调，已形成决定交执行工具。若只需规范操作且专业依据充分，就停止额外怀疑，不增加无用第二意见。
