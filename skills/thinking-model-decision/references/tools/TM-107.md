# TM-107 · 知识的诅咒

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
自己熟悉的术语、步骤或内情被当成对方也知道，导致说明听似清楚而无法继续时使用。知识差距本身不是偏差；对方理解却不同意、缺权限或缺练习，不能统称没听懂。

## 最小输入与追问
要完成的任务、讲过的内容、双方已知信息、对方一次真实尝试及操作条件。关键追问：“对方现在怎样理解这一步，哪里拿不准？”若没有直接反馈，先标记自己的估计。

## 转换与分支
1. 将“我讲清了”拆成解释者预期与接收者实际表现。先观察一处停顿并听其判断，不先从头重讲；没有观察机会则设计低成本核对。
2. 从对方已懂的概念建立对应，展开自己自动省略的那一层。例如名称对应哪个对象、何时选哪个选项，说明动作与可见结果，不堆无关背景。
3. 让对方独立尝试或用自己的话解释理由，核对是否能继续。能做但不愿做转查目标分歧；无权限转找条件负责人；解释者自己讲不通则补自身知识。
4. 根据新卡点修订说明，需要反复使用时留短步骤卡并安排后续核对。一次补充有效，只说明这条信息有用，回看漏讲依据后才讨论是否存在知识误估。

## 最小成果与验收
交付受众起点、缺口、修订说明及实际复述或操作证据。验收看关键判断和操作是否正确，不能以点头、同意或听课完成代替，也不把接受建议当作理解证据。

## 停止与工具箱接口
已能正确理解而仍有分歧时停止补讲，保留对方选择权与双方职责。材料过载可交认知负荷，图文指代混乱可交双重编码；目标冲突交协商或课题分离，避免用教学掩盖权力问题。
