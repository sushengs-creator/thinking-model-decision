# TM-078 · 期望效用理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
两个风险方案期望金额相近，用户却明显偏好稳定，想说清风险对自己的价值时用。效用不是任意优缺点打分，也不能比较不同人的幸福总量。需要当前资源、各最终状态、概率依据、不能突破的责任和本人偏好；底线缺失时问：“这些结果分别发生后，你的实际处境会怎样，哪些后果承受不了？”

## 转换动作
1. 把各分支改写为最终资源、义务和处境，统一是评总资源还是增量。先检查不可承受损失，能够降暴露或换结构则改方案，仍越底线则排除；不能用平均收益冲抵硬约束。
2. 对可承受且概率有依据的风险方案，用相近成对选择询问本人愿意接受的确定结果。逐步定位一个大致等价区间，允许暂时说不清；不得替用户指定效用函数、风险厌恶参数或精确分数。
3. 可比金额条件下，期望金额减确定等价得到对应风险溢价；计算只反映当前赌注、财富和约束下的偏好，不贴永久保守标签。一般表达可用各结果效用按概率加权，但效用须来自一致偏好而非凭空编造。
4. 换等价的得失表述复问，并比较可信概率区间下排序是否变。偏好反转先查框架、遗漏后果或概率不可靠，不直接批评不理性；低风险且差异很小时允许退回简单期望值比较。

## 最小成果与停止
交付最终状态表、硬约束、本人给出的确定等价区间、风险溢价或定性偏好，以及反转条件。能解释当前选择并经等价复问保持一致即可结束。概率不明或偏好难以稳定表达时停算，保留情景与约束；资源、赌注变化时重评。

## 工具箱接口
怀疑参照点影响交前景理论；概率缺依据交证据工具；重复投入影响下轮资格交非遍历性。确定等价是用户的回答，不是模型建议价；建议、选择确认和实际承担风险分别记录。
