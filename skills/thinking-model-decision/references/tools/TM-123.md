# TM-123 · WOOP思维

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
愿望由本人认可、眼下有实现空间，却在相似情境反复停住时使用。WOOP 依次做愿望、最有价值结果、主要内在障碍和计划；普通日程不等于针对障碍的执行意图。

## 最小输入与追问
愿望、期限与可用条件，一次真实停顿中的想法感受，以及能当场执行的动作。关键追问：“上次准备开始却停下来的那一刻，发生了什么？”内在障碍不清就先观察，不补造“懒惰”或畏难。

## 转换与分支
1. 按 W、O 明确本人想在什么范围做到什么，想象做到后最有意义的改变与感受。愿望不可行或并非本人认可时缩小、调整或放下，不代设必须成功的目标。
2. 回放停顿，找最妨碍行动的内在反应，将它与期望结果对照；外部时间、权限、规则和资源另列。条件不足先处理条件，不改写成心理弱点。
3. 写 P：“如果【能察觉的障碍信号】，我就【具体且有用的小动作】”，预演一次。动作回应障碍并接近目标，不写“如果拖延就不拖延”；计划有助减少临场犹豫但不保证自动发生。
4. 到约定节点分查情境出现、信号察觉、动作执行及实际帮助。未察觉改线索，察觉未做查动作难度，已做仍错补教学；时间被占或规则冲突则修现实安排。

## 最小成果与验收
交付完整或注明缺口的 W—O—O—P 卡、一次可执行预案与复查安排。开始行动和目标质量分别验收，练了几次不代表学会，也不要求担忧消失后才算成功。

## 停止与工具箱接口
没有内在障碍证据时停猜原因，先留一次观察；愿望失去价值或条件持续不具备时重新立题。提示与能力门槛可交福格行为，已开始却做不好交具体学习工具，真实价值冲突交期望价值。
