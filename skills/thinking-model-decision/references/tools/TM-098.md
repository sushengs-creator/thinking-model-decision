# TM-098 · 道德风险

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
一方能决定行动，部分后果由别人承担，且行动难以观察或评价时调用。这里分析激励，不作道德定罪；费用上升、结果变差或有人兜底都不是行为偏离的直接证据。最小输入是行动权、后果归属、收益安排和过程资料；先问：“这项安排里，谁能决定具体做法，决定的后果分别由谁承担？”

## 转换动作
1. 列出可控制的行动及其私人收益、成本和对他人的后果，检查保障或报酬怎样改变取舍。长期稳定的安排也可能产生道德风险，不必先发生制度变化；行为人根本不能控制相关行动时，不沿此解释归责。
2. 检查行动是难看见、难证实还是难评价。把激励条件与已观察行为分栏：前者支持“可能发生”，后者才支持相应范围的行为判断；他人事后救助不证明事前必然期待救助。
3. 用可比过程、时间变化或恰当对照辨别行为变化，同时检查人员选择、任务难度、环境和运气。前后变化不能独自完成归因；非随机证据也可用，但应说明比较条件和未排除解释。
4. 比较适度共担、监督、分阶段交付、重复合作与质量约束的成本。防止易量化奖励挤掉重要任务，保留必要保障、信任、公平和隐私；为拟议方案写出反证信号，不默认把所有风险转给执行者。

## 最小成果与停止
交付“条件与行为证据分列表”：机制、证据级别、替代解释、调整选项及代价。能够区分可能性和发生证据即可完成；缺行动控制或更强解释成立时停用。新资料改变任务可比性、行为证据或后果归属时重判。

## 工具箱接口
归因不清交给因果证据；指标挤出交给古德哈特工具；授权、验收和报酬落地交给委托代理。调整建议、各方接受、实际执行、行为改变和最终效果分别记录，不能用处罚被执行来证明原先判断正确。
