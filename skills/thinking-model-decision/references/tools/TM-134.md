# TM-134 · 自我效能

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
具体任务的“我做不到”或过度把握需要核对时使用。自我效能是能力判断，区别于实际技能、做成后的结果预期、愿否投入和现实条件；未行动不能倒推出缺信心。

## 最小输入与追问
任务、标准、执行条件、相关表现、事前判断及依据、预期价值和资源状态。关键追问：“你拿不准的是哪一步，在什么条件下做到什么才算完成？”不要求给信心打分或凑齐四类来源。

## 转换与分支
1. 先分流：缺时间工具配合就补条件，担心做成无用就查结果预期，不愿付代价就比较投入；多障碍并存先处理最限制行动的一项。
2. 写具体任务标准与自然语言预判，查相关掌握经验、他人示范、评价和身体情绪信息。别人的成功不证明自己会，小成功只支持相关片段，真实疲劳不能靠重解释消除。
3. 安排可承担且与目标相关的尝试，保留正常支持并预定观察信号。记录完成部分、卡点和帮助；不能安全试的任务改用已有记录、监督模拟或专业评估，不制造真实失败。
4. 对照预判和表现：技能反复卡住补练，达标却全盘否定依据记录校准，只在特定条件受阻就查变化。过度自信也校准；模糊结果保留多解释，并约目标条件下复查。

## 最小成果与验收
交付任务条件、标准、预判依据、表现证据、支持动作和切换信号，注明改变的是判断、技能、条件还是投入。分别观察信心、开始、达标与稳定表现，不以敢上场或情绪消失验收。

## 停止与工具箱接口
多次相关表现达标仍不行动，回查意愿、结果和外部条件；持续做不到重查技能策略可行性，停止无限打气。弱点交刻意练习，内在逃避证据明确交 WOOP，投入选择交期望价值；不把成败定义为个人价值。
