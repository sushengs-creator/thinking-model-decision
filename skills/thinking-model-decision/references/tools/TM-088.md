# TM-088 · 巴斯扩散模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
新品首次采用先慢后快又回落，想区分扩散阶段和产品故障时用。累计上升不代表新增仍加快，S形曲线也不证明模仿机制。需要采用定义、统计单位、分期首次采用、累计量、市场范围和价格渠道供给变化；缺定义时问：“你们记录的采用究竟是什么行为，同一个对象会不会被重复计入？”

## 转换动作
1. 固定一次采用与市场边界，同时画分期新增和累计；复购、重复登录、留存另列。潜在市场须对应产品、价格、渠道和有需求有条件的人群，不用全体人口当上限。
2. 分查不靠别人也愿先试的基线力量、看到示范后跟进的力量，以及剩余未采用人群；同时查缺货、渠道变化、体验恶化及竞品。新增下降且覆盖仍低时，不急判饱和。
3. 数据足够才使用新增速度=[p+q×N/m]×(m−N)的标准结构，比较多组可信p、q、m情景和峰值区间，留新数据检验。p和q是综合参数，不分别等于广告与口碑，也不代表两类固定人；早期拟合可能多解，不能报神奇见顶日。
4. 依诊断选择降低试用成本、呈现可信案例、修体验供给或转向新细分市场。价格渠道变化会改变边界，需重估。所谓模仿力量超过基线也不等于已经能自我维持，标准模型不直接处理流失和盈利。

## 最小成果与停止
交付采用口径、扩散阶段候选解释、竞争解释、情景预测与对应动作。足以找到下一排查方向即可完成；无可用序列时交定性分支，不伪拟合。新数据不符、市场定义或供给变化时改判；拟合好看不算预测通过。

## 工具箱接口
具体人等谁先用交阈值；现有用户价值随人增加交网络效应；留存流失对账交存量—流量；撤外力自维持交临界质量。把首次采用与持续使用分开传递，建议、试行和实际增长分别记录。
