# TM-079 · 前景理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
因“已经亏了”“一定赚到”而加码或回避，等价方案换个说法偏好就变时用。模型解释行为，不证明选择正确；真实资源压力也可能合理支持保守。需要原方案、最终资源与义务、概率来源、事前参照点及底线；参照点不明时问：“你现在觉得赚或亏，是相对于原先哪个状态或期待？”

## 转换动作
1. 找零点来自原价、期待、过去峰值还是现状，逐项写如何被编码成得到或失去。参照点须来自当事人当时的表达，不能为解释结局事后任意发明。
2. 分开事实概率、主观担忧与它在选择中的实际权重，检查“百分百”或极小可能是否占据注意。辨认参照依赖、边际感受递减、损失不对称和概率加权；不能把所有现象都归损失厌恶，也不套固定倍数参数。
3. 去掉赚、亏、回本等词，重写每个方案从今天起最终拥有什么、失去什么、承担什么。再问如果今天尚未持有或投入，是否愿意按当前条件重新选择；原安排带来的真实切换成本必须保留。
4. 比较中性重写前后的偏好，解释变化来自表述、遗漏结果还是新证据。回到未来收益、机会成本和底线形成选择理由；避免以损失话术隐藏信息或操纵他人。无法区分时只记录可能影响，不作心理诊断。

## 最小成果与停止
交付原参照点、两种等价表述、偏好是否反转及中性选择理由。能看见框架作用并重审真实后果即可结束，无须算人格参数。新现金需求或概率证据出现时重新判断；不要因模型存在而否定用户实际输不起的处境。

## 工具箱接口
旧投入影响继续交沉没成本；一致偏好下要比较风险价值交期望效用；概率未知交证据工具；连续损失会改变资格交路径风险工具。审视意见、本人重选与实施结果分别记，不能把发现框架影响当成行动已纠正。
