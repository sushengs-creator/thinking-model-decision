# TM-048 · 主动找强反证并让判断随证据更新

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
有偏好后调研变成替方案收集论据，即使没人反对也需要检查遗漏时用。开放不等于总要改口、双方等权或无限搜索。输入暂定结论、证据池、强替代、决定期限与取证成本；关键追问：“如果当前选择最终不合适，最可能是哪个前提没有成立？”

## 转换动作
1. 将倾向写成带条件的暂定判断，另记现在最薄弱的假设。先定义需解决的问题，避免搜索词从一开始就变成“怎样证明它好”。
2. 主动查失效条件、不适用人群与真实替代解释，找最强反方而非易驳倒的版本。准确复述其主张，能核对时确认理解；不替反方编事实，也不为展示开放强凑争议。
3. 统一审查来源、样本、区分力和重复信息。支持材料不自动放行，反对材料不追加不可能门槛；身份或投入压力强时，把规则事前写下，不能只靠提醒自己理性。
4. 明确哪条材料改变了结论、适用范围、信心或行动。认真检验后维持原结论也成立；若所有结果都让自己更确信，回查反证是否真正有入口。到期限或新增信息无法改变行动时停止搜索，保留重开条件。

## 最小成果与停点
交付暂定判断、最强反证、同标审查、更新前后差异与停止理由。不同信息得到处理，判断能说明为何变或不变，即完成；听完异议只是入口，不算已经更新，更不代表方案已执行。高成本无效搜索可以停止，关键未解风险则调整行动范围。

## 工具箱接口
需要具体观察的反证交可证伪或试验工具，已收敛候选交取舍与执行。已有同标证据表直接复用，不为了模型完整再次重做全部调查。
