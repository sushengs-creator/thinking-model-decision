# TM-032 · 让未表达的意见可见而不把沉默当同意

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
没听到反对就被记录为全员同意，少数意见因担心孤立而越来越不可见时用。安静也可能是不了解、不关心或尚未看材料，不凭沉默推断受压制。输入议题、已表达立场、表达代价与现有渠道；缺口问：“目前哪些人明确支持，哪些人只是还没有表达？”

## 转换动作
1. 将可见意见分成明确支持、明确反对、保留与未知；沉默保留未知，不替成员填内心态度。核查多数印象来自几位高声量者，还是有覆盖全体的记录。
2. 查异议曾产生什么实际后果，选择可信的私下、独立书写或匿名渠道。说明谁能看见、会怎样使用及匿名限制，不能承诺小群体里无法保证的隐身，也不强迫拒答者披露。
3. 若有主持权限，先收独立理由再讨论，权威后表态；允许真实认可某个风险的人作第二个支持声音。不能安排虚假反对，也不把让人开口当个人勇气考核。
4. 将异议、回应、负责人和复查时间写入决策记录，并观察反馈者是否遭遇不利后果。只增加发言入口却不改变后果，不能算表达环境已经改善。

## 最小成果与停点
产物是支持／保留／未知记录及待回应风险、可靠表达安排。重要意见有进入途径，未知未被冒充同意，即完成本轮；收到答复不代表风险已解决。已有充分独立表达后形成一致，就停止挖掘假想反对者；渠道不安全时先修边界。

## 工具箱接口
已出现的风险交证据与方案工具，表达后果交组织规则或参与者工具。若不同意见已经充分表达却仍越聊越强，转群体极化；若问题是一个人没接任务，转责任明确工具。
