# TM-069 · 运气—技能连续体

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
凭一次爆款、冠军或失败评价人和方法，或准备照搬某个赢家时用。运气重要不等于努力无用，长期排名也可能只是长期资源倾斜。需要活动机制、可比表现、对手资源、环境及过程记录；资料不足时问：“这次成绩具体靠哪些做法和条件产生，你有哪些过程记录？”

## 转换动作
1. 先看活动本身：随机事件是否容易改结局，机会次数多少，参与者能力差异大不大。高手差距缩小时，偶然更容易改相对名次，但绝对能力仍可能很高；不凭直觉给技能与运气编精确比例。
2. 把优势来源拆为可重复的动作判断、资源与任务分配、环境红利及偶发事件。过程质量也要有证据，不能把对成功者的好印象当技能机制；评分或测量误差另列。
3. 在条件可比的不同时间、对象和场景中检查优势能否持续，同时看绝对表现与相对排名。数相对独立的有效出手机会，不机械数年数；同一大客户反复贡献不能算多次证明新客开发能力。
4. 给能力判断设置证据边界：当前只是一条线索，还是有可复制方法支持的持续优势。观察不到稳定优势，也可能因样本少、学习或环境变化；避免直接宣判无能力。提出下次怎样观察最能分清来源，而非无限重复同一条件。

## 最小成果与停止
交付活动噪声性质、优势来源、可比样本、稳定性判断及需补证据。足以决定当前委任或学习范围即可结束，不等到完全剥离运气。换任务、资源分配或竞争条件时重评；评价建议、实际委任和后续成绩分开。

## 工具箱接口
极端表现的下一期预测交回归均值；样本是否提供独立信息交大数定律；要评价当初选择质量交决策—结果分离。若要设计公平评价，把资源差异和待观察能力交参与者与执行工具，不能用一次排名直接替代任用条件。
