# TM-001 · 校准被鲜明个案带偏的判断

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
刚听到事故、投诉或传奇经历，就准备据此扩大风险或收益判断时用；“听得多”需要拆成独立事件与重复转述。已有明确停运、损坏等直接证据时先处理具体变化，不用旧平均数压掉新情况。输入要做的决定、最先浮现的三条信息、对象与期限；缺口先问：“你现在最担心或期待发生的具体事件是什么？”

## 转换动作
1. 给三条信息分别标来源、时间、情绪强度及是否同一事件的转述。把“最近看见三次”转换为“独立事件数未知／已知”，不自动当作发生次数。
2. 把判断改写成带分母的问题：哪类对象、哪个期间、发生什么。寻找同口径总体记录，注明覆盖范围；没有资料就记未知，不能把记得的个案除以想象的总体。
3. 补查平稳运行、未投诉等不显眼材料，并检查近期是否出现真实结构变化。若发生机制已变，旧基线仅作背景；若只是曝光增加，降低其决定权重，不假装已算出风险概率。
4. 对照补充材料前后的行动，列一条足以改变决定的新证据。若资料暂缺且行动可逆，可建议限定范围的小试；紧急情境先处置眼前事实。

## 最小成果与停点
产物是“显眼依据—总体记录—缺失材料—暂定判断”四栏及一项下一步。完成标准是结论口径明确、未知留存、行动与证据强度相称；情绪是否消失不作验收。出现直接新证据就改判，资料不能取得时停止编数并说明限制。

## 工具箱接口
总体记录可交给证据更新类工具判断新信息改变了多少；发现失败样本根本进不了记录时，才接样本选择工具。若问题已转为方案代价，交给取舍工具，不继续盘点新闻。
