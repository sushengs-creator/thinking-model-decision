# TM-101 · Y=f(X)

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
改动很多仍无起色，或怀疑两项措施相互增强、抵消时使用。它把结果、候选因素与关系假说分开；仅需整理意见可先用分类工具，只有相关记录时不能直接宣布原因。

## 最小输入与追问
要解释、预测或改变的结果，测量对象和时段，候选因素记录，以及质量、成本和可干预范围。关键追问：“你目前观察到哪些关系，哪些还只是猜测？”缺测量先固定起止点，不事后换成表现更好的指标。

## 转换与分支
1. 将抱怨改写成可观察的 Y，为各 X 标明证据、能否干预及依赖；已有适用的领域模型先检查条件，不重复从零猜。
2. 把“都有影响”改为带方向、条件、时滞的关系；可能交互时，写清某措施的效果如何随另一措施改变，并写反例信号。
3. 能做可比重复观察时比较单项与组合，同时记录项目差异；只有一个项目时，做可承受试行，结论限定为执行可行性与变化信号，不分摊单项贡献。
4. 分开核对措施实际执行、结果变化、因果证据与继续价值。提速伴随返工、隐性加班或合理需求积压时，重算收益并修补安排。

## 最小成果与验收
交付 Y/X 定义、关系假说、比较办法、执行负责人及停止信号。每条关键关系都能对应记录或待查项；结果有统一口径，不能用四个均值解释参与者内心。

## 停止与工具箱接口
无法观察或无权干预时停止因果承诺，转为补证或协作请求；资源不足不能归为态度问题。竞争解释可交溯因推理，关系中的反馈可交反馈回路，选项对参数很敏感时交敏感性分析；按当前缺口接续。
