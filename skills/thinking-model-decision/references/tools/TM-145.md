# TM-145 · 奥卡姆剃刀

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
同一件事出现几套故事、解释越讲越完整却不断补前提，或想判断一层动机是否必要时用。145检查解释的额外承诺；尚未核实异常或没有合理候选时先交TM-104，证据多且各方选择性举证时交TM-050。已明确且可复现的故障直接处理，不为调用凑故事。

## 最小输入与追问
本次要解释的具体行为或现象、时间、证据来源与未知、现有候选、受影响的行动及期限。已有信息直接用，只追问最关键缺口：“哪些行为已经确认，哪些原因是你后来补上的？”不要求先列满几个假设、打分或猜他人内心；用户提供的经历保留为其报告，不擅自升格为独立核实。

## 转换与分支
**先保留现实处理。** 已有伤害、承诺或迫近期限时，必要保护、补救和履约可先行，不必等证明动机；不要求冒险对质或以善意解释免除责任。核实解释与处理影响可以并行。

1. **固定共同事实。** 写清现象与必须解释的已知条件，标明可靠记录、用户报告、冲突和未知。分开“未回复”与“故意冷落”，也不把“在忙”自动当事实；不得挑选有利事实来制造候选等价。
2. **展开候选的承诺。** 对少量机制不同的解释，分别列支持、冲突、未知及新增假设；也可比较一个解释与其增加动机的版本。说明每项假设的作用及依赖，不按句长、条数或数字总分判胜负，不强迫候选互斥。
3. **先比证据，再试删除。** 证据明显区分候选时优先服从证据，必要复杂性保留。说明力相近时，选具体的额外设定，问“拿掉它，哪些已知事实或可检验预测会解释不了？”记录删除前后差异：无增益可暂不纳入工作解释；删后遗漏事实就保留。未知不等于假，暂时不用不等于证明不存在；连说明力是否相近都不清楚时不硬选。
4. **给暂定状态及更新条件。** 明示暂用较少额外承诺的解释、按更强证据选另一解释、保留并列，或增加必要机制。选一项代价合适的区分性核实，列谁、何时、查什么、什么结果会更新。若任何结果都被补成支持，改写可被削弱的命题；仍不可检验则标明限制，停止编补动机。
5. **落实下一步并留复查。** 依据期限、损害和可用权限安排必要或可逆行动；查明动机不是履约与保护的前提。区分拟定、实施、查验结果与解释更新，不以一句回复、故事流畅或感觉安心宣布问题解决。

## 最小成果与验收
输出“解释—证据（支持/冲突/未知）—额外假设—删除测试—验证/更新条件”的短表或等价文字，加一个现实行动。说明具体移除或保留了哪个设定、依据是什么、仍不知道什么；无法排序就保留分支。把结果交回主流程的解决思路和HTML行动计划，不以模型讲解代替下一步。

## 停止、边界与交接
已能安排下一步、继续分析无新信息、命题无法检验或期限要求行动时停止。一句短解释可能隐藏多项承诺，多句也可表达同一承诺；不能按“假设少”宣布更真实。未观察、难取证、没有反证均不等于不存在；需要才能解释资料的机制必须保留。

不以简单解释否认已证实的威胁、损害或持续失约，不把“先当他无心”变成容忍要求。原文汉隆剃刀、防骗格言与暴力风险清单仅归档，未在本轮独立核验，不得转成动机裁决、预测评分或安全保证。不以假设条数算概率；原文三项八成相乘在概率依据与依赖关系未知时不得使用。不把本工具当专业诊断、法律判断或因果确证。

需要核查更多竞争解释交TM-050；需要生成解释或确认异常交TM-104；找到可干预机制时才交WW-3.3；新证据及基准率足以支持更新时才交WW-3.4，不给缺数据的情境补造精确概率。按缺口选择，避免重复跑整套表格。
