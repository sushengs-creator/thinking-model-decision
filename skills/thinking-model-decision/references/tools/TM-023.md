# TM-023 · 区分体验变化与特定处理的实际作用

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
有人把“做完感觉更好”直接解释成某处理有特定效果，或反过来把真实困扰全说成想出来时用。严格的安慰剂概念属于治疗情境；用于学习等日常场景时仅借其审查期待与情境影响，不能冒称同一医学机制。输入处理前后记录、宣称改善的指标与同时变化的条件；关键追问：“这里说的有效，具体是哪一种变化？”

## 转换动作
1. 分开主观体验、行为表现与客观指标，各保留原始记录。满意、信心或轻松是真实报告，却不能直接替代任务完成、能力提升或疾病变化。
2. 列竞争解释：处理本身、期待与照料情境、练习、自然波动、极端表现后回落以及测量改变。前后变化只能说明共变，不自动确定是哪条路径；也不能把对照组的一切改善都归功于期待。
3. 判断现有对照能排除什么。非医疗的低风险场景，可建议在知情条件下保持任务和评价标准一致，比较流程差异；不设计欺骗或让人承受损害的试验。资料不足时收窄效果宣称。
4. 若涉及具体疗效、症状或治疗选择，停止由模型直接给结论，交当前可靠研究与合格专业判断；不凭原文故事、比例或生理叙述建议停换治疗，不责怪当事人信念不够。

## 最小成果与停点
交付改善指标、竞争解释、已有证据能够支持的最窄表述与缺证项。感觉改善和特定因果效果已分清即完成；不以体验消失或用户相信为验收。客观条件改变时重新核查，任何未实施对照都只记计划。

## 工具箱接口
非医疗的任务指标可交试验设计或复盘工具；极端初始值可交回归基线检查。专业医疗问题交相应查证流程，本工具只整理待核命题和证据要求。
