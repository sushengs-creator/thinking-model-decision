# TM-013 · 把不同标签的钱还原成总账和真实约束

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
同样金额因工资、红包、奖励或日均价格而被不同对待，预算小格子遮住总支出时用。用途受限的补助、借用款与报销规则是真实限制，不能通过改标签解除。输入账户名称、实际支出、可用总额与必须保留的用途；缺口问：“这笔钱有哪些已经明确约定或必须保留的用途？”

## 转换动作
1. 列出每个账户的来源标签、用途和自行设定规则，分别标真实约束与心理分类。“奖励随便花”是规则，不是钱突然没有机会成本；为自控而分桶也可能有价值。
2. 把按天、分次、积分抵扣等表达还原为相同期间的总成本，补上必要配件、续期与资金占用。若金额未知就列待确认，不因每次便宜而绕过总额。
3. 保持商品、用途和总资源不变，只交换来源标签，再看意愿差异。询问变化是否来自用户真实价值排序，如送礼与自用不同，或仅因“意外所得不算钱”；不把所有不同意愿都算不理性。
4. 在总资源和必要保留范围内修订账户规则：可调拨多少、何时复核、哪些用途仍受限制。把培训叫“投资未来”不能证明值得，仍须用实际用途判断。

## 最小成果与停点
产物是总账、标签规则、真实限制与拟调整方案。总成本可见、调整不越过硬约束且理由与价值一致，即可结束；不要求把所有账户合并。发现约定用途或未来必要支出遗漏时改判，建议与实际调拨分开记录。

## 工具箱接口
可支配金额可交机会成本或需求比较工具；用途限制不清先交事实澄清。若只是先见价格带来的偏移，才加入锚点校准，不把所有消费犹豫都解释为心理账户。
