# TM-081 · 凯利准则

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
只在可重复、盈亏改变下一轮资本、分布可估计的机会中讨论理论比例。一次性人生选择、概率近乎未知或损失无上限，不能硬算。需要隔离风险资本、概率依据、净收益与完整损失、费用、相关风险及流动性；条件不清时问：“这个机会每轮具体怎样结算，下一轮还能否以同样规则参与？”

## 转换动作
1. 核实重复与复合前提，明确目标是否适合长期对数增长；先划出不影响基本生活和责任的风险资源。自信不等于优势，无法支持正优势先补证，确认无优势则不参与。
2. 匹配公式。二元全损且赢时每单位净赚b、胜率p时，正优势下理论比例为(bp−(1−p))/b；不允许反向时非正优势取零，不把负数当直接反押。多结果或部分亏损须对Σpᵢlog(1+frᵢ)求适当可行解，确保各可能结果中1+frᵢ>0并满足无杠杆等现实限制。
3. 用可信保守与基准参数查看敏感性，区分算术准确和估计可靠。折扣理论值，并同时约束集中度、总风险、现金和有限期限损失；分数凯利不能创造优势，也不保证不亏。不要把其他赌局的示例比例当本题半凯利。
4. 按每轮新资本、分布和相关性更新。出现优势消失、退出边界接近或参数失效时停止沿用旧比例；不能用单次输赢或翻本冲动调整。

## 最小成果与停止
交付优势证据、收益分布、适用公式、理论比例或不可计算结论、折扣理由与硬上限。前提和不确定性清楚即完成，信息不足时产物是补证或降暴露建议。公平赌局的算术期望不变不代表固定比例下对数增长为零，不能混用。

## 工具箱接口
概率与收益依据不足交证据工具；连续路径与退出检查交非遍历性；非公式适用的选择交可逆决策或多维取舍。理论结果、个人选择、实际投入和长期效果分开，计算不是下注命令。
