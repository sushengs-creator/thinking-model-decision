# TM-074 · 古德哈特定律

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
数字越来越漂亮，真实体验却没改善，或要把一个代理数直接挂奖惩时用。不是所有指标一成目标就失效，也不是一见异常便认定造假。需要真实目标、代理指标、原关联依据、优化压力、行为与独立结果；关系未明时问：“当初为什么认为这个数字变好，就代表你们关心的结果变好？”

## 转换动作
1. 还原目标到代理的联系，反问只想抬高数字可以怎么做。分别查极端筛选混入噪声、超出原有适用范围、另一路径推高指标、参与者迎合规则；前三种无需有人作弊，几种也可能并存。
2. 查达标线前聚集、难测工作被放弃、成本转嫁和指标与独立结果分离。把可观察变化与动机推测分开，先抽查现场与具体成果；不能以可疑分布直接给人定性。
3. 调整指标权重与约束：用少量主指标跟进进展，以护栏保住不能牺牲的维度；降低单一数字决定全部奖惩的力量。定性复核写可审查理由，保留透明申诉，不能从数字独断换成人情独断。
4. 用未直接参与奖励的结果、代表作和用户反馈重新核验联系。若数字持续改善而目标停滞，则降权、修改或退出；指标换新后仍需观察新的适应行为，不用不断增加项目数掩盖失真。

## 最小成果与停止
交付目标代理链、主要失真路径、主指标与护栏、独立核验资料和修订触发。关键路径有对应改法及复核点即可完成；未发现压力改变关系时不强套定律，转查测量或实际业务原因。提出指标方案、规则生效、行为变化和真实结果分别记录。

## 工具箱接口
指标一开始就代表错对象时交测量模型；需要解释参与者如何适应规则时交激励或二阶工具；想知道改考核是否真改善结果时交因果工具。接口输入是具体失真证据，不是“所有考核都有害”的笼统结论。
