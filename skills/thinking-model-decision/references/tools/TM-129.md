# TM-129 · 交互记忆系统

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
有人懂、文档多却解决不了共同任务，或换人后交接失灵时使用。团队需要知道谁掌握什么，并能取得、核实、组合；联系人名单不等于知识系统，个人专业能力仍不可缺。

## 最小输入与追问
具体任务及卡点、可能知识持有人、可访问记录与版本、人员变化。关键追问：“要完成眼前这一步，缺的知识由谁在最近一次同类任务中实际用过？”岗位负责人、声望专家和此次知情人可能不同。

## 转换与分支
1. 固定共同坐标：对象、编号、时间、待作判断、规则版本及已查内容。问题未对齐先澄清，避免不同人各答不同事项。
2. 以相关记录和实际经历确认谁提供哪部分知识，再查能否联系、访问权限及备份来源。找错人、暂取不到与团队根本不懂分开；无知识需补学或外援，不能只加强沟通。
3. 单条答案核查依据、日期、适用条件，再把多源信息按同一对象、时间和版本拼合。分歧保留各方依据和可检验条件，不用多数或信任替代核实。
4. 让接手者实际找一次记录、处理典型例外并联系相关人，形成可查判断。新增知识、维护责任、版本与备份交实际负责人确认并同步，后续同类任务再验收。

## 最小成果与验收
交付任务知识图：需要什么、谁提供、存哪里、依据版本、备份与阻碍，并为主要卡点指定处理人。验收是接手者能取得和核实信息、继续任务；文档已发或名字已改只算过程。

## 停止与工具箱接口
知识齐全却争议谁做时，转权责资源协商；无访问权先处理授权，不借知识保全索取越权资料或阻止人员流动。隐含现场经验交默会知识，定义差异交共同基础，同步新分工交共同知识。
