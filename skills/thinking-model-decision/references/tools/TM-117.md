# TM-117 · 可取的困难

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
当下跟着能做，隔时忘记或混淆类型，需要改变练习安排时使用。可取的是促进提取、区分和重组的困难；疲劳、威胁、糟糕说明不是有效挑战，努力感不能证明学会。

## 最小输入与追问
未来使用目标、基础能力、现有提示、练习节奏、反馈来源和可用时间。关键追问：“将来真正使用时，你需要自己想起什么，哪些资料可以查？”目标允许查阅就不强加闭卷记忆。

## 转换与分支
1. 先排除前置知识缺口、说明不清、无关干扰和疲劳；连提示也无法推进时补教学或拆小任务，别把持续失败解释为学习更深。
2. 按断点选择一项：依赖材料就先尝试回忆再核对；隔时忘就分散复练；相近题型混淆就交错呈现并先选法。交错不是切换无关事务，组合越多也未必越好。
3. 调整提示、间隔或变化幅度，保留可尝试和纠错机会。反复同错先诊断；已稳定独立做对再增加间隔或变化，不套人人通用日历和成功率阈值。
4. 在相同标准下检查延迟表现与新任务，记录耗时及恢复需要。即时变慢而长期改善可保留；长期不改善或负担过大则降难、补基础或改方法。

## 最小成果与验收
交付一种具体加难动作、正确反馈来源、恢复安排、延迟检查和降难信号。比较的是目标技能的保持和迁移，不是挫败程度；存储强度等解释概念不能由感觉直接测出。

## 停止与工具箱接口
难度已妨碍理解或损害必要休息即停加码。概念关系缺口交图式，提示依赖交编码特异性或迁移，训练弱点已明确交刻意练习；不以练习完成替代实际表现。
