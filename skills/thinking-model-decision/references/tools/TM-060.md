# TM-060 · 二阶思维

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
准备改奖励、排名、补贴或扩大小试，直接指标看起来很好但后续影响不清楚时用。二阶不只是“更久以后”，而是前一步改变了后一步的条件；复杂故事也不等于因果证据。需要真实目标、不能牺牲的维度、行动、相关人和时间尺度；缺目标时问：“这次变化最终要改善什么，你还想同时保住什么？”

## 转换动作
1. 写出行动的直接改变，并给“不行动”保留一条后果线。把立即可观察的变化与预期好处分开，避免把愿望当已发生效果。
2. 逐类查看参与者会适应、规避、退出还是转嫁成本，以及资源、容量和规则如何变化。将最重要的两三条写成“直接结果—反应或状态变化—间接结果”；每支箭头注明证据、假设和延迟，正负影响都看，不无限延伸链条。
3. 检查后续结果是否反过来增强或抵消原行动，是否损伤真正目标。为关键链指定能较早观察的信号及解释分歧；指标变化若也可能来自别的原因，保留竞争解释，不能将行动后所有变化都归给它。
4. 可逆且验证值得时，限定范围与复查条件后实施；不能合理试行时提高证据要求并准备替代。扩大规模前重看拥堵、激励与人群改变，原有小范围结果不能自动外推。

## 最小成果与停止
交付影响链、关键假设、早期信号及继续、调整条件。足以识别最可能改变决定的反馈和不可逆后果即可结束，远端猜测不继续堆叠。新行为与预期不符、规模或规则改变时重画链；建议、被接受的方案、执行和效果证据分栏保留。

## 工具箱接口
若反应主要来自各方利益，把参与者节点交给激励或博弈工具；若争议是某变化是否由行动造成，交给反事实因果；需安排落地时仅将已选择的链和预警交给执行工具。二阶分析帮助补全成本收益，不以任何想象副作用否决行动。
