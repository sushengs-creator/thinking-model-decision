# TM-029 · 拆开跟随链中的独立信息与模仿

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
一批人先后跟进，队伍越来越长被当作多条证据，但各自依据说不清时用。真实网络价值会随参与者增加，跟随也可能受离群惩罚影响，不能简单贴不理性标签。输入加入顺序、本人目标、各方依据与退出成本；缺口问：“最早几位行动者实际知道什么，后面的人引用了谁？”

## 转换动作
1. 先写本人不看队伍时的选择理由。若理由只剩大家都做，标为待补证据，不立即反向退出；若协作兼容本身创造价值，保留为真实收益。
2. 画行动与信息链：谁独立试过，谁只听说，谁引用同一演示或榜单。同一信号经十个人转发仍是一个来源，未查到的链条注明未知，不能把人数直接当可靠度。
3. 检查参与者的激励、承担损失者与退出顺序。有的人可能怕排名落后或失去合作，行动不表示看好；多人同时撤出是否造成拥堵、资源骤减等反馈，要单独作为风险。
4. 用实际需求、独立试验和可承受成本定加入范围、观察期限与退出条件。避免进场等别人决定、退出也等别人先动；若条件可逆，可先限定使用而非长承诺。

## 最小成果与停点
交付来源链、独立信息缺口、激励与反馈风险、加入或退出的证据条件。能区分新增参与与新增信息，并为本人行动给出依据，即完成；不以逆势或押中趋势验收。真实独立验证或网络条件改变时更新判断。

## 工具箱接口
来源缺口交证据核验，集体撤出反馈可交系统回路工具，迁移方案交约束与执行工具。若主要是会议上怕反对而附和，改用表达压力视角，不虚构先后级联。
