# TM-072 · 信号检测论

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
过滤、审核或提醒系统越报越多，却仍漏重要事项时用。报警多不代表更准确，误报多也不能直接一律提高门槛。需要实际信号定义、判断结果、独立核验、两类错误代价及响应容量；标签不清时问：“什么情况才算真的需要处理，你们怎样确认它确实存在？”

## 转换动作
1. 按实际有无信号与判断有无信号画四格：命中、漏报、误报、正确拒绝。命中率分母是真实信号，误报率分母是无信号情况；“报警中有多少假的”另列，不能拿它替代误报率。未核验样本明确标未知。
2. 在同类对象与条件下同时看命中和误报。两者一起上升可能只是降门槛；同误报率更多命中或同命中率更少误报才支持辨别力改善。工具、人群或基准率变化先重建可比口径。
3. 若主要是辨别力弱，补有效信息、训练或换工具；若主要是门槛取舍，结合真实信号频率、两类错误损失及各自承担者定标准。没有可信代价与记录时给条件方案，不编通用阈值。
4. 把检测与实际处置接起来：检查去重、分级、人工复核和处理能力。提醒过多导致忽略属于后续响应问题，应观察真信号是否被积压，不能仅把系统报警数当成果。

## 最小成果与停止
交付四格及分母、能力与门槛的诊断依据、门槛权衡和响应改法。已能定位主要缺口并提出可检查调整即可完成；真实标签无法获得时先交核验方案，不强判性能。场景、容量或错误后果变化时重评；建议调整、实际设置和最终处置效果分开。

## 工具箱接口
信号定义不对应真实目标时交测量模型；误报后的真假概率交基准率与贝叶斯；调整可能改变行为时交二阶思维。涉及专业安全阈值需相应标准，本工具不凭一般经验生成设置值。
