# TM-049 · 把迟早有效改成有条件有期限的可检验主张

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
“迟早会成功”“失败只是还没做到位”让任何结果都不能改变判断时用。只对经验主张设计观察检验，价值与审美即使不可证伪仍有意义。输入主张、对象、期限、指标、测量方法和必要条件；关键追问：“出现什么具体观察，会让你缩小或修改这个判断？”

## 转换动作
1. 将价值、偏好和经验预测分开，把后者写成在什么条件下、针对谁、何时观察什么变化。数值阈值需有基线与用途依据；没有资料先定可观察标准，不任造成功率。
2. 事前列支持、削弱或冲突结果，并写辅助条件：是否真正执行、对象是否触达、记录口径是否稳定。条件要能被检查，不能等失败后才补一条永远无法满足的免责要求。
3. 出现冲突先查测量与执行，再判断核心机制。单次异常不机械推翻复杂解释；概率性主张更不能用一次没发生证明为假，需要对应样本和合适检验。
4. 若调整辅助条件或范围，保存旧预测与结果，说明新预测会在哪个未来窗口被检验。只解释已有失败却不产生新风险的补丁，不算恢复检验；反复延长时间必须有新依据。

## 最小成果与停点
产物是一条可结算主张、削弱条件、辅助检查表与必要的修订预测。别人能判断结果支持到哪一步，即完成设计；可检验不等于已证实，也不等于因果成立。某轮未达标准可以否定该轮假设，不能宣布整个方向永无价值。

## 工具箱接口
有竞争解释时交假设比较工具，缺测量交试验与数据工具，到期结果交复盘。若核心只是用户想维护的原则，退出证伪流程，改澄清实现它的可调整方法。
