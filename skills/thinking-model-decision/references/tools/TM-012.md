# TM-012 · 用等价重述检验选择是否被说法带动

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
同一选择换成“保住”或“失去”就改变倾向，或讨论被某个词限定时用。两种表述若实际费用、时间或结果不同，选择改变可能完全合理。输入原句、真实选项、共同分母与目标；缺口问：“两种说法背后，哪些具体结果相同，哪些不相同？”

## 转换动作
1. 去掉形容词，列各方案的结果、成本、时间和概率信息；概率没有来源就标未知。先核对分母和互补关系，避免把不等价算例当重述，不能用词语翻转偷换事实。
2. 对确实相同的结果各写一版获得描述与损失描述，再记录用户倾向。识别隐含参考点是现状、原承诺还是理想状态；变化只提示呈现有影响，不直接宣布此前决定错误。
3. 若困扰来自“失败者”“浪费”等标签，换成用户认可的目标和具体选择重新提问，并补回被原议题遗漏的维持、小试或调整范围。价值词重写与严格等价实验分开，不把修辞共鸣当实验验证。
4. 在中性结果表上说明取舍理由，同时披露重要收益和代价。若用户在两种表达下都偏好同案，保留该选择，但不据此宣称完全免疫框架影响。

## 最小成果与停点
交付原表述、等价性核对、两种重述和基于完整结果的选择依据。目标与事实不再随措辞偷偷改变，即完成本轮；若发现信息不等价，停止翻转练习，直接补事实。用户赞同新说法不是方案接受或执行证据。

## 工具箱接口
中性结果表可交多标准取舍工具；若核心是参考点造成不愿认亏，才加入损失判断工具。沟通材料可使用清楚表达，但不能为得到认同隐藏风险或编造因果。
