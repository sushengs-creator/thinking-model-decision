# TM-062 · 信息价值

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
在立即决定、继续调研和小试之间选择，或给有限调查预算排序时用。没有具体可调整决定，先澄清决定；纯学习、审美和长期探索另记价值。需要选项、无新信息时的选择、关键未知、最晚决策时间及成本。缺行动基准时问：“如果现在拿不到更多信息，你会先选哪条路？”

## 转换动作
1. 建立“可能答案—到时能改的行动—改善来自哪里—最晚到达时间”表，包含仍不清楚的结果。所有答案均不改变行动时，固定选项下单次决策毛价值为零；发现新选项的价值另列。来得太晚的信息移出当前候选。
2. 无可信概率或可比收益时，只做定性分支与成本范围，不声称算出价值上限。输入足够且风险偏好适用时，比较无信息最佳期望结果与完美信息下的期望结果，得到毛价值上限。现实调查按各状态下信号概率更新，逐信号选行动再加权；总体准确率不足以算后验，最好分支也不能代表整份调查。
3. 扣齐新增费用、准备、等待、沟通处理、调整及错过窗口的代价，已进入收益表的不再扣。成本超过可信上限则排除；区间已足以选择就停止求精。比较及时行动与更便宜但足够的信息渠道，小试也必须及时且有区分力。
4. 为所选获取建议写到账期限及什么答案足够选择。答案已足够、窗口将关闭或继续获取的改善不抵成本时停止搜索，剩余不确定性进入行动条件。

## 最小成果与停止
交付当前行动、关键未知、答案分支、价值依据、完整成本及获取与停止建议。分支可执行、成本未漏、停止点清楚即完成；找不到会改变动作的未知，允许“暂无明确决策用途”。建议获取、用户确认和已获信息分开记；选项、期限、信号可靠性变化时重估。

## 工具箱接口
需要更新各答案下的判断时接贝叶斯；灾难损失及硬约束先交约束工具，不能用平均收益抵消。确定值得验证后才交调查或实验工具；学习兴趣不受本次决策上限否定。
