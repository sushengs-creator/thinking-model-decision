# TM-138 · 期望价值理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
认可某事有用却迟迟不投入，或数个现实选项争夺时间精力时使用。成功期望、兴趣/用途/身份价值和代价须放进情境比较；没开始不证明另一选项必然胜出，提示、疲劳、资源也可能阻断行动。

## 最小输入与追问
当前可行选项、各自目标、可用时间支持、已有表现与必须履行的约定。关键追问：“这段时间实际能选哪些安排，各会占用或保留什么？”包含休息、暂缓和既有任务，不能把不存在的自由选择当真。

## 转换与分支
1. 写各选项在现实条件下预期走到哪一步，以经历或材料支持；未知就标未知，不把信心换算成功率。能力判断偏差才进一步检查自我效能。
2. 分列兴趣、用途和身份意义，让本人说明权重与冲突；再列精力、情绪压力及被挤掉的活动。机会损失与时间成本可能重叠，避免重复计价，不强设总分或价值次序。
3. 找能改变选择的未知项，如内容是否适用、时间是否真实可得。先查现有资料，必要时作低成本试用；关键资源或义务需协商，不能用价值比较自行取消承诺。
4. 给带条件的暂定安排与复核点。若问题在条件先补条件，若价值和代价确实不合适允许缩小、延后或放弃；选择后仍未开始，再查具体机会而非反复讲好处。

## 最小成果与验收
交付现实选项、期望依据、多种价值、不可承受代价、关键未知及条件选择。验收看比较是否足以指导下一安排，后续分别记录开始、持续、任务进展与成本；点头认可课程不算投入成果。

## 停止与工具箱接口
无实际选择权先澄清授权与资源，避免以身份羞耻推动投入。自主压力交自我决定，启动障碍交福格，结果对未知敏感交敏感性分析；这些视角按需使用，没有固定递进顺序。
