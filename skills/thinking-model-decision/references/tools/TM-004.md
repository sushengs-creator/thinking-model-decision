# TM-004 · 补出退出者与分母再判断经验能否迁移

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
用成功者、留存用户或存续项目推导一般规律，却看不见退出过程时用。如果问题本来只关心当前留下的成员，不能强行把所有历史参与者纳入。输入目标总体、眼前样本、声称有效的做法及记录来源；缺口问：“你希望这个结论适用于哪些人或项目？”

## 转换动作
1. 从目标总体画到现有名单：谁有机会进入、谁未回应、谁退出、谁的记录被删。给每个关口标筛选条件，区分资料虽在但没注意与失败后根本未被保存。
2. 回找采用同样做法却失败、放弃或未被展示的对象，并核对起始人数。不能只补一个失败故事就自称完整；追不回时注明缺失群体及结论可能偏向，不把未知失败率写为零。
3. 把“成功者共有特征”与“该特征带来成功”拆开。尽量比较起点相近、做法不同者，记录资源、时间等混杂因素；缺对照时只保留候选解释。
4. 判断经验可迁移到什么条件：有完整队列才描述相应比例；仅有精选案例时最多形成待试做法，建议范围可控的验证，不能直接许诺成功。

## 最小成果与停点
交付一张筛选路径、缺失名单及带条件的经验结论。重要退出环节已显露、分母可靠性与迁移限制已说明，就结束这一轮；不要求找齐永远无法恢复的样本。发现当前总体与原案例不同应改判，而非把成功一律归于运气。

## 工具箱接口
样本图可交给调查设计工具制定补访；留下的候选机制可交因果或小试工具。若只是某条新闻特别鲜明、记录并未筛掉谁，则改用显著性校准，不混为同一种缺失。
