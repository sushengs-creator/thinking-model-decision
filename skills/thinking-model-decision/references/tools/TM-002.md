# TM-002 · 检查支持与反对证据是否受到同样审查

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
结论先于调查、异议总被另找理由排除，或只想让助手论证自己正确时用。单纯坚持已有高质量证据不等于偏差，也无需给每个反对意见同样篇幅。输入当前结论、依据、准备采取的行动与期限；关键缺口问：“出现什么可观察的情况，你会愿意重新考虑这个判断？”答不出不替用户捏造反证。

## 转换动作
1. 在补材料之前冻结原判断：把“他不负责”写成具体行为预期，记录什么时候会看到什么；无法被观察检验的标签先降为感受或价值评价。
2. 找一个能解释同样现象的竞争解释，并为双方各列能区分它们的观察。不要把所有可能结果都解释成支持自己；也不要求反方提出不可能取得的证据。
3. 对同一份材料做对称审查：来源可靠性、覆盖范围、其他解释，对赞同和反对均用同一尺度。找反证是补漏，不能把它变成只收反方资料的新偏向。
4. 按证据决定保留、缩小或撤回结论，并注明理由；到期限对照原预测，分清推理过程、实际结果和偶然因素，不事后重写自己当时“早就知道”。

## 最小成果与停点
交付原判断、竞争解释、区分性证据、改判条件和到期动作。已有足以支撑当前行动的证据且重要反例已处理，即结束本轮；未找到反例只能记尚未找到。若核心争论是价值偏好，停止事实证伪，转为讨论各自重视什么。

## 工具箱接口
日志可交给学习或复盘工具追踪预测偏差；若新材料真假尚不清，先交证据核验类。只有需要比较证据在不同解释下的意义时，才加入更新判断工具，不把“用了两个工具”当双重证明。
