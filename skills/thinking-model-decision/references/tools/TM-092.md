# TM-092 · 复杂适应系统

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
适用于规则刚生效时有用，后来参与者学会绕开、合作或退出，彼此又不断改变环境的情境。部件多不等于复杂适应；已明确的机械故障先处理故障。最小输入是参与者、各自目标、可见信息、互动方式和变化记录；先补问：“这项改变出现后，哪些人会调整做法，他们各自想保住或得到什么？”

## 转换动作
1. 把参与者的“看到什么—能做什么—得到或失去什么”放到同一张图上，连接彼此行为造成的影响。标明观察与猜测，补上承担代价但未发声的人；系统解释不取消个人和组织的责任。
2. 推演两轮反应：第一轮直接响应新规则，第二轮学会适应后改变策略。并列配合、绕行、转移、退出等有根据的分支，不认定所有人必然钻空子；检查局部收益怎样改变他人的选择。
3. 从边界、信号、激励、连接、记忆中选择实际可改的位置，写出希望改变哪条互动及可能的反作用。有授权且可回退时才小范围尝试；明确故障或紧急保护不必为了模型而实验。
4. 留下规则版本、参与者反馈和效果时间线。效果衰减时分别检查学习适应、负担转移和外部变化，给反应留下合理时间；不能只凭短期数字把方案定为成功。

## 最小成果与停止
交付“参与者两轮反应图”，包含关键互动、竞争解释、可改位置和重判信号。能够解释一条重要的适应链即可完成，不追求预测所有人。没有学习或策略调整证据时，改用固定反馈或直接因果分析；边界、角色或规则变化时重画。

## 工具箱接口
指标诱导的适应交给古德哈特工具；闭环放大交给反馈工具；整体模式如何生成交给涌现工具；授权和利益偏离交给委托代理。建议、各方接受、规则真正执行和持续效果分开记录。
