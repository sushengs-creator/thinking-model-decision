# TM-136 · 双重编码理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
会背步骤却找不到对象、看图熟悉却说不出含义，或图文关系不一致时使用。言语与非言语表征可相互联系；非言语不限视觉，文字加相同朗读不自动构成双重编码，图多也不保证理解。

## 最小输入与追问
具体识别或操作目标、教程与实际对象、当前错误、版本和辅助需求。关键追问：“看到这个名称时，你会指向哪个对象或关系，为什么？”先核对规则、权限及前置知识，不能把条件不足归给脑内表征。

## 转换与分支
1. 确定要辨认的名称、起终点、方向或空间关系，先由文字指认或画出对应。术语不懂先补含义，位置找不到再对照实际对象；图的美观不作评分。
2. 反向从对象或图说出名称与关系。只遮答案标签，保留可识别特征；遮完不可辨就换实物、简图或可访问形式。无法命名与方向理解错误分别修正，不诊断固定学习类型。
3. 名称、箭头、文字冲突先查材料来源与版本，改材料后重试。原图能做而新图不能，先确认规则相同，再检查是否依赖颜色位置；规则已变须补学变化。
4. 以测试对象执行目标任务，核对最终位置或关系，按需要隔时或换同义外观再试。能双向解释却操作失败，查具体动作、资源和环境，停止单纯加图。

## 最小成果与验收
交付关键名称—对象—关系对应、可定位错误、修正材料和任务检查安排。验收看准确对应及实际任务，区分提示下完成与独立完成；实际目标允许的辅助不必撤掉，漂亮和熟悉不能代替效果。

## 停止与工具箱接口
必要条件未具备先解决条件；重复对应已正确就不再堆材料。关系组织可交图式，方向区别可交变易理论，动作练习交刻意练习；一次改善不证明脑内机制或长期记忆。
