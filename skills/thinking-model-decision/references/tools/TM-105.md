# TM-105 · 敏感性分析

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
基准方案看似划算，但结论依赖次数、成本、收益估计时使用。它检查结论对输入的脆弱程度，不预测这些输入发生的概率；目标和关系尚不明确时先澄清，不能靠随意打分制造确定性。

## 最小输入与追问
可比方案、计算关系、固定量、不确定量的依据与范围、联动关系、非金钱偏好。关键追问：“哪些估计一旦偏一点，你就可能改变选择？”缺范围时列待查，不默认为零。

## 转换与分支
1. 固定同等需求与比较周期，补齐额外交通、浪费、转换、维护和增购成本。需求已改变时重建账，不用为回本增加无用消费。
2. 用历史记录、可确认报价和已知日程给输入定范围。只有愿望无依据时先用条件表达，明确哪些数字仅为演算假设。
3. 分别改变关键输入，再计算有理由同时变化的组合。次数变少但每次数量变大时同步调整单位收益；不是把互不相容的极端值任意拼接。
4. 找到触发改选的边界，连同固定条件一起报告。若合理范围内始终同选则暂缓继续查数；若靠近边界，优先核实能改变决定的输入，或用短期试用取得记录。

## 最小成果与验收
交付关系式或定性关系、单项及联合情景、带条件翻转点、核实顺序与暂定选择。计算可复查，结论标明适用范围；方便、喜好等偏好单列，由使用者权衡。

## 停止与工具箱接口
关系遗漏或成本口径错误先修模型，不能多算几次掩盖。新需求、报价或联动改变时重算。最敏感未知可交信息价值，方案无法撤回可交可逆决策，价值冲突交目标澄清；不以精确小数替代未知。
