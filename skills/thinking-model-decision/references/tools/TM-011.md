# TM-011 · 把做什么都没用拆成可控行动与真实障碍

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
反复受挫后从“这次没做成”扩展成“做什么都没用”，连可行尝试也停下时用。绝对化语言不是心理诊断，放弃确实无效的行动也可能合理。输入具体受挫任务、最近结果、外部条件和可得支持；缺口先问：“最近一次没有做成，具体卡在哪一步？”

## 转换动作
1. 把笼统自评还原为任务、时间、做过的动作和观察到的结果，先承认真实障碍。不把情绪当错误，也不靠一句积极口号覆盖失败记录。
2. 沿内部／外部、稳定／可变、普遍／特定三轴拆归因。每个解释都找事实支撑：权限不开放是环境限制，方法未学会可能可调整；内部原因未必坏，外部原因也未必可变，不把三轴变成强制乐观打分。
3. 选一个确实能控制、成本可承受且能得到反馈的小动作。把目标设为验证某一步是否可行，例如在已有权限环境运行示例，而不是保证整个项目成功；不编“成功率八成”等数字。
4. 记录动作改变了什么。有效只证明相应条件下这一步可行；无效则检查方法、支持或环境，允许暂停与求助，不把再次受挫当意志不足。

## 最小成果与停点
交付具体问题、可控／待协助／暂不可控三类因素和一次行动观察表。能够限定失败范围并提出可检验的下一步即可结束，不以恢复信心或情绪归零验收。若障碍持续不可改变，停止要求重复尝试；困扰长期严重影响生活时不作诊断，支持寻求合适帮助。

## 工具箱接口
小动作可交执行与反馈工具；外部限制需资源或参与者协调时再加入相应工具。若问题是目标不值得继续，交取舍工具，不能把停止一律视为需要纠正。
