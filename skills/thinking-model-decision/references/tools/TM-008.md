# TM-008 · 区分真实持有价值与仅因拥有而加价

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
自己的物品、订阅或方案总觉得比同类更值钱，出售与购买意愿明显不同时用。真实迁移成本、个人信息与纪念意义必须保留，不能把不愿卖都诊断成偏差。输入继续持有理由、未来使用、持有成本与可选去向；缺口问：“从今天开始，留下它最具体能带来什么？”

## 转换动作
1. 先记拥有者视角的保留理由与愿卖条件，区分原价、已付心血和未来利益。原价可作来源信息，但不能自动充当今天价值。
2. 暂设尚未拥有、手里保留等值资源，问现在是否愿意重新获取，以及愿意付出多少。允许答案是非金钱价值；没有市场价格的纪念品不强迫折现。
3. 解释两种视角的差额：逐项列未来使用便利、资料迁移、别人不知道的品质、不可替代情感和仅由“这是我的”引起的不舍。差额只是待解释信号，不能精确等同偏差大小，更不能用买方低报价代替客观价值。
4. 对保留、转让、暂存或先导出再停用比较从今天起的结果。若真实迁移费用大，先降成本再决定；若只是未来可能会用，设一次明确检查点，而不无限自动续期。

## 最小成果与停点
交付两种视角、可解释价差、剩余未知及一项持有或退出条件。能说清为何保留或何时放手即完成，不要求一定出售，也不以用户舍不得的感受消失为准。发现独有用途、隐性迁移损失时改判；物品归属有争议时暂停处分建议。

## 工具箱接口
真实未来代价可交给机会成本或方案比较工具；依赖很多时才用路径分析。纪念意义若是核心，交价值澄清，不再追求所谓完全理性的市场定价。
