# TM-097 · 信息不对称

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
对方掌握会改变交易或合作选择的信息，而自己难核实时调用。信息差不等于欺骗，也不限于成交前；双方都不知道未来属于共同不确定性。最小输入是选择、各方已知、关键未知和可取证渠道；先问：“哪条对方可能知道、你难确认的事实，会真正改变这次选择？”

## 转换动作
1. 把隐藏属性、共同未知和难观察的后续行动分开，标明谁可能掌握什么。检查交易条件会吸引或排除哪些类型；低报价本身不证明质量差，也不能仅由结果反推对方早已知道。
2. 区分对方主动发出的信号、我方设计的筛选和独立第三方核实。信号是否可信取决于不同类型模仿它的成本是否不同，以及材料能否追溯；昂贵、漂亮或同一来源材料很多，都不自动更可靠。
3. 选择与任务相关的样本、阶段交付或可核验证据。接受某套餐、保证金或分期安排可能反映现金、偏好等因素，不能直接给人贴类型标签；写下替代解释及补充核实方式。
4. 比较核实成本、等待、隐私和误排合适人选的代价，选择足以改变决定的证据。持续检查筛选规则是否只筛出善于展示的人；已足够的事实不再无限索取证明。

## 最小成果与停止
交付“信息差与验证方案表”：关键事实、持有者、现有证据、核实办法、成本和剩余不确定性。差异已足够缩小或剩余风险被明确接受即可完成；共同未知改用情景工具。来源冲突、交付范围变化或新证据出现后重判。

## 工具箱接口
证据更新和是否值得再查交给贝叶斯、信息价值工具；难观察行动的激励问题交给道德风险；代表自己办事的授权交给委托代理。收到材料、核验材料、接受合作、实际履约和结果分别记录，证书或样本不能替代最终交付。
