# TM-026 · 用具体任务与外部标准校准能力自评

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
初学、听课或一次成功后认为已经掌握，却说不出好坏标准时用。自信不等于无知，不能拿概念评价整个人，也不把网络山峰图当个人发展规律。输入具体技能、自评能完成的任务、作品与可用评价标准；关键追问：“在哪一种具体任务上，你想确认自己已经能独立做到？”

## 转换动作
1. 先记录预期表现和允许的辅助条件，把听过、能解释、能独立做、能迁移到新场景分别列出。会复述教程不能自动证明能处理真实限制，熟练也不代表能准确估计初学者困难。
2. 选一个代表任务及外部标准，明确合格结果、常见错误和必要约束。标准来自实际用途或可靠评阅，不能只拿别人点赞或一次好运当尺子。
3. 对比预期与实际作品，请适任评阅者指出具体差距及证据。记录哪些已达到、哪些未达到、哪些没测；不从某一环不会推断全部无能，也不从顺利一次推出稳定能力。
4. 为最影响结果的微技能安排补练，随后换一个有代表性的新场景再测。训练建议与完成记录分开，若标准本身含糊，先改善评价而不是加练。

## 最小成果与停点
产物是“事前自评—任务表现—标准差距—下一回合”记录。能力边界与误差可说明，并有对应训练或补证任务，即完成诊断；信心下降不是验收，低调也不证明能力提升。新场景超出已验证范围时重新校准。

## 工具箱接口
具体微技能差距可交刻意练习工具；真实任务分派可交约束与执行工具。若外部评价只剩模糊赞美，先转描述证据审查，不将评价者头衔当标准。
