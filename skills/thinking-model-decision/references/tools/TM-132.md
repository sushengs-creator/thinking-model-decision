# TM-132 · 福格行为模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
本人认可目标，在一次具体机会中没开始或当时做不成时使用。B=MAP 是概念关系，不能乘主观分数算概率；能开始却做不好转技能，完成动作却无成果转路径有效性。

## 最小输入与追问
认可的目标、可观察动作、最近一次没做的场景。关键追问：“最近一次原本打算做却没做，当时发生了什么？”想不起就保留原因未知，记录下一次自然机会，不编不自律故事。

## 转换与分支
1. 分开长期成果和当次动作，还原提示是否出现、察觉、知道下一步，以及当时的任务。买课时想学不等于当时愿意，收到提醒不等于有条件执行。
2. 从准备到开始逐项查时间、工具、权限、体力、认知与日程。提示错时换时机，缺技能给教学，缺资源先协调；动作过大缩为仍有意义的起步，不以缩动作掩盖组织资源不足。
3. 提示明确、条件具备仍不愿做，比较当时付出的代价、竞争需要和目标价值，允许改路径、暂缓或放下。多个解释保留，不用羞耻、密集催促或强制打卡补动机。
4. 写成下次安排：什么信号后做什么、谁准备条件、预计改善哪一环。需分辨原因先改明显一处，需快速解决可合改但不分配因果功劳；依真实机会约复看，不规定坚持天数。

## 最小成果与验收
交付目标动作、场景事实、障碍假说、调整与支持，分别观察提示、开始、完成和成果。先标建议，获认可也不记成已执行；下一次信号动作条件清楚即可结束本轮分析。

## 停止与工具箱接口
提示到了仍做不了回查条件，开始改善却成果无进展就停止启动主线，转学习或路径检验；目标不被认可重新选目标。内在障碍明确可交 WOOP，价值压力可交自我决定或期望价值；一次有效仅作线索，保留正常职责与退出空间。
