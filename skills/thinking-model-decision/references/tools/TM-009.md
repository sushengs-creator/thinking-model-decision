# TM-009 · 把注意变多与外界真实增长分开

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
刚学一个概念或关注一件事后觉得“到处都是”，并准备按热度加码时用。明确的同口径增长记录不能因为用户有关注起点就被否定；本工具检查趋势判断的来源。输入开始注意时间、曝光渠道、要判断的总体和准备行动；缺口问：“你说的变多，具体是在哪些地方、跟哪个时期相比？”

## 转换动作
1. 画一条简短时间线，标首次关注、搜索、关注账号和推荐设置的变化。清晰起点只生成注意力改变这个候选解释，不是偏差确诊，四十八小时也不是界线。
2. 拆出三个不同的量：总体发生数量、进入个人信息流的数量、自己注意到的数量。同一条内容多平台转载要去重；算法增加曝光是真实变化，但不能推出全社会需求增加。
3. 为“外界增长”“渠道改变”“注意增强”各找能区分它们的记录。优先固定地点、相同时间窗与定义的前后比较；无历史记录时建立后续观测，不让未登录搜索或朋友印象冒充完整总体。
4. 将证据强度接回行动：只有个人曝光时可建议小规模验证；多个独立且可比指标支持增长，再讨论扩张。若外界与注意同时变化，两者并存，不强选单一解释。

## 最小成果与停点
交付三层数量的已知与未知、竞争解释、核验方法及行动条件。明确“看得多”究竟支持哪一层，就完成本轮；未拿到总体数据时保留趋势未知，不编增长率。新出现可比历史资料或渠道规则改变时更新结论。

## 工具箱接口
核验计划可交调查或小试工具；真实增长确认后才交容量和执行工具。若要估的是一类事故的风险而非增长趋势，可转基础比率校准，避免把两种问题混在一起。
