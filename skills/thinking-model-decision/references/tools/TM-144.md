# TM-144 · 情绪ABC

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
一次失误被扩大成“我整个人都不行”，僵化要求或“完全承受不了”的判断开始阻碍行动，或因仍然难受再次责备自己时，帮助用户检查具体评价。与WW-2.9认知解耦共享事实/解释分离；本工具进一步查评价与要求，不重复执行整套流程。出现难过不自动意味着需要改信念，不把所有情绪归因于B，不作心理诊断。

## 最小输入与追问
一个具体片段、已知与猜测、感受及动作、最重的评价；同时留意现实影响、责任与期限。已有信息直接用，只问下一步最重要的缺口，例如“发生哪件具体的事，让你觉得整个人都不行？”或“假如这次确实没做好，你由此给自己下了什么结论？”不一次要求填写ABCDE；用户没表达的信念保留待确认，不替其承认。

## 转换与分支
**现实处理优先。** 有危险、现实损害、必须履行的约定或迫近期限，先安排可行保护、补救和必要回应；不等分析完或情绪下降才做。只有用户愿意，才帮助梳理其判断；不替别人判“不理性”。这是一种日常反思，不是治疗。

1. **定位触发点与证据状态。** 区分已经发生、记忆中、设想的情境；记忆细节也需按证据状态标记。把听到/看到的内容与未核实推断分列，不把猜测改写成事实，也不用乐观猜测填空。原文“观察—推断—评价”图只作整理提示，不称REBT标准B三层。
2. **记录反应，找到关键评价。** 允许难过存在，分开感受、已经做的动作、想做的动作及影响。由用户确认最困住自己的评价或要求。僵化要求、灾难化、低挫折容忍、整体贬低只作核查方向，不凑四类；“必须”可能是必要条件或合理职责，不能机械删去。
3. **查依据、推理与行动影响。** 对关键句分别检查已知/未知、结论是否能从前提推出、它如何影响下一步。即使某项失误或他人的不满属实，也不自动推出整个人没有价值；但不强迫用户想象更坏情境。不因一种想法让人舒服或有用就判为真实。若感受有现实理由且无明显不当判断，保留感受，直接处理问题。
4. **形成能认同的新说法与现实回应。** 给符合证据、保留标准和责任的候选，让用户修改或拒绝，如“这次有具体错误，需要补正；它不能概括我整个人”。未接受就标待确认。选一个现实动作，明确执行者、时点、条件和完成证据；必要时查事实、补救、履约、求助或休息，不要求先开心再做。

## 最小成果与验收
交付“具体事件的评价核查与现实回应”：触发点及状态、待查推断、感受/动作、关键评价、核查理由、接受或待确认的新说法、现实一步及复查信号。说清哪个推理跨越改变了选择，或为什么当前应保留合理感受而直接处理现实问题；信息不足交付核实动作，不造完整结论。复查分别记录动作拟定/尝试/完成、实际问题、回避变化与情绪状态，不能以说出新句子或暂时轻松认定问题解决。

## 停止、边界与交接
一轮核查不再产生新信息、越分析越像自我审问、用户不愿继续，或迫近期限需要行动时，停止展开。若又出现“学了就必须马上调整好”，先放下这项额外考核并允许暂停；不以仍难受为由追加审问。持续困扰明显影响睡眠或工作生活，可建议专业支持；现实危险先保护。不要把真实能力、资源或安全限制统统说成“你能忍”。

失误需要改进，不等于整个人被否定；真实伤害需保护和处理责任，不能让受害者改想法替别人免责。帮助他人需其意愿，不用ABC施压、诊断或要求危险对质。行动与结果边界不清交TM-141；权限、承诺或伤害责任混杂交TM-142；冲动回应需留空间时可交WW-2.9，但不以情绪降低作为必要行动的条件；已经观察到反复检查情绪干扰行动时才考虑WW-9.4。仅按实际缺口交接，不固定串联所有近邻。
