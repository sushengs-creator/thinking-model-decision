# TM-110 · 图尔敏论证模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
拿出数据仍无法解释为什么应采取某行动，或理由强度与结论不匹配时使用。六个维度检查论证连接，不自动核验事实；需要选最佳方案时还得比较替代及必要标准。

## 最小输入与追问
明确主张、根据及来源、实际连接规则、规则支持、适用条件和可能例外。关键追问：“这些事实为什么能支持这项建议？”替提出者重建的隐含理由先标推测，等待其确认。

## 转换与分支
1. 固定主张对象和强度，核对根据。将“事实是什么”与“因此要怎样”拆开，资料只支持候选时不写成必选。
2. 提取担保，即证据到主张的连接规则，再查它由什么经验或记录支持。同样事实可能对应不同担保；增加同类名单不能填补需求不可比的缺口。
3. 找最重要的失效条件，区分已知反证和待查可能。分别定位质疑针对根据、规则还是当前适配；推翻一条支持只削弱对应链条，未必否定最终结论。
4. 按缺口收缩结论或安排有区分力的补证，给出更新节点。已有充分依据时不机械填满六格；仅想象无穷例外会拖延，优先处理可能改变行动的部分。

## 最小成果与验收
交付主张—根据—担保链、支持、限定与关键反驳，连同补证行动。结论强度与现有证据一致，每个缺口能说明需要哪类新材料；结构齐全和对方被说服都不算证实。

## 停止与工具箱接口
证据核验受阻时保留条件建议，不填假材料或概率。缺口是竞争原因可交溯因推理，取证成本可交信息价值，多个可靠候选交取舍工具。论证通过不意味着已经获授权、执行或实现效果。
