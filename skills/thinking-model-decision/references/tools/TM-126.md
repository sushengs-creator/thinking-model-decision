# TM-126 · 具身认知

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
照步骤做过却换条件拿不准，需检查动作与感觉是否帮助理解关系时使用。具身经验可以参与思考，不保证动手胜于听讲，更不要求所有人完成同一身体动作。

## 最小输入与追问
一个具体步骤、目标效果、实际操作与反馈、已用工具提示、变化条件和卡点。关键追问：“这个动作让你看到或感到什么变化，你据此怎样调整？”只会说手怎么动，还需核对与结果的联系。

## 转换与分支
1. 将步骤写成“动作→感受或可见变化→所提示的关系→下一步判断”，与可靠说明或示范对照。感觉是待校准依据，不能直接当正确结论。
2. 根据缺口选安排：不懂作用先补讲解，再操作核对；只缺新条件知识就补知识；动作与关系无关或负担过重则改用图示、观察、手势或简化任务。已懂会用不额外加动作仪式。
3. 在可承担环境只改一个关键条件，先预测或判断，再操作与结果比较。保留正常工具、无障碍支持和规范，减少的是逐步答案提示；陌生条件太多就缩小变化。
4. 跨回合结合判断依据、变式和延后表现检查。稳定手感即使暂不能完整言说也有价值，但应验证范围；新证据支持知识或负荷缺口时改学习安排。

## 最小成果与验收
交付动作反馈关系、最小练习、可观察结果与改用其他表征的条件。验收看目标关系在新条件下能否用于有效判断和操作，填表、做过一次和动作多都不等于理解。

## 停止与工具箱接口
无必要感官信息或超出可承担操作范围时停止自行试错；不能凭手感替代专业标准。辨别状态交默会知识，负担交认知负荷，跨任务适配交迁移；不把做不到指定动作解释成能力不足。
