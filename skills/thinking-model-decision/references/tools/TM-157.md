# TM-157 · 马尔科夫链

状态：v2运行文件；来源与实际试跑范围以tool-index.json为准。

## 触发与最少输入

需要解释总量变化或稳定背后的人员流动，预测同一批对象逐期处于哪些状态，比较留存/回流等概率变化在不同期限下的结果。至少需要对象边界、互斥且完整的状态、时间步、起始分布、转移人数或概率及依据、目标期限和指标；比较干预再加效果维持时间、成本与硬约束。先问影响最大的一项：“两期记录能对上同一批对象吗，还是有人新增、退出或没记录？”

## 转移表如何变成判断

**先定研究范围。** 固定队列使用完整名单，计入两期都未出现的人；新入、注销、失访及定义变动另记，不混成原有对象的转移。开放系统先明确进出规则，或缩到可比较队列。只有汇总人数或两份活跃名单不能自动推得全部条件概率。

**从计数估表。** 对齐相邻时间步，行是现在、列是下一步；每格人数除以该出发状态人数，核对行和1与人数守恒。某行无人只能记未知，不能填0；某格观察到0不证明事件不可能。概率来源、期间和分层样本量并列，不能用全部注册人数代替同行分母。

**核两个不同假设。** 当前状态是否已包含影响下一步的历史信息，检查同状态内停用时长/使用频次等分层；转移表是否可跨期沿用，检查各周、活动和环境。分层差异须结合样本量及不确定性，不以一两周数据宣称已验证马尔科夫性质或长期稳定。历史仍有预测力就考虑扩大状态，规则随期变就用逐期表；不能用一句“只看现在”丢掉有用信息。

**先推任务需要的有限期。** 行向量递推 `n_(t+1)=n_t P_t`；只有固定表才用 `P^t`。各方案从同一初态出发，各自更新人数；一周改善只用于那一步，后面恢复对应表。两状态可用 `下一期活跃 = 本期活跃×留存 + 本期不活跃×回流`。报告期望值与实际波动的区别。按用户的期限区分末期人数、累计人周、去重人数；累计量是否包含起始期须说清，不能把人周当独立人数。

**长期只作有条件补充。** `πP=π` 是平稳条件，不是任意初态收敛证明。有限固定表的不可约和非周期是常用充分条件；不满足时检查可达闭类、吸收或周期，不能一概判定无分析价值。两状态平稳活跃比例 `q/(1-r+q)` 要求分母非零；r=1、q=0时保持初态，r=0、q=1时一般会交替，不能把50%平稳比例当每期都会趋近的承诺。多状态不用两状态公式。对象数量或环境长期变化时，旧平稳比例不能当未来平台规模。

**回到可执行比较。** 同口径对比基线和各情景的有限期增量，再列全周期费用、执行时间及约束；有可信单位价值才折算金额，不自行编收益。概率变了会怎样是条件预测，某措施能否造成这种变化是另一个证据问题。稳定总量也可能由人员轮换维持，轮换本身既不证明无风险，也不证明必然崩塌。选择逐期核对、补齐名册或可负担的验证行动，明确负责人/确认状态、时点、重估条件；未知时给补数次序和条件分支，不编造精确最优方案。

## 最小成果、停止与交接

交付状态/队列说明、初态、转移计数与概率（含未知项）、假设与证据界限、指定期间的基线和方案表、成本与推荐依据、下一步及更新触发。关键行或队列口径不明时暂停精确外推，不妨碍先修数据；数据充分且已支持当前决定时停止追加复杂状态和无限期计算。每期把实际与预测对照，持续偏离、活动结束、样本结构或口径变化时重估；单次偏离不自动证明失效。

状态颗粒度与干预机制可接WW-3.3，行动测量闭环可接WW-8.4，归因可接TM-056，策略适应可接TM-092，阶段承诺可接TM-156。若须按状态优化动作和回报，需另建决策过程；本工具不以描述性转移表冒充最优控制。结果回到主流程综合方案与HTML报告。
