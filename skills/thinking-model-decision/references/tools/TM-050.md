# TM-050 · 让多个解释接受同一批证据的交叉检查

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
异常有数个说得通的原因，各方各拿一套材料支持自己时用。已定位且复现充分的简单问题不必凑假设；矩阵只是审查结构，不自动计算真相。输入中性异常、时间口径、候选解释、共同证据与观测覆盖；关键追问：“如果这些解释分别成立，哪一种可观察现象会不同？”

## 转换动作
1. 用指标与时间描述异常，合并同义解释，保留强替代、测量变化和必要的多因素分支。为各假设写不同预测；没有任何独特预测的万能解释不能凭冲突少胜出。
2. 建共同证据池，先标可靠性、来源依赖与区分力。十份转述同一来源只算同源材料；所有假设下都容易出现的现象，不能被某一方独占为支持。
3. 每条证据横向放进各假设，标相容、冲突或未知并简述依据。未看到的迹象只有本应能检测且观测足够时才有反证力量；缺覆盖就留未知，不把空格当否定。
4. 比较关键冲突、整体解释力和额外假设负担，不数正负票。删除或替换最关键证据检查结论是否翻转，再选最能区分存活解释、又可取得的一条信息作为下一调查。

## 最小成果与停点
交付小型矩阵、证据依赖、暂时最强解释、存活分支和重开条件。能说明当前结论依赖什么及下一证据价值，即完成本轮；不编精确概率，相容不等于因果成立。修复一处后异常仍在，要重开剩余原因，不能宣布所有问题解决。

## 工具箱接口
区分性预测交可证伪或试验工具，已支持的机制交选项与执行工具。假设可共同作用时保留组合，不强迫互斥；资料无法取得时输出条件化方案而非假装得出唯一答案。
