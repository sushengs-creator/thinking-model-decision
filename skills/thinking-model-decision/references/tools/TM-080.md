# TM-080 · 非遍历性

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
反复承担项目或投入资源，年终平均回报不错却担心中途耗尽时用。一次性、不复合的选择不能直接套，生存边界是另需检查的约束，不是非遍历性的定义。需要每期资源变化、支出时点、相关风险、期限及最低储备；路径不清时问：“这一轮的结果会怎样改变你下一轮还能投入的资源或参与资格？”

## 转换动作
1. 画资源递推：期初有什么，本期结果怎样改变下期起点，是否按比例复合或产生持续义务。加法与乘法过程分开；资料不足保留情景，不随意补每期概率。
2. 并列集合平均、典型路径和可信不利连续路径。平均可能由少数极好路径抬高，不能自动当成一个人的长期增长；对数增长可帮助描述某些乘法过程，但不是所有人的唯一目标，也不能因有波动就宣判非遍历。
3. 按真实到期支出逐期检查最低现金、时间、恢复精力或继续资格。区分数学吸收壁、制度强制退出和个人可逆退出；有限轮仍为正的资源不能夸称必然归零，实际门槛要单独明确。
4. 比较降低单次暴露、分散不同风险源、保留缓冲和转移不可承受损失的组合。多项同源风险并不是真分散；写继续、缩减与退出条件，不能照搬示例投入比例，也不能用“长期会好”拒绝更新已失效逻辑。

## 最小成果与停止
交付资源递推表、退出边界、压力情景及可承受的参与方式。已找到可能中断路径的节点并有对应安排即完成；只有一次选择且状态不延续时改用普通结果比较。回款、支出、风险相关性或最低储备改变时重算。

## 工具箱接口
要把路径薄弱处变成余量交安全边际；要比较是否值得参与交期望值或多维取舍；要决定分阶段承诺交期权与停止规则。路径安排建议、被接受的承诺、实际资源变化和长期效果分开记录，幸存不能单独证明机会有价值。
