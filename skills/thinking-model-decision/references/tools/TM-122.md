# TM-122 · 自我决定理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
参与依赖催促、排名或内疚，需判断改激励还是补支持时使用。分类的是行动理由，不给人格排级；认可任务价值也可自主，不必变成有趣，自主也不等于独立或取消标准。

## 最小输入与追问
本人认可的理由、压力来源、具体困难、原兴趣、任务要求资源、能力与质量基线。关键追问：“这件事哪些部分你认可，哪些主要靠压力维持？”理由可混合，口头回答结合现实安排看。

## 转换与分支
1. 区分看不到作用、觉得做不到、主要受奖惩或自我施压驱动、认可价值或享受过程；不把无人催促当自主，也不由能说用途判定已内化。
2. 检查真实选择与认可、能获得的进展和反馈、求助后的待遇。暂时缺帮助就补支持；被羞辱或排斥还须处理行为本身与责任，不能只增加答疑渠道。
3. 选择一个可实施改变：补样例和练习、明确标准、调整控制性排名或协商任务。奖励检查挂钩对象和本人体验；已有合理薪酬不能因理论直接取消，选择也不能全是本人不接受的选项。
4. 用难度与条件可比的任务、同一质量标准复查，分别记录动机理由、参与行为、实际能力、成本压力。多项同时改变只能评估整体安排，不能隔离各项因果。

## 最小成果与验收
交付支持与阻碍图、一项具体改动、四类观察及重议条件。愿意但不会先补技能，能做但压力主导再查控制与价值，负担增加则减量；错误率未变只说明未观察到准确性改善。

## 停止与工具箱接口
任务确与本人目标冲突可重新协商，不强求认同。技能缺口交学习工具，开口遭惩罚交团队心理安全，收益与代价选择交期望价值；不把持续参与或同意安排当动机改善证明。
