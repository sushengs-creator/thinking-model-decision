# TM-063 · 期权思维

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
大投入难撤回、以后会有关键新信息，又可能用有限成本保住入口时用。普通试点只制造信息，未必拥有扩大或退出的权利；随时可撤回的小事也无需额外买期权。需要难回头节点、保留什么机会、费用、到期日及后续资源；缺权利信息时问：“第一阶段结束后，你实际能选择继续、扩大或退出中的哪些路径？”

## 转换动作
1. 标出不可逆承诺之前的分段点，并列立即投入、不投与保留权利的真实方案。核实锁住的是价格、位置、资源还是访问资格，权利是否可执行；人人随时能拿到的机会不能包装成付费稀缺入口。
2. 设计能获取关键事实且损失可承受的首期投入，算等待、维护、沟通和后续切换成本。明确新信息何时到来、到来时机会还在不在；不确定性越大并不自动越值得等。
3. 事前写不同信息下扩大、缩小、切换和退出的条件，核实谁能做决定、谁能调动后续资源。失败停不下来或成功加不上去，都应降低对期权价值的判断；条款暗含强制继续时重新设计。
4. 到期比较现在行权、继续保留和放弃的未来价值。信息已成熟就承诺，窗口将丧失则计入等待损失，不能用反复延长试点逃避选择。

## 最小成果与停止
交付机会、实际权利、首期上限、期限、关键事实、行权与退出条件、可用资源卡。权利真实且条件可执行即完成；投入不可分、关键反馈只能在全部承诺后出现时停用，改整体取舍。保留权利的建议、实际取得权利与日后行权分别记录。

## 工具箱接口
关键事实是否值得获取交信息价值；如何取得证据交调查或最小验证工具；总投入与失败后承受能力交安全边际。长期信任若依赖稳定承诺，应把灵活性代价交关系和参与者工具，不把随时退出当普遍最优。
