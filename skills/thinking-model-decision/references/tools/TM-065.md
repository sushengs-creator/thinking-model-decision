# TM-065 · 边际成本

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
要多接一单、再投一批或延长一段时间，争论却只看历史总成绩和平均成本时用。技术复制便宜不等于全部服务便宜，增量也不总是一个人或一件产品。需要当前基线、真实可行的下一步、期限、收益成本与容量；增量模糊时问：“你眼前真正要增加或减少的那一笔承诺具体是什么？”

## 转换动作
1. 固定“不做这一步”的基线，判断动作是否可分；必须整套购买或持续绑定的，把整个承诺视为一单位。成本时间覆盖准备、协调、实施、售后和复查，不只计眼前付款。
2. 列这一步带来的新增收入、能力、信息及全部新增代价，剔除无论如何都不变的旧支出。核查挤走更高价值任务、服务压力、长期价格预期和风险，无法统一单位的影响单列。
3. 查容量阈值与批次差异：多一个看似便宜的用户是否触发扩容，下一批是否比前一批更难获得。可算时以新增收益减完整新增成本；再与最佳可行替代比较，机会成本已扣不再扣第二次。
4. 给下一步量与复核节点。接近零或排序敏感时偏向可调整安排；短期亏损若以学习为理由，必须说明信息会改变哪项行动。不能仅靠“以后变好”无期限加码，也不把可逆小试强加给不可拆决定。

## 最小成果与停止
交付增量及基线、完整收支、阈值、替代比较和下一步建议。最影响排序的漏项已处理即可结束；容量、价格或绑定条件变化时重算。新增净值与总项目长期可持续性分开，短期低于平均成本可行不代表永久定价可忽略固定成本。

## 工具箱接口
未来替代用途交机会成本；拿旧投入辩护交沉没成本；学习回报难判断交信息价值。已选增量交执行与停止规则，分别记录建议量、批准量、实际投入和得到的结果。
