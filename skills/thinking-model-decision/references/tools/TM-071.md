# TM-071 · 测量模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
看到评分、工时、停留等数字，准备据此评价质量、忠诚或贡献时用。稳定测出同一数值不等于测对目标，更多数据也不能修复测错对象。需要本次决定、真正目标、指标定义、测量过程及样本；目标含混时问：“如果这个数字不展示，你最想确认实际发生了什么变化？”

## 转换动作
1. 把目标和指标分栏，说明指标是目标的一部分、目标带来的表现，还是间接代理。写出从目标到数字的推断依据；“容易拿到”不能作为代表资格。
2. 列目标不变也能推动数字的因素，包括人群、规则、激励、测量方式及情境。反查重要维度是否被漏掉，例如响应快是否遗漏问题解决；同样分数跨时期、人群比较前检查含义与口径。
3. 收集不同来源的支持：覆盖目标关键部分的证据、换一种方法的交叉证据，以及目标变化理论上应伴随的外部结果。几项指标共享同一偏差不能算独立验证；观察矛盾时先解释分歧，不用平均分抹平。
4. 按现有证据限定数字用途：足以作为追问线索、可参与比较，还是足以承担重要资源决定的一部分。缺证据就降低权重并提出最有区分力的补测，不从“不能量化”跳回无约束直觉。

## 最小成果与停止
交付“目标—指标关系—支持依据—污染因素”表，附能与不能支持的结论。当前用途的解释链已可检验、主要缺口已列即完成；目标或测量机制变化时重新审查。指标上升、解释获得支持、改进建议被采用及真实结果改善分别记录。

## 工具箱接口
指标成为奖励目标后关系失真，交古德哈特；争议只是抽样波动，交统计精度工具；要证明行动造成目标改善，交反事实因果。补测成本较大时把具体解释分歧交信息价值，不为“数据全面”无限加指标。
