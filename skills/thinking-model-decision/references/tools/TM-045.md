# TM-045 · 为坚持的目标保留修改方法的证据入口

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
方法与忠诚绑定，成功失败都被解释成方向正确，反例逐渐失去作用时用。此处是封闭判断的综合检查，不是单一心理诊断；价值与原则不能当普通经验假设来推翻。输入坚持的价值、方法、事实主张、原期限和标准；关键追问：“你想维护的目标是什么，当前做法又依据什么被认为能实现它？”

## 转换动作
1. 分开价值、现实事实、实现方法与未来预测。可以坚定重视成长，同时检验某种管理方式是否有效；质疑方法不自动否定目标，也不把不同意见者贴成被洗脑。
2. 在下一轮结果出现前写观察对象、时间窗、支持与削弱信号及暂停线，说明辅助条件。不给没有依据的指标编数字；先约定怎样区分执行没完成与完成后仍无效果。
3. 用同样标准审查正反材料，复述最强替代观点与自己的薄弱假设。设置真实可用的质疑渠道；若发问仍受惩罚，不能仅靠要求个人开放来解决。
4. 到期对照原记录，查成功标准、观察窗口或重要指标是否被事后移动。新信息可以支持修改规则，但要说明理由并形成下一条可检验预测；一次反例也不必抛弃所有复杂理论。

## 最小成果与停点
交付可修改的方法假设：价值保留什么、方法可改什么、由谁核查、何时暂停。事实与方法重新承担被现实削弱的可能，即完成；不以用户放弃价值或变中立验收。若分歧主要是合法的价值优先级，退出证伪，转取舍协商。

## 工具箱接口
具体预测交可证伪与试验工具，证据审查共享已有表，组织表达成本交参与者工具。只在确有封闭链条时使用全套，不因出现绝对词就判定需要信念改造。
