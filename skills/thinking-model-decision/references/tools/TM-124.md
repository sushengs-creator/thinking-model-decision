# TM-124 · 多臂老虎机模型

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
选项能反复选择，选择既带回报又提供后续有用信息，需要分配机会时使用。一次性重大选择不能轮番试用；临时领先的样本成功率不等于真正最优。

## 最小输入与追问
可重复候选、真实回报与确认时间、剩余机会预算、损失约束、版本和人群记录。关键追问：“新结果回来时，还剩哪些来得及改变的选择？”检查实际反馈窗口，不仅用平均延迟。

## 转换与分支
1. 固定回报口径，分开成功、失败和待确认；点击、报名、实际收益不能互代。列事前预算与损失约束，并使分配规则本身守住边界，不等损失后再叫停。
2. 核查可比性与反馈时效。版本、人群或环境不同需分层或扩展模型；本轮结束前无反馈时改为临时批量安排，新数据用于将来，不能许诺活动内动态优化。
3. 按信息、成本和剩余机会选择分配规则，明确更新时点、并列处理和结束探索条件。采用具体算法须有参数依据和适用条件；数据不足先给记录方案，不默认固定探索比例或编概率。
4. 只据已确认反馈更新，记录当时依据、选择、成本与结果；随机策略留足抽样信息。复盘包含探索损失和后续收益，比较需可比条件，不能只展示胜出项好成绩。

## 最小成果与验收
交付候选、回报、剩余预算、反馈窗口、下一轮规则及停止重估条件。执行者能据此选下一项，未知明确保留；只剩一次且仅求即时回报时，按当前有据预期选可行项，不额外探索。

## 停止与工具箱接口
行动改变未来状态、库存耗尽或反馈失效时停止套基础算法。延迟及环境变化交动态系统工具，是否值得取证交信息价值，不可重复选择交取舍与可逆决策；学习回报不得掩盖当期实际损失。
