# TM-135 · 编码特异性原则

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
学过却提取不出、提示不同表现改变，需调整线索或学习关联时使用。当时怎样编码会约束有效线索；一般关联强不保证贴合本次学习，提示多也不等于区分力强。

## 最小输入与追问
要找回的内容、实际学习笔记或回忆、当前问题线索、答案暴露、间隔及目标是否允许查阅。关键追问：“当时你把这项内容和哪个具体问题或例子联系在一起？”没有记录不编编码关系。

## 转换与分支
1. 区分当下查回名称与未来独立选用。允许查资料即可先查证，不为证明记忆强加闭卷；需要独立掌握再另安排练习。留下现有表现，不以空白判没学或全忘。
2. 从原例、笔记或关联挑一条有依据且不泄露答案的线索，过宽就具体化，记录提示原话和暴露顺序。别人说答案后的重复不能算自主提取，也不机械还原座位场地。
3. 用可靠材料核对回忆的正确、遗漏和错误。提示无效时查编码不足、理解混淆、疲劳和任务变化，必要时补学，停止无限堆提示；成功也不证明完整记忆或可独立应用。
4. 将未来实际会收到的需求、故障或题目与知识意义和适用条件重新关联，用未泄答案的新问题及适当间隔检查。分别记录独立、借线索、查阅完成；只原例能唤起时补新关联，选错方法则补理解。

## 最小成果与验收
交付目标辅助条件、当前表现、待试线索依据、答案参照、补学内容和下次检查。验收针对实际目标，熟悉、再认、辅助回忆、独立回答、正确使用分别记录，不编记忆完整度或匹配概率。

## 停止与工具箱接口
重要事实优先查独立记录，不用诱导提示证明争议经历。知识关系错交图式或概念转变，长期保持交可取的困难，目标情境关联交迁移；一次辅助成功不能确定因果或长期效果。
