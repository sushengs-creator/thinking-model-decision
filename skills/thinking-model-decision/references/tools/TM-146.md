# TM-146 · 心理灵活性

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻

当“先不紧张、先有把握、状态好了再做”长期挡住本人仍重视且现实允许的事情，或想分清准备、恢复与回避时用。未知价值、现实约束或健康问题未排清，不能先定性心理僵化。需要检查具体评价是否成立时交TM-144；需要核实资源、期限和依赖时交WW-1.4。

## 最小输入与关键问题

一件具体的事；已知条件和期限；本人是否仍愿意做；出现的念头/感受；通常怎么应对以及作用。已有材料直接使用，只补最影响下一步的一点：“这次准备具体补了什么，补到什么程度就能开始？”现实困难与情绪阻力可并存，不逼用户二选一，不让其先学六过程术语。

## 运行转换

先看是否有须立即处理的危险、现实伤害或必要责任。此时先安排相应保护、求助或履约，不能等情绪下降、练习完成或原因查明。火警比喻不是安全行动指南。

把一个真实片段转成短链：**情境/条件 → 念头与感受 → 实际应对 → 短期作用 → 长期代价**。分开观察与猜测，不把一次休息标为回避。问应对是否仍有帮助，是否一直在等待一种无法保证到来的心情。

若出现“只有感觉好了才有资格开始”的规则，邀请本人观察这条规则，而非要求证明它愚蠢或消灭感受。可以自愿试一句“我注意到自己正在担心……”，但这句话没有让人平静也不构成失败，不转成新的行动门槛。

回到本人方向和条件，形成一项选择：

- 继续：本人仍重视，条件允许，成本可承受；带着尚存感受做具体动作。
- 调整：方向还在，方式、规模或时点需要改变。
- 暂缓：现实条件、休息或更急责任优先；如有用，约定重看条件。
- 求助：缺必要信息、技能、支持或需要专业评估。
- 退出：不再愿意、环境不合适或代价不值得。

五项无勇敢高低之分，害怕也不使退出理由失效。明确一个动作及时间/触发点、总资源、完成标志和改变判断的信号。没有确认价值时只给可供选择的分支，不代用户承诺。

## 最小成果、完成与反馈

输出“当前循环—隐含前提—本人方向—现实条件—所选动作—复查信号”的短卡或等价文字；说明改变的是哪条行为规则，而非只介绍ACT。按实际执行、代价与新信息复查，不把报名等同参加、完成等同效果，或把仍紧张当成失败。

用户不愿继续、反复练习成为自我考核、没有新增信息或现实期限要求行动时停止。未行动先查困难、规模和支持，允许调整或退出，不加码心理训练。完成分析后将成果接回主流程的解决思路与HTML实施方案。

## 边界与交接

接纳内在体验不等于接受外部伤害；不要求用户顺从、容忍危险或放弃责任。此为日常反思工具，不诊断、不提供完整治疗或疗效承诺；持续明显影响生活的困扰可转专业支持。文章研究考察特定App，不能证明本练习有效；六过程不做人格打分，认知解离也不是临床解离症状。

WW-2.9可补替代视角，但不把情绪下降作为先决条件；WW-1.4核查真约束；TM-144检查评价的证据/逻辑。只在当前缺口需要时调用，不重复套用。
