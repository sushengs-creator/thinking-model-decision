# TM-073 · 参考类预测法

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
计划写得很细却总延期，或把希望达到的数字当最可能结果时用。内部计划负责组织行动，历史分布用于校准预测；参考类不是挑一个成功榜样。需要指标、起止点、同类计划和实际记录、失败未完项及当前差异；缺可比案例时问：“之前哪些事情在任务规模和协作条件上最接近这次，最后各用了多久或得到什么结果？”

## 转换动作
1. 固定预测变量与口径，按任务、规模、成熟度、资源和依赖选择同类，记纳入排除理由。不同失败机制不因名称相同而合并；保留延期、停止与未完状态，未完不能被悄悄删成已完成分布。
2. 查看中间位置、范围、尾部和失败，而非只有平均值。小样本提供方向和粗区间，不把几例频数当精确未来概率；历史最坏不是未来上限。不同资料冲突就报告可比性分歧。
3. 将本次先放到普通同类的位置，再逐项用已验证差异调整。资源到位、复用成果可作为证据，“更努力”不足以加分；已纳入参考类的优势不重复调整。准备、沟通、审批和复查必须进入工期口径。
4. 分列目标、基准预测与对外承诺，按失约损失配置缓冲。成本和工期各自达到某分位，不代表同时满足也有同样概率；联合风险另查。没有可靠历史时保留区间与依赖，不移植别处的上调百分比。

## 最小成果与停止
交付参考类及局限、完整结果基线、调整证据、预测区间及承诺条件。已经足以修正不可靠承诺即可结束，不必追求精确到天。关键机制改变时重选同类；发现选择性报喜要核查资料与激励，不能只靠统计修补。预测建议、承诺确认和实际交付分别记录。

## 工具箱接口
承诺需要资源余量时交安全边际；需把范围拆成可行步骤时交执行工具；资料疑点会影响当前决定时交信息价值。历史可约束预期，不能规定用户只能追求平均结果。
