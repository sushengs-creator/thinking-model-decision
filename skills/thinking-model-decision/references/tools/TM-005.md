# TM-005 · 从独立依据重建数值范围与底线

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
报价、工期或评分围着最先出现的数字小幅挪动，却没有独立依据时用。真实开放时段、已测容量和硬性成本虽先出现，仍可能是有效约束；识别锚不等于删除所有数字。输入初始数及来源、估计对象、已有记录与决策期限；关键追问：“如果不沿用这个数，你手上有哪些可比记录或可拆算的部分？”

## 转换动作
1. 给初始数分类：实测值、外部限制、策略报价或随口估计。注明哪些部分确实约束行动，哪些只是让讨论有了起点，避免把谈判对手开价当成本证明。
2. 从另一条证据路线独立建范围：按工作包估时，或找相同规格的已完成案例。列出差异调整及缺口；资料不足就给条件区间，不能任造一个相反数字与锚对冲。
3. 对已见锚做去标签检查：“只看当前价格和用途，还愿意选吗？”同时寻找真实的上、下界依据。若新数字仍只是旧数打折或加成，返回独立拆算。
4. 把估值范围与个人可承受底线分开。超过底线可缩范围、换方案或暂缓；新增服务、规格或时间约束出现时按其实际影响重算，不因改口尴尬而守着原数。

## 最小成果与停点
交付锚点来源、独立计算、差异理由及可行动边界。关键条件可解释且结果不只来自围绕锚调整，即完成；不保证完全消除影响。若问题根本是偏好选择，停止数值纠偏；数据无法支撑精确估计时保留范围和待补项。

## 工具箱接口
独立范围可交给排期或谈判工具；有多项非数值取舍时交多标准比较。必要时用参考案例补外部基线，不把另一个未经核实的平均数奉为新锚。
