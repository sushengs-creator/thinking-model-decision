# TM-014 · 把专属评价拆成可检验的具体描述

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
笼统描述因冠以专属测试、身份或权威标签而显得精准，并将影响选择时用。共鸣可以有情感价值，具体可验证反馈也可能可靠；本工具不嘲笑个人兴趣。输入逐句评价、报告如何生成、拟影响的决定；缺口问：“其中哪一句最让你想据此改变行动？”

## 转换动作
1. 暂时去掉名字、类型和“为你生成”等标识，把关键句放到不同的人身上试读。广泛适用只是警示，不能单凭换名还成立就判定测评无效。
2. 将句子改成带场景、时间和行为的陈述，分别找符合与不符合的经历。“有时外向有时内向”若无法说明何时、相比谁、怎样观察，保留为谈话线索，不升级成能力结论。
3. 追问方法依据：输入用了什么、怎样形成判断、参照对象是谁、能否预测未参与生成的行为。专业名词、数据量和常模字样都不自动证明有效；没有可追溯方法就明确证据缺口。
4. 对拟定决定逐项检查相关性。比如是否适合组织活动，需要实际协调和交付表现；可建议一个小任务获取反馈，不能由悦耳赞语推出转向或长期承诺。

## 最小成果与停点
交付“原描述—具体性—区分力—证据—可用于何种决定”的清单。关键句已被具体化或降为未验证线索，即完成；不要求用户否定所有报告。出现独立、可重复的行为证据时更新评价；若本来只是娱乐，停止过度审核。

## 工具箱接口
具体行为缺口可交任务试验或反馈工具；价值偏好可交澄清工具。对笼统标签不再继续做人格推断，也不把这种机制用于制作让别人误以为被精准了解的话术。
