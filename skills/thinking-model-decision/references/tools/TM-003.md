# TM-003 · 把整体印象拆成有独立依据的评价

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
因名气、外貌、品牌或一次成败，把好坏印象复制到多种能力时用。日常亲近感与审美偏好无需强拆评分；真实相关的能力也不能仅因一起得高评价就判为光环。输入待评价任务、必需能力、已见行为与最初印象；缺信息问：“这个决定最需要对方做好哪一件具体的事？”

## 转换动作
1. 先按任务拆出少数必要维度，再看人名和总评。例如带活动要区分内容准备、现场协调与后续交付，不能用“很优秀”覆盖三项，也不为凑完整而强造分值。
2. 每一维只放能直接支持它的行为、作品或记录。同一业绩若被反复用来证明沟通、领导力和诚信，逐项问它究竟观察到了什么；不能推出的留作未知。
3. 条件允许时隐去身份或最终结果，先评作品与过程，再恢复背景。做一次结果反转检查：假如同样过程最后没成功，自己是否会立刻改说它混乱？这提示需独立取证，不证明过程一定优良。
4. 用明确的任务要求汇总维度；关键能力未知时补对应演练或记录，而非继续搜名气。新证据只更新它实际覆盖的维度。

## 最小成果与停点
产物为“任务维度—独立证据—未知—影响决定的程度”表与一项补证动作。完成以重要维度有证据或被明确标未知为准，不以总分漂亮或团队同意为准。若主要争议变成任务要求不同，停止评人，先对齐要求；真实违规或损害不能用滤镜概念淡化。

## 工具箱接口
已拆开的维度可交给多标准取舍工具；某项原因仍来自成功后的倒推时，可交因果解释工具。无需为每个人追加一整套人格诊断。
