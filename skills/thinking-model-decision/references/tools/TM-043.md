# TM-043 · 用同一把尺子评估支持与反对材料

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
同样质量的材料支持己方就宽容，反对己方就提高门槛时用。拥有立场不证明结论错误，反方也不天然更客观；这里检查评价标准，不能用标签代替回应证据。输入事实主张、双方材料、原可靠性规则与利益投入；关键追问：“同一条材料如果支持另一方案，你会怎样评价它？”

## 转换动作
1. 分列希望什么成立与实际可检验命题，注明自己的倾向。若核心是价值取舍，先保留价值，不把喜欢或原则伪装成能由一条数据决定的事实。
2. 在看材料支持谁之前，写来源、样本覆盖、逻辑链和重要反例的检查规则。可行时隐作者和支持方向；样本充分与否需对应具体推断，不凭空规定通用人数门槛。
3. 将正反材料放同表逐项审查，并做换边检验。记录因方向变化而改变的评价，再按原规则纠正；证据质量确有不同就应有不同权重，不凑相等条数或五五开。
4. 重点查己方最弱假设，准确复述反方最强理由，并据材料保留、缩小或修改选择。没有概率依据时用条件与缺口表达，不能把纠偏动作包装为客观正确的保证。

## 最小成果与停点
交付对称证据表、换边后发现的差异、纠正方式及决定有无改变。相同材料接受相同审查，主要分歧能追到证据或价值，即完成；不以必须改口验收。遇到新资料质量差异时正常调整，不能因担心偏误而放弃必要筛选。

## 工具箱接口
材料真伪交证据核验，明确的候选交取舍工具，关键缺口交试验设计。若根本没搜反方资料，先补取证；若低估自己会偏，才加自我校准，不反复重复同一张表。
