# TM-064 · 机会成本

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与输入
项目看起来有收益，却挤占同一批人、时间或注意力时用；休息也可以是有价值的替代。机会成本不是所有放弃项相加，更不是事后见到的完美人生。需要当前用途、冲突资源、可行替代、相近期限及用户偏好；缺替代时问：“如果这份资源不放在这里，眼下你实际还能把它用在哪里？”

## 转换动作
1. 找真正稀缺的资源，包含管理注意力、渠道位置和恢复精力。检查方案是否互斥；不同资源可以同时做的，不强迫二选一，而比较可行组合。
2. 逐个验证替代项是否在当时够得着，有没有资格、资源及时间窗口；可能获得的机会标为不确定，不能当确定收入。已不可收回的过去投入另放，仍能改变去向的未来资源保留。
3. 在相近时间、风险和完整成本口径下比较预期净价值，选最佳未选项作为机会成本。不同价值无法统一时，按用户认可的底线和优先级分栏比较，不擅自用自己的时薪否定他人的乐趣。
4. 比较当前方案相对最佳替代的增量优势，已在成本表扣过的机会成本不重复扣。差距对小变化敏感时列反转条件并保留灵活性；选择完成转执行，到约定节点或关键事实改变才重评。

## 最小成果与停止
交付冲突资源、最佳可行替代及可行性证据、增量优势或多维权衡、当前建议与更新条件。知道真实放弃了什么并能说明权衡即完成；没有冲突资源或可行替代时停用，别制造虚构成本。事后别人的结果更好不能自动推翻事前选择，建议、接受和实际资源分配分别记。

## 工具箱接口
替代项太少时把资源限制交给选项生成；过去投入搅乱讨论时用沉没成本清账；要知道下一份资源怎样增投时交边际分析。选择取决于未知收益时再接概率或信息价值工具，不为日常每一分钟持续算账。
