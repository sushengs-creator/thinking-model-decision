# TM-042 · 在群体气氛中恢复行为责任与后果意识

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
匿名或强烈群体气氛下，以“没人知道是我”“多我一句无所谓”为越界理由时用。匿名也能保护真实意见，群体规范可能促进帮助，不能因参加群体就判定失控。输入拟做行为、平时认可标准、受影响者、责任链与匿名需求；关键追问：“这件事具体会给谁带来什么后果？”

## 转换动作
1. 写清准备说或做的动作，问独自冷静时是否认可，区分个人贡献与全部群体行为。自己只转发一次也可能产生影响，但不能把群体全部责任压给一人。
2. 查现场正在奖励什么：事实核查、帮助、羞辱、转发或更强表态。把可识别性降低、责任稀释、群体规范变显著作为待区分路径，不宣称所有人都经历同一心理开关。
3. 情绪高时暂停非必要传播、惩罚与公开表态，回查对象、来源和权限，将标签还原成实际受影响的人。保留正当批评与求助，不用“冷静”要求当事人承受真实损害。
4. 分开表达、判断与执行：表达可安全匿名，判断记录理由，正式行动明确适当责任和纠错入口。公开实名不能代替治理，也不能强迫弱势者暴露身份；可撤回或更正的步骤要具体。

## 最小成果与停点
交付行动、事实状态、影响、责任与纠错检查，以及保留匿名保护的流程。个人贡献和后果清楚、行动符合核查与授权条件，即完成；不以情绪归零验收。若只是在匿名报告真实问题，停止越界归因，转正常处理。

## 工具箱接口
未知截图或主张交证据核验，群体规则交参与者治理，已决定的更正交执行工具。若真正问题是没人承接任务，改用责任明确；不能用取消匿名包办所有群体问题。
