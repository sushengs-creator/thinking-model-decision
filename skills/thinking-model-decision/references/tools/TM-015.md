# TM-015 · 去掉被支配选项后按真实需要重选

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
多了一个自己不会选的套餐，另一项突然显得必选，却没增加实际需求时用。价格更高、数量更多往往是权衡，不能直接称全面优势；也不能看到三个选项就认定商家操控。输入所有候选、同口径属性、必要用途与预算；缺口问：“你实际会用到哪些功能或份量？”

## 转换动作
1. 先写必要需要，再列价格、数量、质量、限制等属性矩阵，连同不买或维持现状。把表面规格与用户真正有用的部分区分，缺失属性不擅自假定相同。
2. 逐对核查支配：某项在所有相关维度不差，且至少一项更好，才能说它支配另一项。若目标支配第三项，而竞争方案与第三项各有优劣，才形成典型不对称关系；记录逻辑而非只贴诱饵标签。
3. 暂时移除被支配候选，重新比较剩下真实竞争方案的增量成本与必要收益。注意升级相对诱饵便宜，不等于相对用户原需求值得；同内容更贵者若无额外条件，就是劣项，不能反着判断。
4. 若去掉后仍选择升级，说明具体满足什么需要；若改变选择，记录情境影响但不声称已证明他人故意操控。不同选择也可能来自刚发现的真实信息。

## 最小成果与停点
交付属性矩阵、可核查的支配箭头和按需求重选的理由。必要属性齐全、升级理由不只依赖“比那档划算”即可结束；不要求选最便宜。出现新增服务或隐藏限制时重画关系，属性不可比时退出支配判断。

## 工具箱接口
剩余各有利弊的方案可交多标准取舍；总费用被分期或日均表达遮住时才接总成本工具。无需再添加一个人为选项来抵消原诱饵。
