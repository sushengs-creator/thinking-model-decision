# TM-016 · 分清不甘认亏与真实不能承受的损失

状态：v2运行文件；来源与试跑范围以tool-index.json为准。

## 触发与最小输入
为避免承认损失而守住不合适方案，或想通过进一步冒险把之前投入赢回来时用。谨慎可能符合真实底线，不能把所有怕失去都纠正成大胆。输入觉得亏的对象、比较基准、未来可选动作与不可承受后果；关键追问：“你说亏了，主要是跟什么状态或承诺在比较？”

## 转换动作
1. 写出参考点是原价、原计划、曾经达到的状态还是别人期待，区分已发生损失与未来可能损失。参考点解释感受，不自动决定下一步应该继续还是停止。
2. 从今天起按同一期间列继续、缩小和退出的新增成本、机会与不可逆后果。过去无法追回的投入不重复计费，退出确实造成的后续责任和转换成本仍需计入。
3. 做从零选择检验：若没有此前得失，现在愿意选择同样行动吗？若不愿，查是否仅是不甘，还是已有资源、经验和关系让继续更有价值。不得把一切冒险都归因于损失厌恶，也不套个人固定痛感倍数。
4. 依据可观察证据设继续、缩小或停止条件，必要时留出可行的冷静时间。若追加可能越过生活或承诺底线，先约束最大投入；不可用期待翻本来替代新增行动的证据。

## 最小成果与停点
产物是参考点、未来方案表和一条明确改判条件。感受与未来代价已分清、行动不靠补偿过去的冲动支撑，即完成本轮；不要求用户不再难过。发现真实不可承受损失时保留谨慎，新证据改变未来收益时重新比较。

## 工具箱接口
未来方案交取舍或执行工具；若争议只是既往投入无法放下，可接沉没成本分析。关系或复杂责任不能凭此单一模型决定，必要时引入参与者与约束视角。
