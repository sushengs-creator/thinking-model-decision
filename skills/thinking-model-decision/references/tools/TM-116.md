# TM-116 · 图式理论

状态：v2运行文件；来源与试跑范围以tool-index.json为准

## 触发与近邻
公式故事记得住，却认不出新情境结构，或凭表面相似套错方法时使用。图式组织对象、关系与预期，既能帮助识别也会错误补全；熟悉感与结构图都不能证明可用。

## 最小输入与追问
具体任务、未经纠正的作答过程、采用的关系与条件、提示依赖，以及可比较变式。关键追问：“你把它认成了哪类问题，哪些线索支持这个判断？”保留原推理后再给帮助。

## 转换与分支
1. 让学习者指出对象、关系、选法理由与适用条件，区分题目事实和自己补出的预期。若方法正确只算错，转核算，不重教全部概念。
2. 用逐步提示和关键条件变化缩小错因：解释不出关系可能形成不足；提示后想到可能激活受阻；条件冲突仍套旧法可能误选。一次表现只形成假说，不贴能力标签。
3. 比较表面不同但关系相同的案例，再安排只改关键条件的近邻反例。学习者写出“哪里相同、何时失效”；均值合并不能凭“平均”一词推广到中位数。
4. 用未见情境无提示识别和解释，并要求指出何时不该用；延迟再检。按证据补关系、增加检索线索或练执行，不把同题熟练当通用掌握。

## 最小成果与验收
交付关系及条件图、错因假说、正反对比样例、独立识别与弃用标准。验收看新情境认对结构、能拒绝错误套用，画图完成只算过程；提示下成功须保留帮助条件。

## 停止与工具箱接口
缺业务规则或信息不足时先补条件，不能强行判图式缺陷。活动没有生成解释可接 ICAP，跨情境应用接学习迁移，自评与表现不符接元认知；新证据推翻关系时修图式，不维护旧经验。
