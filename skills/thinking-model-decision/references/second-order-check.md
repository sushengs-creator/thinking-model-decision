# 二阶影响检查：按需要启用

本文件是对现有二阶思考教练的交互方法与万维钢资料中因果、反馈、反作用机制的适配，不是新增TM编号，也不是要求每个问题都推演未来。

## 何时有用

当前方案会改变其他参与者的行为、激励、供需、能力或后续选择，且这些反应可能改变方案排序时启用。也适用于用户从一个变化直接推出长期职业或行业结论。简单事实、已经够用的局部决定和无关的远期想象不启用。

## 怎样检查

1. **固定起点与第一层影响。** 写清实际发生或拟采取的变化、比较基准和时间窗口。区分已发生、用户观察、待验证预测。行业共识不等于一阶，逆向观点也不自动更深入。按问题需要同时考虑规模、变化速度、限制和证据，不能仅凭增速推断方向。
2. **识别后续反应。** 由该变化提出一项最可能改变行动的问题：谁会怎样应对？稀缺环节可能转移吗，或者不变？是否出现反馈、延迟、抵消或资源约束？可以用“然后呢”帮助表达，但每个关键箭头都要说明机制、条件和依据。没有证据的箭头保留为假设，不用漂亮因果链冒充因果证明。
3. **给竞争解释留下空间。** 在最影响选择的分叉处提出有竞争力的另一情景，如需求没有增长、参与者改变策略、限制条件阻断作用，或瓶颈并存。不要固定预设“生产过剩，分发稀缺”。只比较会改变当前行动的分支，不无限列世界可能性。
4. **回到选择与检验。** 区分对多种情景都值得做的动作与只在某假设成立时值得做的动作。把需要核实的假设接到可观察证据、信息来源、投入边界和更新节点；低成本小试只是可选方式，已有资料、询问、等待或暂不行动也可以。长期承诺须有相应证据，不能因走完流程就要求用户押注3—5年。

## 最小产物与停止规则

留下与决定相关的因果链或分支，注明关键机制、依据与假设；给出哪个反应会改变选择、目前能做什么、出现什么信息就改判。时间窗口按实际任务确定，不固定5—10年。缺证据就保留未知；高/中/低置信度若使用须有理由，不能依据谁推演或语气多坚定来决定。

当新一层影响已经不改变当前方案、没有可检验依据或用户要求停止时，结束扩展。必要时由TM-062或WW-3.5帮助判断是否值得继续查证，先读取对应机制，不因本文件提及就自动叠加。

## 来源与适配边界

借鉴用户已安装的`second-order-thinking`中逐轮提问、卡住时示范、结果追溯和笔记沉淀的设计；未复制其历史引语、行业案例、固定实验数量及“用户亲自推演置信度更高”等表述。它不是本技能包的运行依赖。
