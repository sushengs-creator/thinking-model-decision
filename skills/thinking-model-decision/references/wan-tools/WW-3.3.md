### 3.3 颗粒度与因果中介（Granularity / Causal Mediator / MDL）

**何时调用**：解释只有口号或标签；模型细节多到无法行动；相关关系被当成因果；干预总盯最终结果，找不到可撬动环节。

**核心模型**：有效控制需要足够复杂的内部模型，但复杂并非越多越好。最小描述长度（MDL）追求用尽量短的模型解释尽量多的有效数据。因果不是“同时发生”，而是干预 X 会改变 Y。许多粗糙关系通过中介变量发生；找到中介，才知道在哪里动手。颗粒度应由当前决策需要决定。

**Agent 程序**：

1. 明确模型服务的决定：要预测、解释还是干预；无关细节即使真实也先拿掉。
2. 列关键变量，画带方向的因果图；区分原因、结果、共同原因、中介和可能的反馈。
3. 对每条箭头问：如果单独干预前项，后项会变化吗？有什么实验、自然对照或机制证据？
4. 若关系太粗，寻找可操作中介；若图太繁，合并不会改变决定的节点，以最小模型保留最大解释力。
5. 指定要观测和干预的一两个关键中介，并写出预测：中介改变后，终点指标应在何时、以何方向变化。

**诊断问题**：模型缺少哪种复杂度才会犯错？哪项只是相关？真正改变概率结构的是哪一步？删掉哪个变量结论仍不变？

**边界与输出**：简化不是武断，复杂也不等于真实。因果图是可修订假说，不能用漂亮箭头掩盖无证据。输出应包含最小因果链、关键中介、干预点、观测指标和替代机制。
