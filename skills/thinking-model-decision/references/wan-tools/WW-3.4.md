### 3.4 贝叶斯先验（Bayesian Prior）

**何时调用**：新证据需要改变信念；罕见事件检测；判断人、消息或风险是否可信；用户在“毫无立场”和“绝不动摇”之间摆动。

**核心模型**：后验判断来自先验与新证据的似然共同作用。先验不是可耻偏见，而是压缩历史频率、环境知识和已有经验的起点；新证据的力量取决于它在不同假设下出现的相对可能性。罕见事物即使测试很准，也可能有大量假阳性。科学气度是先有合理强度的信念，又为“我可能错”保留概率。

**Agent 程序**：

1. 定义互斥或可比较的假设，并找最接近的基准率作为外部先验。
2. 加入对象特征，说明它为何应使先验上调或下调；不要重复计算同一信息。
3. 评价证据似然：若假设真/假，看到该证据各有多常见；生动、权威和转发量不等于高似然比。
4. 更新到一个范围或等级，并记录前后变化。证据弱就小改，独立且诊断性强的证据才大改。
5. 预先规定下一条什么证据会继续更新，并用行动获取；持续校准预测而非只发表观点。

**诊断问题**：基准率是多少？这个证据在假设为假时也很常见吗？先验来自数据、环境，还是身份忠诚？

**边界与输出**：不把概率设为绝对 0 或 1，但也不必对荒谬说法假装五五开。证据相关、选择性呈现时不能连乘。输出应列先验、证据诊断性、更新后判断和下一更新条件。
