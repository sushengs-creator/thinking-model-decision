# 安装与加载：先看你的智能体能做什么

本工具面向各种智能体用户。**先把技能资料交给 AI，再开始问问题。** 有的产品把资料保存为可反复调用的技能，有的只能在当前会话读取文件；二者都可能执行本工具的流程，但保存和再次使用的方式不同。

你不必先学会命令行，也不需要某个特定品牌的智能体。Skill 是方法与资料的完整文件夹，不是一个只要复制名称就能生效的口令。

## 选择加载方式

不知道当前产品支持什么，先复制 [README 中的安装与检查请求](../README.md#第一次使用) 给它。若它无法识别所在产品，请补充你使用的产品名、网页或桌面版、能看到的“技能／导入／附件”入口；不要照着它猜出的菜单操作。

| 当前环境能做什么 | 选哪条路径 | 完成后怎样继续 |
|---|---|---|
| 能从仓库安装技能，或有技能导入功能 | **A：原生安装**，使用该产品的安装器或导入入口 | 按产品要求启用或重新加载，再做下文的读取检查 |
| 没有技能入口，但能读取工作区目录，或能解压附件并逐个读取其中的文件 | **B：本次会话加载**，提供完整技能目录 | 让它先读 `SKILL.md`，按需读取模型资料；新会话可能要重新提供 |
| 只能聊天，或上传后只能看到名称／摘要，不能访问技能正文和所需资料 | **C：当前不能运行完整工具** | 可以先做普通问题分析；要使用本库，需切换到能读取完整目录的环境，或启用当前产品提供的相应能力 |

**看到上传按钮不代表属于 B。** 是否能解压、读取嵌套文件、保留文件名与路径，需要实际检查。把几百份资料一次塞进聊天框也不等于完整加载：使用时只需读相关模型，但完整包必须保持可访问。

## 手动下载与加载

### 先取得正确的文件夹

1. [下载仓库 ZIP](https://github.com/sushengs-creator/thinking-model-decision/archive/refs/heads/main.zip)。也可以在仓库首页选择 **Code → Download ZIP**。
2. 在电脑上解压。在通常名为 `thinking-model-decision-main` 的文件夹里，打开 `skills`。
3. 找到里面的 **`thinking-model-decision` 文件夹**。这整个文件夹才是技能包；不要只取 `SKILL.md`，也不要把 README 当作技能。
4. 确认里面能看到如下结构。普通使用无需打开全部文件：

```text
thinking-model-decision/
├── SKILL.md                入口：告诉 AI 怎样工作
├── references/             模型卡、原文、目录和规则
├── assets/                 HTML 报告模板
├── scripts/                检索与维护辅助脚本
└── agents/                 部分客户端使用的可选界面信息
```

只用手机时，可先尝试产品的链接导入；如果只能上传附件，可以提供下载的 ZIP，让具备解压能力的助手定位其中的 `skills/thinking-model-decision`。若它既不能解压，也没有文件夹读取能力，就还没有完成加载；不要把“收到附件”当作可用了。

### A：有技能安装或导入入口

- **支持仓库链接：** 使用这个技能目录链接，并让安装器安装完整目录：
  `https://github.com/sushengs-creator/thinking-model-decision/tree/main/skills/thinking-model-decision`
- **支持文件夹导入：** 选择上一步取得的 `thinking-model-decision` 文件夹。
- **只接受技能 ZIP：** 按该产品导入说明，将技能文件夹或其中内容压缩后导入。若要求 ZIP 根目录直接有 `SKILL.md`，应压缩技能文件夹里面的内容；若要求带顶层技能文件夹，则压缩整个文件夹。**刚下载的仓库 ZIP 还含 README、docs 和 skills 外层，不能假定能直接导入。**
- **要求放到技能目录：** 先从当前产品官方文档确认路径，再复制整个技能文件夹。结果应是 `<产品技能目录>/thinking-model-decision/SKILL.md`，不要多套一层 `skills` 或仓库文件夹。复制前检查有无同名技能，已有修改先备份。

各产品的路径、导入格式、大小限制及启用方式不同，没有一条适用于所有产品的本地路径或安装命令。让助手核对当前产品的官方说明；它无法核实时，应说明这一缺口，而不是默认使用别的产品的设置。

安装后按该产品要求刷新技能列表、启用技能或新建会话，再做 [读取检查](#确认是否可用)。复制文件成功、列出技能名称、实际读取资料是不同的确认步骤。

### B：只有工作区或附件功能

**能读取工作区目录：** 把完整技能文件夹放到这个 AI 能访问的项目或工作区中，选中或附上该目录，让它知道具体位置。电脑上的路径不自动等于云端 AI 能访问的路径。

**只能上传附件：** 提供完整技能包 ZIP；也可以提供仓库 ZIP，并说明要加载其中的 `skills/thinking-model-decision`。先让助手尝试解压并检查文件读取能力。若产品不支持压缩包，但支持保留目录结构的文件夹上传，可以改用文件夹；只有单文件摘要能力时，不能由此宣布整个库可用。

然后发送：

```text
我提供的是 thinking-model-decision 技能资料。
请先确认你能读取完整技能目录：如果是 ZIP，先解压并定位 SKILL.md；
先读 SKILL.md，再读 references/library-state.json 和 references/cards/TM-077.md。
请报告实际读到的版本、模型名称和这张卡的一个使用边界。
后续按入口流程、按需读取相关资料来帮我，不用一次读取全部文章。
这是本次会话加载；如果不能解压或不能读取文件，请说清楚卡在哪一步，不要称为已安装。
```

确认可读取之后，再发送自己的困惑。上传记录或附件名并不能证明读取成功。若平台只把附件转换成摘要，文件路径和正文都无法定位，请按路径 C 处理。

### C：当前不能读取技能包

请助手明确说明“当前未加载本工具”，你可以先让它做普通分析。要完整使用这套模型库，需要一个能安装技能或读取这些文件的环境；这与是否叫“智能体”无关。单独粘贴 README 或一段提示词，无法替代模型原文和操作卡。

## 确认是否可用

安装或上传后，复制下面这段，不用自己检查几百份文件：

```text
请检查本次 thinking-model-decision 是否已经可用，不要只看技能名称。
1. 告诉我这是原生安装，还是仅本次会话加载，并给出实际安装位置或资料位置。
2. 实际读取 SKILL.md 和 references/library-state.json，报告版本及模型数量。
3. 实际读取 references/cards/TM-077.md，报告模型名称及一个具体使用边界。
4. 说明你能否生成可下载的 HTML 文件；不能时能怎样交付。
未完成的检查请明确标注，不要猜测。
```

当前公开技能为 **1.6.0**，库状态应记录 133 篇用户模型、133 张卡片和 100 个万维钢工具；TM-077 的名称为“可逆决策”。卡片中的一个边界是：**能够停止，并不代表能恢复全部后果**。数字和名称是核对线索，不能只照抄这页就算通过；要有实际读取记录、可核对的文件位置或产品可见的安装状态。

这是抽查入口和一张卡是否可读，不代表已检查全部文件、所有模型效果或新会话自动加载。原生安装还要按产品界面或实际路径确认，当前会话未识别时按官方方式重新加载。

有命令执行能力和 Python 3.9 以上版本时，可再让助手运行库完整性检查：

```sh
python3 "<技能目录的实际路径>/scripts/library.py" validate
```

这是可选的维护检查，日常问答不要求会用 Python。脚本使用标准库，通过自身位置查找资料，不依赖特定产品目录；没有运行就写明未运行。

## 第一次开始对话

确认可读后，发送：

```text
请调用 thinking-model-decision（思维模型决策工具）。
我学一门技能几个月了，现在不知道该不该继续。
请每轮问我一个关键问题，等我回答后再继续，最后给 HTML 下一步行动计划。
```

对于这段还不清楚的困惑，助手通常会先问目标或具体困难，等你回答后继续；如果你一开始已把信息讲全，也可以直接要求报告。可参考 [完整操作示范](../README.md#操作示范)。

自然语言是本项目通用的使用请求。若产品有技能菜单、`/` 命令或其他专用语法，使用该产品提供的方式；`$thinking-model-decision` 只是 Codex 的一种调用语法，不要求其他产品采用。`skill-installer` 也不是本工具的依赖。

## 报告怎么拿到

| 当前能力 | 你会收到什么、怎样使用 |
|---|---|
| 能生成文件或附件 | 实际存在的 `.html` 文件或下载链接；保存后用浏览器打开，也可打印 |
| 不能写文件，但能输出文本 | 完整 HTML 源码和文件名建议；复制到纯文本编辑器，以 UTF-8 保存为 `.html`，不要保存为 `.html.txt` |
| 不方便保存 HTML | 直接说“本次只要纯文本行动计划”，内容要求不变 |

只有源码时，不能称为已经生成可下载文件；仅完成追问时也不需要报告。浏览器预览、外部事实检索取决于当前环境能力；没有完成的核验应标注，不妨碍有依据的部分继续分析。本项目不额外要求专用 API Key，所用 AI 平台可能有自己的账号和额度要求。

## 更新已安装版本

仓库变了，不会自动更新你此前安装或上传的副本。需要新版时可以发送：

```text
请检查当前 thinking-model-decision 与仓库最新版本：
https://github.com/sushengs-creator/thinking-model-decision
先识别并备份我的新增文稿、卡片及本地修订，在临时位置准备新版。
比较差异并保留有效修改，完成可用的校验后，按当前产品的方式更新或重新加载。
告诉我实际更新的位置、版本和未完成的步骤。
```

即使没有自定义内容，也先留旧版备份。备份放在自动发现范围以外，避免两个同名技能。只更新 README 等使用文档时，通常无需重装技能；模型或入口规则有变化时，再按发布说明更新。临时加载者需提供新的完整资料，保留旧报告以便继续分析。

## 格式与兼容性说明

包结构依据 [Agent Skills 开放规范](https://agentskills.io/specification)；该规范定义目录、入口和资源，并没有规定所有产品统一的安装按钮或路径。客户端如何发现和读取技能，见 [官方接入说明](https://agentskills.io/client-implementation/adding-skills-support)。

`agents/openai.yaml` 只用于识别它的客户端提供界面信息，不是核心流程的前置条件，不需要为此另装 OpenAI 组件。普通分析按需读取文件即可；修改模型库才需要写入权限，运行辅助校验才需要命令执行能力。

本次核对了文件结构与文档使用路径，未声称实测了所有产品的安装、上传、自动发现或附件生成。遇到特定产品问题，请提供产品名、版本与不含隐私的错误信息，便于定位安装还是调用环节。
