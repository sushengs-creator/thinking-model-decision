# 完整操作示范

本例演示怎样决定是否报名数据分析课程。

**下面的情境、问答和报告均为编写的虚构教学示例，用来演示操作，不是真实用户记录、实跑记录或效果证明。** 实际使用时，助手会等待你的回答，再决定下一步；你不用照着示例回答，也不用先学会模型名称。

### 第一步，把困惑发给 AI

完成安装并启用，或在当前会话加载技能后，在当前 Agent 的对话框里发送下面这段话。不同产品可使用自己的技能菜单或命令，下面统一用自然语言。

```text
请调用 thinking-model-decision（思维模型决策工具）。
我想学数据分析，已经看了好几门课，但一直决定不了要不要报名。
请一步一步帮我梳理，每轮问一个关键问题，等我回答后再继续。
问题清楚后，给我一份 HTML 下一步行动计划。
```

### 第二步，每次回答一个问题

**AI 第一次提问**

> 你希望学会数据分析后，先解决哪一件具体的事？

**示例回答**

> 我每个月都要整理一份活动数据，希望能自己看出哪些活动值得继续做。

**AI 根据回答继续问**

> 现在有了具体目标，就是改善每月的活动分析。你能稳定投入多少学习时间？

**示例回答**

> 每周最多三小时。我看中的系统课每周要八小时，暂时挤不出更多时间。

**AI 再确认可行的选择**

> 这门课的时间要求超过了你的稳定投入。除了报名系统课，你还有什么可以先试的学习方式？

**示例回答**

> 有一份免费短教程，可以拿往年的一张数据表跟着做，我有权用它练习，但还没试过。没有必须现在报名的期限。

三轮只属于这个示例。信息已经足够时，助手会停止常规追问；实际问题缺少关键条件时，才继续问。你不知道的事情可以直接回答“不知道”。

### 第三步，看问题如何变清楚，模型如何改变判断

此时助手可以归纳为“怎样在每周三小时以内，开始改善活动数据分析”。还不知道短教程是否适用、数据是否齐全、学习后能否独立解释结果，这些会保留为待验证条件。

本例选择 **[TM-077 可逆决策](../skills/thinking-model-decision/references/cards/TM-077.md)** 作主模型，把下一步限定为有时间上限的小任务，同时承认已经花掉的时间无法收回。补充 **[TM-062 信息价值](../skills/thinking-model-decision/references/cards/TM-062.md)**，明确这次尝试要回答“时间够不够、卡在哪里、能否独立解释”，以及不同结果会怎样改变后续选择。缺少可信概率和收益数据时，不编造分数或回报率。

| 可选方案 | 与当前目标、约束的关系 | 本例中的判断 |
|---|---|---|
| 立即报名所看的系统课 | 按已提供信息，每周八小时超过三小时上限 | 暂缓；只有时间安排或课程要求发生可核实的变化，才重新比较 |
| 先用短教程完成一个小任务 | 可以限制投入，并观察实际学习困难；适用性尚未知 | 有条件优先，先检查材料和资源要求 |
| 暂时维持原有月报做法 | 无需新增学习投入，但改善目标仍未推进 | 保留为基准；当前没有合适材料时可以暂用 |

### 第四步，打开 HTML 行动计划，照着做第一件事

在能生成文件或附件的环境，正常完成分析后会给出实际保存的 HTML 文件链接。打开即可阅读和打印。不能生成文件时，助手应给完整源码和保存方法；也可以明确要求只用聊天文字交付，详见[打开与保存方法](USAGE.md#报告怎样打开与保存)。

这里提供一份可查看结构和内容的 **[HTML 示例报告](examples/learning-decision-demo.html)**。GitHub 文件页显示源码，可点击 **Download raw file** 下载，再用浏览器打开。文件名是 `learning-decision-demo.html`，无需联网阅读。

报告中的行动安排如下。三小时来自示例中的个人约束，只是本次投入上限，不代表能在三小时内学会数据分析。

| 顺序 | 示例学习者要做什么 | 得到什么，以及何时停下 |
|---|---|---|
| 先检查能否开始 | 查看教程是否需要新付款、额外软件及当前没有的数据；选一个月报中确实需要回答的小问题 | 明确能否在现有条件下尝试；有前置缺口就先缩小任务或暂停 |
| 下次可用学习时段内尝试 | 用允许使用的数据副本，围绕这个问题做一张简单汇总；准备、操作和复盘合计不超过三小时 | 保留结果、实际用时和卡点；到时间上限即停，不用挤占其他安排强行完成 |
| 尝试结束后判断 | 检查能否说明统计口径、结果含义和限制；区分“照着做成”与“能够独立解释” | 根据具体缺口决定继续短教程、补基础、寻求有针对性的帮助或另选课程 |

能完成一次小任务，也不自动说明适合报名每周八小时的课程。报告会保留当前建议的前提，以及哪些新信息会改变它。

### 第五步，带着结果回来更新

继续这个虚构情境。假设尝试后出现下面的情况，可以在原对话发送这段话；真实使用时换成自己的实际记录。

```text
请继续使用 thinking-model-decision，更新刚才的 HTML 行动计划。
我本周试了两小时，能跟着教程做出一张汇总表，
但离开教程后，不能独立解释计算口径。
每周仍然只有三小时。请说明哪些判断改变了、哪些仍成立，
保留旧版，再给出下一步安排。
```

助手应把“能照着做出结果”记为新信息，把“独立理解仍不足”作为下一步要处理的缺口，调整练习或求助方式，并更新 HTML。原来的时间约束仍然成立，不应因为做出一张表就建议增加到八小时；本周后续学习与复盘合计最多再用一小时，不足的部分延至下一次可用时段。若已换新对话，先附上旧报告或结论摘要，再补充变化。

把第一步中的困惑换成你的问题，就可以开始。背景已经充分时，也可以直接说“根据这些材料出报告”；暂时不想继续回答时，说“先给阶段性报告，标明未知”。
