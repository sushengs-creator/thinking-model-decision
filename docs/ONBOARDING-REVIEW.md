# 新手使用与跨智能体说明审阅

审阅日期：2026-10-09。对应技能版本：1.6.0，库修订号 33。本次修改 README、安装指南与使用指南，新增本记录；技能入口、模型资料和脚本保持不变。

## 发现了什么，如何修复

| 原有问题 | 本次修订 |
|---|---|
| 新读者未必知道 Skill 是什么，也不知道该在哪里对话 | 首页先解释技能包与 AI 助手的关系，再给四步使用路径；模型数量和历史记录放到后面 |
| “按当前 Agent 的方式安装”无法指导只有聊天和上传按钮的用户 | 安装指南分成原生安装、会话加载、能力不足三条路径；给出下载、解压定位、附件检查和下一步提示词 |
| 容易把收到 ZIP、出现技能名或复述版本当成成功 | 要求实际读取入口、库状态和一张模型卡，区分抽查、完整性校验、持久安装与会话识别 |
| 新用户知道可以提问，却不清楚拿到报告后怎么用 | 补充先核对建议前提、执行第一步、观察调整信号，以及原对话／新对话更新的方法 |
| 文件能力不足时，文案先承诺文件链接再补例外 | 在交付说明前置能力条件；分别给文件、源码、用户选择纯文本的路径 |
| “新增文章”例句仍用已收录的 TM-127 | 更新为 TM-134 示例，要求沿用新稿原编号；已有编号修订另走修订流程 |
| 新稿局部措辞混淆虚构问答与真实记录、解压与读取 | 根据独立试读修正，并做定点复查 |

## 实际完成的审阅

1. **修改前的独立读者推演：**设定读者使用非 Codex 智能体，只知道聊天和上传，不知道是否支持技能。只读原文档，未实际安装。推演明确卡在“按官方说明导入”和“能读取工作区文件”，无法从普通附件上传走到可读确认；调用与报告预期能理解。
2. **技能本体只读审计：**检查入口、可选界面信息、引导对话、报告、HTML、维护和模型关系规范及用户文档。未发现必须修订的产品专用硬依赖；区分了现有可选客户端语法与核心要求，不把所有出现的产品名都当缺陷。
3. **修改后的另一组独立读者推演：**分别处理“只有附件功能，不知道能否解压”和“已有导入入口，只收到安装完成”两种情境。两者均能找到具体请求、文件路径、读取检查、能力不足出口、首次使用及报告更新步骤。推演提出三处措辞问题，维护者修正后，评阅者定点复查确认均已解决。
4. **可移植性复核：**未发现新增品牌依赖或全产品安装保证；566 个技能文件与修改前逐文件 SHA-256 一致。公开包保留现有 133 篇模型、133 张卡片及 100 个万维钢工具。
5. **交付检查：**技能结构和库完整性校验通过；新增及修改文档的本地链接与标题定位检查通过。README 和安装指南做了本地 Markdown 桌面／窄屏预览（1440、390 像素）；正文没有整页横向溢出，宽表通过滚动查看。这是本地阅读预览，不是所有产品或 GitHub 客户端的视觉验收。

原始读者推演和执行回执保留在本次维护工作区。上述推演由独立 AI 评阅者执行，**不是招募真实读者的可用性研究，也不是在各品牌产品中完成安装测试**。

## 普适性的范围

本包沿用 [Agent Skills 规范](https://agentskills.io/specification)。官方 [客户端接入说明](https://agentskills.io/client-implementation/adding-skills-support) 区分本地与云端的技能发现和内容访问方式。文档据此按实际能力给出路径，不规定所有产品共享一个安装目录或调用命令。

面向各种智能体用户，不等于任何聊天或上传界面都能运行完整技能库。原生安装、读取附件、生成文件和联网核实，都需要当前产品实际支持。当前不支持时，如实说明尚未加载，并给普通分析或切换到具备所需能力环境的选择。

本次不新增模型或修改分析流程，技能仍为 1.6.0；已安装用户无需为此次文档修订重新安装。新手从 [README](../README.md#第一次使用) 开始，安装问题查看 [安装指南](INSTALL.md)，完整流程查看 [使用指南](USAGE.md)。
