# v2.1 高质量 Skill 深度检查

日期：2026-10-18。检查基线为 v2.0.0；修复与第143篇增量合并为 v2.1.0。重点是首次使用、逐轮追问、工具箱运行、报告交付和后续维护的连续可用性。

依据当前 skill-creator 的任务范围、渐进披露、按风险验证和独立实际试用原则，并沿用[此前从用户提供 PDF 提炼的18项标准](QUALITY-AUDIT.md)。本轮没有再次校勘该 PDF，不把下表称为认证或所有客户端的兼容保证。

## 发现并修复的问题

| 问题 | 对使用者的影响 | 修复 |
|---|---|---|
| 临近截止仍按提问时完整余额安排 | 用户读完建议后可能已经来不及执行全部步骤 | 核对真实截止时刻，扣除已耗时间；时间不足则压缩分析并优先完成决定与回复，保留原失败和复测 |
| 复述时把同事表达的目标称为共同目标 | 可能无意替用户接受目标 | 保留目标归属，只有双方明确接受才称共同目标；有缺口且影响选择时才追问 |
| 原文改变后，旧卡或未审卡仍能重新登记运行工具 | 新指纹可能掩盖卡片尚未复核，继续调用过期理解 | 登记、校验和查看同时检查卡片状态、卡片对应来源及正文/卡片登记指纹；拒绝待复核、草稿、未知状态及未登记改动 |
| 检索结果未显示资料已改变 | 使用者可能把检索命中当成当前可直接运行 | TM/WW 候选显示 `registered_current` 或 `review_required` 及原因；入口说明需先复核，当前一致也不等于现实有效 |
| 安装说明仍引用“四步”，新增文稿示例遗漏 v2 运行工具 | 新读者难以判断安装和更新是否完成 | 改为首页入门步骤；示例包含原文、卡片、运行工具、目录、真实试跑和各副本状态 |
| “不会自动监控”的绝对表述未区分独立调度 | 已授权的每日任务无法获得清晰维护规则 | 说明技能不自带常驻调度器；用户授权的定时任务沿用维护流程，其他读者安装后不会默认被监控 |
| 历史成功读取方法未沉淀到维护入口 | 直连返回验证页后容易过早要求用户重复提供全文 | 新增[已发表文集读取流程](../skills/thinking-model-decision/references/published-source-reading.md)：合集定位、正常浏览器可见正文、失败分类、文字指纹、媒体范围与运行记录 |

维护脚本缺陷先在虚构小库中复现，再加入针对性回归。原始失败、第一次修补及最终补全记录均保留，没有将旧失败覆盖为通过。详见[维护审计](../skills/thinking-model-decision/references/evaluation/v2.1.0/runtime-review.md)。

## 18项逐一检查

| # | 标准 | 本轮结论与证据 |
|---|---|---|
| 01 | 一句话任务与产物 | README 首屏说明从困惑到解决方案与 HTML 步骤；不要求先懂模型 |
| 02 | 输入、输出、失败和停止 | SKILL 与运行协议承接一句困惑；明确缺资料、暂停及维护的不同出口 |
| 03 | 真实触发与排除 | 模糊困惑正常提问；简单翻译、只想倾诉不强推分析；本轮是已加载入口的行为检查，非客户端自动发现实验 |
| 04 | 描述简洁、无万能承诺 | description 描述实际工作；数量与来源放正文，并披露机制重叠和验证范围 |
| 05 | 按信息缺口进入 | 一轮一个主要问题；连续对话依据用户新回答再问；足够信息不重复审批 |
| 06 | 步骤有实际产物 | TM-143 输出前提核查、可改条件、候选比较与退出路径；完整入口将工具成果汇入行动 |
| 07 | 质量门槛可核对 | 核实硬约束、总预算和第三方同意；不以“第三选择”合理化虚假完整交付 |
| 08 | 有停止条件 | 真冲突和搜索到期允许取舍；用户暂停立即停止；不承诺一定双赢 |
| 09 | 交代产物、核验及局限 | 完成分析生成实际 HTML；纯文字请求遵从；报告不假定实施已经发生 |
| 10 | 确定性工作脚本化 | 修复来源/卡片/运行指纹与检索状态；30项维护脚本回归通过，另做库完整性检查 |
| 11 | 平台能力解耦 | 通用 Agent 安装与会话加载分开；Python 和 OpenAI 元数据可选；不把某客户端命令写成普遍要求 |
| 12 | 渐进披露 | 入口只保留共同流程，按需读取对话、工具箱、具体工具或维护；不默认加载243条正文 |
| 13 | 标准场景真实试跑 | 适用的第三选择案例、旧工具协作报告及新工具连续对话均保存实际回应 |
| 14 | 缺口不乱猜 | 未证实的“全部重做”保持为用户理解，不替同事补写动机与同意 |
| 15 | 催促或跳核验不降低质量 | 10分钟真两难与容量不足交付案例保留硬约束、损失与义务 |
| 16 | 区分发现与执行 | 10条词面检索记录与独立作答分开；不把关键词命中当语义召回或自动触发成功率 |
| 17 | 异常可恢复或明确停止 | 正常浏览器读取和 HTTP 返回分别记录；真实验证障碍不绕过；陈旧工具须复核 |
| 18 | 根据失败窄改、保留经验 | 针对可复现缺陷修脚本，保持旧知识文件；新增读取经验和有来源的回归证据 |

## 交付与边界

本版增加 TM-143「第三选择」，当前143篇原文、143张卡、143个TM运行文件与100个WW来源条目。前142个模型与WW正文保持原内容；本轮未重新逐篇通读或重跑旧库全部模型。具体实际输入、输出和检查范围见[本轮验证记录](../skills/thinking-model-decision/references/evaluation/results-v2.1.md)。

HTML 已检查内容、资源预算、结构与引用；没有进行本轮视觉预览、所有客户端安装或现实效果研究。标准结构校验通过不证明决策总是正确；模拟通过也不保证真人一定接受或结果一定改善。远端、包与安装状态须以逐目标读回为准。
